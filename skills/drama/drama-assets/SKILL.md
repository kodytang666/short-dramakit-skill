# 短剧视觉资产设计与管理

为剧本建立**完整、统一、可持续复用**的视觉资产体系。核心认知：AI 生成没有搭景化妆——角色、场景、道具都是要被生成几十次还得长一样的**资产**；一致性靠参考图与锚点约束，不靠模型记忆。

## 核心立场

1. **三层模型**（判断一切视觉变化的骨架）：
   - **身份**：换掉就不再是同一个人/地/物（脸型发型身形、地点的固定结构、道具的本质形制）→ 资产卡核心；
   - **变体**：身份不变、状态改变（换装/受伤/湿污/时段天气/开合状态）→ 登记为变体，各需独立参考图；
   - **镜头瞬态**：姿势/视线/站位/角度 → 属于分镜（阶段五），本阶段不建。
2. **识别锚点三性**：可见（具体可指认，"左眉一道疤"✓ "眼神冷峻"✗）、可生成（文字能驱动画面）、可比较（两张图能判同异）。每场景锚点 3-5 个。
3. **提案-待定两态**：资产出现证据=剧本里的可见出场；剧本/圣经未写的外貌细节，本阶段**必须提案**（不建锚点就无法出图），但全部列入"待定项"并逐条标注"提案待确认"——创作者确认前不进入已确认状态，确认后转正。"不发明"指不静默当作既定事实，不是不写提案。
4. **连续性锁**：跨镜出现且观众看得出不一致的可见事实（红外套的颜色材质）写锁；锁面用最小名词短语，进入一切下游提示词；锁的是"不随剧情改变的事实"，会变的进变体。
5. **空景分层**：环境参考图不带人物（参考图里混进人，一致性全毁）；道具白底无手（可贴进任意镜头）。

## 工作流

1. **接收上游**：读剧本（或指定集范围的场次表+台词本+场景描述）、故事圣经（人物档案/说话方式无关但小传相关）、连续性设定文档、阶段一简报的制作预警（高负担角色提前规划变体数量）。剧本未确认时先向创作者确认，未确认剧本拆出的资产会随剧本改版漂移。
2. **风格先行**：先写《视觉风格指南》（见 templates/visual-style.md）：全局画风句（写实真人感一句固定措辞）、光色基调（按主要场景各一句）、负面清单（禁止出现的画风词——如"漫画脸/插画感"）、参考图语言。**所有 IMG 条目与关键帧共用同一画风句**——一集的关键帧要像同一部片。人物锚点图与变体图一律用**中性影棚光**（不绑场景光，保证可贴进任意场景）；场景光色归场景卡的光色句，镜头级光效归阶段五。
   开始前先做**project_id 核对**：剧本/圣经/简报的 project_id 必须一致，不一致立即报告（示例文档中的资产不得混入真实项目）。
3. **新实体登记规则**：剧本出现圣经未登记的可见实体（新道具/新地点）时：本阶段可建卡（编号接圣经顺延，如 PROP-8 之后从 PROP-9 起），卡头标注"**新增资产**"，并建议回阶段二补登记；无台词群演类背景实体不建卡（同阶段三豁免）。
4. **逐场扫证**：过一遍剧本找实体可见出场、可见描述、状态变化、含混指代（含混不猜，标待定）。
5. **人物资产卡**（CHAR 对齐，templates/asset-card-character.md）：
   - 基础身份锚点：脸型/发型发色/体形身高/肤质年龄感——4-6 条锚点，每条过三性检验；
   - 服装造型表：本集每套造型一个变体（变体 ID：CHAR-1-V2），每套写清"什么不变使它仍是同一资产，什么是本状态新增"；
   - **连续性锁**：跨集不变事实逐条写锁（最小名词短语）；
   - **画面代称**：提示词正文中如何指代该角色（中文名或描述短语——名字撞常用词时改用描述短语并声明"画面代称：无"）；
   - 参考图需求：锚点图（正面全身定妆）→ 派生视图（侧面/背面/45°半身/特写）——派生只参考锚点图，不改身份。
6. **场景资产卡**（LOC 对齐，templates/asset-card-location.md）：固定锚点 3-5（可画可认可核对）；光照时段变体（从剧本场次反推需要的时段，不写全家桶）；空景提示词（无人物）；一次性场景优先做母场景变体（variantOf）而非新景。
7. **道具资产卡**（PROP 对齐，templates/asset-card-prop.md）：戏剧功能（接圣经）、形制锚点、**状态变体**（合上/打开/损坏是不同参考图——道具有状态弧）、**尺度参照**（"可单手握持的长度约 20cm 的皮箱"，防 AI 把手持物画成家具尺寸）、白底无手提示词（可抠）。
8. **图片提示词**（IMG-ID 条目，templates/image-prompt.md）：每条 = 用途（身份板/造型变体/场景板/道具板）+ 六段式可复制正文：主体与身份锚点 → 当前变体 → 构图视角 → 光色材质 → 背景边界 → 禁止项。正文可直接复制、无占位符、无流程语言；连续性锁锁面原样进入正文；画风句进入每条正文。
9. **资产登记表**（templates/asset-registry.md）：ID/名称/类型/版本/依赖（哪张参考图派生）/使用集范围/当前状态（未出图/已出图待确认/已确认/过期）。重出某资产时，依赖它的派生图自动标"过期"。
10. **停靠**：资产卡与提示词成稿 → 汇报（资产数量/变体数/连续性锁数/待定项）→ 创作者确认后标 approved（"一次跑完"可豁免标注之）。

## 修订规则

- **人物状态变体编号**：湿身/受伤/污渍等状态与服装造型合并编号——同一套服装下的状态变化记为该造型的子变体（CHAR-1-V2-a），不另开新 V；换装才开新 V。
- 已确认资产的变更请求（含口头）：一律记 DEC（改什么/为什么/影响哪些集），按"改卡 vs 加变体"三层模型裁决——身份变=新资产，状态变=变体追加，均不覆盖已确认版本。
- 剧本改版：受影响资产卡版本 +1；被删除的场不再引用的资产标"闲置"（不删，备复用）；登记表同步。
- 新造型中途加入：新变体 ID 追加（V 顺延），不覆盖旧变体；旧变体在后续集仍可能被引用。
- 已确认参考图重出：登记表标过期 + 影响评估（哪些集的镜头引用过它）。
- 上游矛盾（剧本与圣经冲突，如剧本让角色"白发"而圣经年龄不符）：停笔报 DEC。

## 自检清单

1. 每个人物卡锚点过三性检验（抽 3 条自问：可见？可生成？可比较？）；
2. 每场景锚点 3-5 条；空景提示词无人物；
3. 每道具：状态变体齐（剧本用到的每个状态都有）、有尺度参照、白底无手；
4. 每个跨集可见事实有锁；锁面是最小名词短语；
5. 画面代称与提示词正文一致（名字会撞常用词的已声明）；
6. 所有 IMG 正文含同一画风句；光色句按场景统一；
7. IMG 正文无占位符/无流程语言/无"高质量"空话；
8. 登记表覆盖所有资产卡与 IMG 条目，无孤儿条目；
9. 待定项集中列出（含混指代/剧本未写细节），不静默发明。

## 常见错误

| 错误 | 纠正 |
|---|---|
| "气质冷峻"当锚点 | 锚点必须可画可认可核对 |
| 变体没建参考图就投产 | 每个变体 = 独立参考图需求 |
| 场景图里带人物 | 空景分层 |
| 道具图里有手 | 白底无手 |
| 把姿势写进资产卡 | 镜头瞬态归阶段五 |
| 剧本没写的外貌细节直接发明 | 标"待定"，创作者确认后入库 |
| 每条提示词画风措辞不同 | 全局画风句逐字复用 |

## 边界

- 不生成图片、不调 TTS（生产归外部工具/阶段六）；
- 不写视频提示词（阶段六）；
- 不做分镜与关键帧构图设计（阶段五，但 IMG 正文格式与阶段五冻结关键帧共享六段式）。
