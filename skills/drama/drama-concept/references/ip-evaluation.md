# 小说 IP 适配评估方法

## 四类判定（三类判定的扩展版）

对小说内容（按剧情单元或按抽样章节）逐段判定其**从文字到 AI 视频成片**的适配度：

| 判定 | 含义 | 后续处理 |
|---|---|---|
| `screen_ready` | 功能由可见行动、可听对白或空间关系承担 | 直接可用 |
| `needs_carrier` | 功能成立，但当前载体是文字专属（内心独白、叙述性诡计） | 必须写新载体（可见行动/物证/空间关系/对白策略/第三方反应），写不出则降级 |
| `prose_only` | 功能依赖读者与叙述者的关系，屏幕上无法兑现 | 明确放弃，写进风险 |
| `ai_hard` | 可拍但 AI 生成困难（大规模群演同框互殴、复杂肢体接触、长镜头调度、密集特效） | 标注给阶段五六评估替代方案或提高制作预算 |

**不要把 `prose_only` 悄悄改写成 `needs_carrier`**——假装能拍的代价会在分镜/生成阶段才暴露。同样，`ai_hard` 不是"不行"，是"贵或不稳"，立项时要把它折进制作规模判断。

## 抽样法（长篇原文）

原文超过约 10 万字或 60 章时抽样评估，否则全量。

抽样规则：
1. **等距抽样，首尾必取**，确定可复现（第二次跑引用同一批章）；
2. 默认 12 章（按 `总章数/12` 取间隔）；书特别长或结构复杂时调大，调大要写进报告；
3. 抽到的章正文极少（卷首页/过渡章）时向后顺延一章并记录；
4. **报告首行写覆盖率声明**：`> 本评估基于抽样：读了 N 章中的 M 章（x%），章号见附录。结论是假设，不是结论。`
5. 全量数字（精确爽点分布、完整人物线）留给阶段二的原著分析，本阶段只做"值不值得立项"。

## 材料降级规则（无原文全文时）

按可获得的材料分三档，采集信息时先确认能到哪一档：

| 档位 | 材料 | 处理 |
|---|---|---|
| 全量 | 原文全文 | 直接全量或抽样（上文规则） |
| 抽样 | 原文节选/前 N 章 | 按抽样规则，覆盖率声明如实写 |
| 降级 | 仅书名+简介，或简介+章节梗概 | 允许评估，但四类判定分母为"已读梗概章数/单元数"，全部判定与开篇替换点结论标 `[推断]`；覆盖率声明写明"基于简介与 N 章梗概（非正文）"；报告须建议创作者在阶段二全量拆解前提供原文复核 |

降级档的纪律：梗概是他人/作者的功能压缩，载体细节（心理描写占比、叙述方式）不可见——因此 `prose_only`/`needs_carrier` 判定只能给出保守估计，且不得用 Agent 对同类小说的记忆补细节。简介与 Agent 记忆冲突时以简介为准并提示创作者核实。

## 评估五问（IP 入口专用）

1. **故事框架**：升级流 / 复仇线 / 单元剧 / 多线交织 / 蜕变成长——框架决定按集切的难度（单元剧最贴合，多线交织最贵）。
2. **四类判定比例**：分母为实际阅读的章数/单元数。`prose_only` 过半 → 建议放弃或大幅重构；`ai_hard` 集中在某几卷 → 进制作风险。
3. **开篇替换点**：第 1 集从哪里开始——收益最强、且能同时交代主角身份/眼前危机/目标的一处（打脸、奇观、反转、身份揭露、危机爆发），通常不在第一章；后文更强的 高光可做冷开。写清：落在第几章、收益类型、它之前哪些信息必须后补、哪些是原著读者需要而短剧观众不需要的。
4. **人物资产量级**：主要人物数、造型复杂度、跨时间变化（重生双造型、变身、年龄跨度）→ 折算 AI 角色一致性负担。
5. **核心主线浓度**：原著注水比例的粗判（抽样里"对本集叙事无推进"的章占比）→ 决定改编幅度建议（忠实/抽核/借壳三档）。

## 改编幅度三档

| 档位 | 含义 | 适用 |
|---|---|---|
| 忠实 | 保留主线、人物、名场面，压缩注水 | 原著主线浓度高、粉丝基础强 |
| 抽核 | 保核心人物关系与爽点结构，重组情节 | 注水多、但单元判定 screen_ready 比例高 |
| 借壳 | 只取设定/题材，重写故事 | prose_only 比例高但题材与世界观值钱 |

## 输出要求

IP 入口的第④维评估必须包含：
- 覆盖率声明（抽样时，报告首行）；
- 四类判定比例（含分母）；
- 开篇替换点结论（或"抽样内未见可用开篇替换点"+列入风险）；
- 人物资产量级一句话；
- 改编幅度建议（三档选一 + 理由）。

## 法律与道德边界

- 只评估创作者**合法持有、拥有使用权**的作品；版权状态不明的网文默认"仅供个人评估"，商业改编需创作者确认授权 `[待验证]`。
- 评估是转化性分析：提取结构与功能，不在报告里成段复制原文；引用限于最短必要片段。
