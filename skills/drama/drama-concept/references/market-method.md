# 受众画像与市场评估方法

## 证据分级体系（本技能的核心纪律）

| 标注 | 含义 | 使用场景 |
|---|---|---|
| `[实测]` | 用户提供的真实数据、原文中的直接证据、创作者确认的事实 | 原文判定、创作者约束、对标作品的公开设定 |
| `[推断]` | 从已有证据经合理推导的结论 | 从题材卡推受众画像、从桥段推爽点密度 |
| `[待验证]` | 行业通识或经验规律，当前无法核实 | 平台政策、市场数据、模式收益、模型能力 |

规则：
1. 每个结论必须三选一标注；**裸断言不合格**。
2. `[待验证]` 的内容不参与"放弃立项"类强结论的依据链——不能用无法验证的市场判断否决一个选题，除非创作者补充确认。
3. 报告汇总处统计三类标注的比例，`[待验证]` 占比超过一半时在总评里声明"本评估的确定性有限"。

## 受众画像卡

四栏结构（写入选题评估报告与立项书）：

```markdown
| 栏目 | 内容 |
|---|---|
| 谁在看 | 人群（性别/年龄段/观看场景：通勤碎片/睡前/家务间隙） |
| 来感受什么 | 情绪需求（爽/甜/燃/恨/悬念/公道），对应题材卡"受众要点" |
| 在哪里消费 | 平台倾向（付费/免费）× 内容形态（竖屏信息流/剧场） |
| 什么时候走 | 弃剧点预测（对照题材卡的弃剧点字段） |
```

依据：性别/年龄段来自题材卡受众要点 `[推断]`；创作者提供目标人群时升级为 `[实测]`。不确定的栏写"待创作者确认"而非编造。

## 市场对标方法（定性）

只在创作者提供对标作品时做；无对标不虚构"市场情况"。

对标分析四步：
1. 列对标作品的公开可见要素（题材、集数时长、核心卖点——来自创作者描述或公开常识 `[待验证]`）；
2. 找**同**：本选题与对标的题材/桥段/受众重叠度；
3. 找**异**：本选题的差异化点（机制层面：对抗来源/代价结构/主角策略，不是措辞与职业）；
4. 结论：跟随策略（吃品类红利，吃同质化风险）/ 差异策略（吃辨识度，吃教育成本）。

**禁止**：引用具体充值/播放/投流数字（除非创作者提供并标 `[实测]`）；断言平台推荐机制（标 `[待验证]`）。

## 商业模式初判（三选一 + 理由）

| 模式 | 特征 | 适配信号 |
|---|---|---|
| 付费卡点 | 高潮悬念切集，用户单集/全集解锁 | 打脸/复仇强节奏题材；爽点密集可切卡 |
| 免费投流 | 完播率与留存导向，广告/品牌变现 | 甜宠/家庭/悬疑；情绪浓度高、弃剧点可控 |
| 分账/定制 | 平台采购或品牌定制 | 有 IP 基础或品牌契合点 |

初判输出 = 三选一 + 一句适配理由（引用题材卡"商业适配"字段，标注 `[待验证]`）。创作者给了平台倾向则以创作者为准 `[实测]`。

## 弃剧点分析（受众维的关键产出）

从题材卡弃剧点字段 + 本选题的具体结构推 2-3 个最可能的弃剧点，并各给一条规避建议（这些建议会写进制作简报的"受众与爽点要点"，供阶段二设计分集时规避）。

例：打脸题材弃剧点"打脸兑现前拖延过久"→ 规避建议"第 1 集必须完成一次小额打脸兑现 `[推断]`"。
