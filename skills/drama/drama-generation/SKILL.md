# 短剧 AI 视频生成与镜头制作

把已确认的分镜变成**可执行、可核对、可返修**的视频生成任务。严格分层：模型无关层（MOTION 正文 + 特效与电影感视觉语言 fx-cinematic.md）+ 模型方言层（references/seedance.md、jimeng.md，按目标模型只读其一）；troubleshooting.md、fx-cinematic.md 为跨模型通用参考，不属方言。**任何模型的参数、格式、能力限制都不得越层污染**；无法确认的能力一律标 `[待验证]`。

## 核心立场

1. **MOTION 条目是模型无关合同**：每镜一条，含从已确认起点到终点的完整状态链；方言层只翻译不增删。分镜的"起点→唯一动作→终点"被完整实现，交接与持物落点不跨镜省略。
2. **生成方式三态判定**（读分镜的参考图状态）：
   - 有已确认真实参考图（本镜关键帧图/人物锚点图/场景图/道具图）→ **图生视频**；
   - 参考图"待出图"但生成时由创作者自行挂载 → 图生视频（挂载计划），任务清单标"依赖待出图"；
   - 创作者明确选择不挂图 → **文生视频**，MOTION 必须写"静态视觉锚点"（人物外观/造型/地点/构图/光色——执行端没有任何图可保持，只写"保持外观"是无效指令）。
3. **方言只读一份**：目标模型在项目配置确认后，只读命中方言；换模型=换方言重编译 MOTION 正文，MOTION 本体不变。
4. **不编造能力**：方言文件中每条规则带证据强度（官方文档/实测小样本/待验证）；生成端行为未经验证的写法标注，验收时优先核对。
5. **续接优先于独立生成**：同一连续时空中相邻的两段（上一段尾帧是下一段开场画面），优先"从上一段实际视频续接"——续接需要**实际视频+实际尾帧**两样真实输入；剪接关系（换景别机位）的两段各自独立生成。未取得真实产物前，续接段标"待续接，不可提交"。
6. **提示词正文直呼人名，不认关系称谓**：视频模型读不到剧本上下文，不知道"父亲""儿子""两人""对方"是谁。正文一律写角色在剧本里的名字（陈默、陈建国、快递小哥等），不写"人物A/人物B"这类代号，不写关系称谓、身份代称与代词（父亲、儿子、老爹、两人、对方、他/她）。人名只在正文出现，**已挂参考图的角色正文内不写外形描述**——外形由挂载的角色图承载；**未挂图的角色（如无锚点的次要人物），外形必须写在正文首次出现处**，否则模型随机生成。`@图片N` 引用是提示词语法的一部分，**写在正文提及处**（每次提及都重复绑定，方言语法），任务上方的"参考："行只是给人看的核对清单。道具写实物名词（准考证、搪瓷茶缸、通知书）。
7. **空间基准先于提示词，一条一落**：模型只会独立看每一条提示词，不会记住上一段人在哪。动笔前先建一份**空间基准表**（平面位置 + 人物常驻位 + 道具位置 + 机位轴线），全片共用；每条正文按 **机位 → 空间 → 动作** 三段写：
   - **机位**：在哪、朝哪、什么景别；
   - **空间**：每个人在画面哪一侧、面朝哪、距谁多远、中间隔着什么、道具在画内哪个位置；
   - **动作**：从哪个状态开始、做完停在哪个位置。
   没有空间句的提示词（只写"他坐下""递给对方"）等于把站位交给模型随机决定，同一集里必然漂移。
8. **动作必须能被站位支撑**：动作句要物理自洽——手能不能够到、脚要不要挪、挪几步、挪完人在哪，都要写清且与空间句一致。**禁止重复位移与矛盾位移**（"从沙发站起、跨半步站到沙发前"：站起时人已在沙发处，再"站到沙发前"就是同一位置说了两遍）；**禁止一个动作里既原地又移位**（验收写"起立在原地"、正文写"跨半步"）。够不到的道具，先写"弯腰/前倾/迈一步"，再写抓取。

## 工作流

1. **接收上游**：已确认分镜（SHOT 条目+关键帧+镜头清单批次表）+ 视觉设定（资产图状态）。分镜未确认先催确认。
2. **确认目标模型**：项目未声明时问一次（影响方言、时长区间、参考方式）。**目标模型与原生时长声明后同时约束分镜与生成两端**——分镜镜长不在模型原生区间内，回阶段五调整，不在提示词里暗改时长。
3. **建空间基准**（先于逐镜写正文）：从分镜的站位块与场景图定出平面——机位在哪、朝哪、轴线在哪一侧；每个人在画面的哪一侧、面朝哪、离谁多远、中间隔着什么家具；每个关键道具落在哪个家具的哪一端、被谁拿、落点在哪。输出一张表放在提示词文件开头，后续每条正文只引用、不另起一套。跨段不换位的写成"常驻位"，中途移动的写明**移动的起点、路径、终点**（哪一镜起走、哪一镜到位）。
4. **逐镜编译 MOTION 条目**（templates/motion-entry.md）：来源 SHOT、时长、生成方式、静态视觉锚点（文生时）、参考图绑定（用途与顺序）、状态链正文（模型无关描述）、声音计划（对白逐字+发声窗口）、禁止项。相邻同时空的 SHOT 拆镜碎于模型时长下限时，可用**合并生成**（一条 MOTION 覆盖多镜起终态链，验收仍逐 SHOT 核对）。然后逐条改写称呼：正文里的人称全部换成剧本角色名，删掉"人物A/B/C"代号、关系称谓、代词与正文内外形描述（外形交给挂载图）；`@图片N` 按方言语法保留在正文提及处并重复绑定。镜头命中高精 CG / 机甲 / 科幻 / 奇幻 / 特效大片 / 强视觉风格时，先读 [references/fx-cinematic.md](references/fx-cinematic.md) 取视觉词，再写状态链与静态锚点。
5. **落空间三段**：每条正文补 **机位 → 空间 → 动作** 三段，并按"上一段结束位置 = 下一段开场位置"核对衔接；动作句逐步自检物理合理性（够不够得到、要不要挪脚、挪完停在哪），发现重复位移/矛盾位移就重写这一句，不靠"再靠近一点"这类模糊词补救。
6. **方言编译**：按目标模型读 [references/seedance.md](references/seedance.md)（Seedance 2.0/即梦共用底层）或 [references/jimeng.md](references/jimeng.md)（即梦平台操作差异）——**只读命中的一份**；其他目标模型暂无方言文件时，按方言文件中"通用降级路径"（见 seedance.md 末节）输出并标注"未验证方言"。每个可辨对白事件、音效、配乐按方言语法翻译；无对白镜写底声或静默。
7. **生成批次清单**（templates/generation-plan.md）：接阶段五批次表——每镜一行（任务 ID/参考图依赖与顺序/时长/预计生成次数/复用候选/方言正文位置）；依赖待出图的行标"阻塞：IMG-xxx 待出图"。**批次配置快照冻结**（模型版本/分辨率/方言版本，本批不改，换配置另开新批）；**预算确认**——按预计生成次数折算本批计费量级，创作者确认预算上限后才可提交；每行提交前过**预检**（参考图文件实际在手/正文无占位符/时长落区间/平台凭证可用/复用候选已核对/预算已确认），不过不提交。
8. **生成记录**（templates/generation-log.md）：按**产物条目**登记——创作者在生成端每次执行后回填一条产物（日期/参数/结果文件），每条产物独立可验收、可复用，验收挑选其中一条，其余保留不删；本 Skill 不调用 API、不上传文件。
9. **验收**（templates/acceptance.md）：按可核对项逐镜验收——起终态与 MOTION 一致、对白逐字完整、无未授权文字/水印、无身份漂移、时长达标；不通过的镜进返修流程。
10. **返修**（references/troubleshooting.md）：按症状查诊断表 → 首修动作（多数为"改写正文"而非"加负面词"）→ 记录返修版本；返修意见遵循**批评三轴**（指得出位置/扫同类镜/带修法——见 templates/acceptance.md 验收纪律）；同一镜返修两次仍失败 → 上报建议回上游（分镜拆镜/资产重出/关键帧修正）。
11. **停靠**：任务清单成稿 → 汇报（任务数/依赖阻塞/预计生成量）→ 确认后交付提示词包。

## 修改传播

- 分镜改版：受影响 SHOT 的 MOTION 重编译，版本 +1；已生成的旧素材按**产物条目**逐镜核对——与新版状态链一致的标"沿用旧产物"（在生成登记表回填沿用标注：文件名+对应 MOTION 版本+核对日期），不一致的标"需重生成"。沿用不重交，不重复计费。
- 参考图重出：依赖它的任务全部标"需重新核对"（登记表联动）。
- 上游矛盾（MOTION 无法忠实实现分镜，如动作量超时）：报 DEC 回阶段五。

## 自检清单（成稿必查）

1. 每个 SHOT 都有 MOTION 承载（含合并生成覆盖——合并条覆盖的每个 SHOT 起终态都在状态链中，无镜外瞬移）；
2. 生成方式三态判定与参考图实际状态一致（无"待出图"当"已确认"用）；
3. 文生镜有静态视觉锚点；图生镜参考图用途与顺序明确；
4. 对白逐字来自剧本（不改动台词——改词回阶段三）；有对白镜的发声窗口 ≤ 镜长；
5. 方言正文符合命中方言语法（对白/音效/配乐符号、时长整数、参考绑定重复提及）；
6. 未验证的方言写法已标注；验收清单含标注项核对；
7. 批次依赖无循环阻塞；待出图项回阶段四有登记；
8. 续接段的两样真实输入（视频+尾帧）有登记或已标"待续接"；
9. 无提示词正文夹带流程语言/文件路径/占位符；
10. 正文只写角色名，无"人物A/B/C"代号、无关系称谓与代词（父亲/儿子/两人/对方/他/她）、无外形复述；`@图片N` 按方言语法写在正文提及处并重复绑定，任务上方"参考："行与正文绑定一致；
11. 每条正文都有 **机位 → 空间 → 动作** 三段：人物在画面哪侧、面朝哪、距谁多远、中间隔什么，道具在哪个家具的哪一端；
12. 跨段衔接对得上：本段开场位置 = 上一段结束位置；换景别只换机位不换站位；
13. 动作句物理自洽：够得到道具（该弯腰/迈步的都写了）、无重复位移与矛盾位移、动作结束停在明确位置，且与验收栏一致；
14. 批次清单含配置快照，逐行已过预检（预检不过的行标阻塞并写明原因）；
15. 批次清单含预计生成次数与预算确认记录（未确认预算整批不提交）；
16. 生成记录按产物条目登记，每条产物有复用状态（候选/采用/被取代/沿用源），验收只挑选其中一条，其余保留可复用；
17. 上游改版后的沿用旧产物已核对状态链一致并回填沿用标注（文件名+MOTION 版本+核对日期）。

## 常见错误

| 错误 | 纠正 |
|---|---|
| "保持已有外观"（文生无图） | 写完整静态视觉锚点 |
| 上游改版就把所有镜重新生成 | 逐镜核对旧产物，状态链一致的沿用旧产物并回填沿用标注，不一致的才重生成 |
| 把 8 秒动作塞 5 秒镜 | 回阶段五拆镜，不在提示词里赌 |
| 所有镜都用同一套参考图 | 逐镜按视觉依据绑定 |
| 失败就堆负面词 | 查诊断表，先改正文写法 |
| 用 Seedance 语法写即梦之外的模型 | 方言只读命中份；未知模型走降级路径 |
| 台词在提示词里被"润色" | 逐字原则，改词回阶段三 |
| 用"父亲/儿子/老爹/两人/对方"等关系称谓，或用"他/她"代替 | 换成剧本角色名（陈默、陈建国、快递小哥） |
| 正文写"人物A @图片1（18岁男性，黑色三七分短发…）" | 人名直接写剧本角色名，`@图片1` 保留在正文；外形描述删掉，交给挂载的角色图 |
| 用"推到对面手边""两人对峙"这类关系描述 | 按机位写仓位与画面左右，人物一律写角色名 |
| 整条提示词只写动作，不写人在画面哪侧、面朝哪 | 补"机位 → 空间 → 动作"三段；空间句写死画面左右、朝向、距离、间隔物 |
| 同一集里两人左右乱换、每段像换了个房间 | 先建空间基准表并放在文件开头，每条正文只引用这张表；人物写"常驻位" |
| "从沙发站起、跨半步站到沙发前"（重复位移/矛盾位移） | 写一条位移路径：起点 → 迈几步 → 终点；站起就已在沙发处，只写"向前迈半步，停在沙发与茶几之间" |
| 手够不到茶几另一端的道具，却写成直接抓取 | 先写"弯腰/前倾/迈一步"，再写抓取，落点写清 |
| 正文写"跨半步"、验收写"站在原地" | 正文与验收同一口径：要么原地、要么写清移到哪 |
