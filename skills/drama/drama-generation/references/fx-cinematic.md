# 特效与电影感视觉语言（模型无关层）

> 定位：**跨模型通用的画面质感措辞手册**。当镜头涉及高精 CG、机甲 / 科幻 / 奇幻、特效大片、强视觉风格时读取本文件。作用是把手上的"每一帧烧钱"工业质感，翻译成生成模型能理解的视觉词——既用于 MOTION 状态链正文 / 静态视觉锚点的措辞，也用于方言正文的"风格锚点 / 场景 / 光色 / 视觉形态"段。
> 与方言分工：`seedance.md` / `jimeng.md` 管语法、时长、参考绑定、对白符号；本文件只管画面质感词，不重复它们的规则。本文件不点名具体公司 / 引擎 / 作品。

## 触发条件

命中以下任一特征时逐节套用，其余写实对话戏可只取「材质物理」「光线」两节：

- 高精 CG、机甲、太空 / 未来 / 废土科幻、东方玄幻 / 西方奇幻；
- 特效大片（爆炸、能量、法术、变身、机械变形）；
- 强视觉风格（强光影、高对比、电影宽幅、胶片质感）。

## 核心原则：单段可独立生成

每个镜头必须**自足**——把与前后段的无效因果、空间指向，改写为画面坐标、动作、镜头运动、光影材质；只写这一镜需要被看见的东西。

| 错误写法（依赖前段） | 改写（本段可见事实） |
|---|---|
| "她比刚才更愤怒" | "她攥拳、眉头锁紧、深吸一口气，指节发白" |
| "他朝刚才那位走去" | "他朝画面右侧门口的男人走去，机位在两人之间的过道" |
| "延续上一段的压抑感" | "冷调、单侧顶光、地面反光、低饱和" |
| "还是那套机甲的发光状态" | "机甲胸口能量纹逐一点亮、接缝透出蓝光" |

## 一句总纲

**写物理现象，不写形容词；用可见事实承载质感，而不是用褒义词堆质感。** 模型不认识"炫酷""炸裂""震撼"——它只认"火花飞溅、能量光纹、体积光、次表面散射"这类可被渲染的具体词。

## 1. 风格锚点（放最前，定基调）

风格锚点写在提示词**最前**，用通用风格词定下整镜基调。字数精炼，一到两个短语即可，不与后文动作搅在一起。

- 可用通用词：赛博朋克、废土、蒸汽朋克、太空歌剧、东方玄幻、神话史诗、写实军事、都市科幻；写实电影质感、高对比戏剧光、低饱和冷调、胶片颗粒。
- **禁忌（触发版权拦截，一律不用）**：虚幻引擎 5 / Unreal Engine、工业光魔 / 皮克斯 / 某导演名、某部具体电影 / 游戏名。

## 2. 材质物理（决定"真实感"）

| 目标 | 词条 |
|---|---|
| 金属 / 机甲 | PBR 金属材质、装甲反光、粗糙度、接缝螺丝、液压管线、磨损划痕 |
| 皮肤 / 人物 | 次表面散射、皮肤通透感、毛孔细纹、自然妆感 |
| 玻璃 / 透明 | 焦散、环境反射、折射、高光 |
| 织物 / 布料 | 纤维纹理、褶皱物理、垂坠感 |
| 通用 | 材质层次丰富、反射真实、不塑料 |

用法：把材质词**绑到具体物体**上写（"装甲板 PBR 金属，接缝有螺丝，边缘磨损"），不空写"材质真实"。

## 3. 光线（决定"烧钱感"）

| 类别 | 词条 |
|---|---|
| 体积感 | 体积光、丁达尔效应、空气中尘埃 / 烟雾可见 |
| 真实反射 | 全局光照、光线追踪、环境反射、地面反光 |
| 轮廓塑造 | 轮廓光、侧逆光勾勒边缘 |
| 戏剧感 | 强明暗对比、高对比光影层次 |
| 色彩基调 | 冷调 / 暖调 / 低饱和 / 高对比，统一风格 |

用法：光线写**方向和来源**（"单侧侧逆光勾勒人物轮廓，地面有环境反光"），不写"光很美"。

## 4. 特效具体化（写物理现象，不写形容词）

| 类别 | 写法 |
|---|---|
| 能量 / 光效 | 能量光纹逐一点亮、光束交错、环形冲击波、粒子光屑 |
| 爆炸 / 破坏 | 火花飞溅、碎屑飞散、烟尘扬起、地面崩裂、冲击波扩散 |
| 流体 / 天气 | 雨水滑落反光、水面涟漪、烟雾体积、蒸汽升腾 |
| 机械变形 | 装甲板展开、结构滑动重组、液压关节联动、缝隙透光 |
| 环境细节 | 漂浮微尘、湿滑地面反射、光斑、镜头光晕 |

禁忌词："炫酷特效""炸裂""震撼"——抽象形容词删除，替换为上表具体物理现象。

## 5. 镜头质感与保质感手段

**镜头质感**：大光圈浅景深、运动模糊自然、胶片颗粒细腻、电影宽幅、镜头光晕。

**保质感五条**：

1. **复杂镜头压时长**：爆炸 / 变身 / 打斗这类高算力镜头，单段压到 5–8 秒，不硬撑 10 秒以上（与 `seedance.md` 时长区间构成更严约束）。
2. **一镜一特效**：不在同一镜塞"爆炸 + 飞行 + 变身"——模型通常只保开头，后段丢特效。
3. **图生视频打底**：高精关键帧 / 参考图比纯文生稳一个量级；先出高精首帧，再图生动起来。
4. **质感词与动作分开**：前半定质感风格，后半定运镜和动作时间线，避免质感词淹没动作顺序。
5. **不靠删字凑质感**：超长时先删不进画面的环境铺陈，连续性锁面与逐字对白不删（与 `seedance.md` 正文长度纪律一致）。

## 组织顺序（命中特效镜时，方言正文顺序）

在 `seedance.md` 的"主体 + 动作 + 场景 + 光色 + 运镜 + 视觉形态 + 约束"基础上，把质感词落到对应段，并把风格锚点提到最前：

**风格锚点 → 主体 → 动作细节 → 场景（含材质物理）→ 光色（含光线）→ 运镜 → 视觉形态（颗粒 / 宽幅 / 浅景深）→ 约束**

## 证据边界与验证纪律

- 本文件是**画面措辞规范**：词条来自影视 / CG 工业通行视觉术语，作为高信息密度提示词给出，不构成对任何模型生效性的承诺。
- 每条词对具体模型的兑现程度**未被本工具箱实测**，标 `[待验证]`：首次使用时先出 1 条单镜试产，核对材质 / 光线 / 特效词是否被兑现，再批量铺开；验收首集全查、稳定后抽查（呼应 `jimeng.md` 的核对清单）。
- 本文件不重复方言规则（时长整数、参考图上限、对白 / 音效符号、三种起点互斥），冲突时以方言规则为准。
