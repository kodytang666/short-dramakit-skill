# 即梦（Jimeng）平台方言差异

> 定位：即梦是字节系消费端视频生成平台，底层模型为 Seedance `[可信：seedance-2.0 仓库 surface 列举]`。**提示词正文语法与 [seedance.md](seedance.md) 完全共用**；本文件只写平台操作差异。即梦的界面/参数随版本变动较快，以下标注 `[待验证]` 的条目**必须由创作者在生成端实际核对后回填 generation-log**，本文件不编造。

## 与 API 路线的差异总表

| 维度 | Seedance API 路线 | 即梦平台 | 证据强度 |
|---|---|---|---|
| 提示词正文 | seedance.md 方言 | **相同**（共用） | 可信 |
| 时长 4-15 秒整数 | API duration 参数 | 平台时长选择器（档位可能不同） | `[待验证]` 档位集 |
| 全模态参考槽位 | API 声明式（图/视频/音频计数） | 界面挂载槽位（数量与顺序操作） | `[待验证]` 槽位数 |
| 对白逐字语法 `{说："…"}` | `[实测]` 有效 | 平台端预期相同，**建议首镜试产验证** | `[待验证]` |
| 续接（extend） | API 模式 | 平台是否有"延长"入口与素材组合方式 | `[待验证]` |
| 画音同轨 | same_pass | 平台版本默认行为 | `[待验证]` |
| 分辨率/帧率/比例 | API 参数 | 平台选择器 | `[待验证]` |

## 创作者操作核对清单（首次使用即梦时逐项核对并回填）

1. 参考图挂载：可挂几张、顺序是否影响绑定（正文用 `@图片1` 时确认与界面顺序对应）；
2. 时长档位：可选秒数集合（是否 4-15 全档整数）；
3. 对白语法试产：取一个有台词的镜，按 seedance.md 语法出 1 条，核对成片对白是否逐字；
4. 首尾帧模式入口与"起始帧+人物图+地点图"组合是否可用；
5. 续接/延长入口（若无：按独立生成处理，尾帧仅作首帧参考）；
6. 生成结果文件的分辨率与帧率（回填供阶段七剪辑规格对齐）。

## 平台路线的写法调整（相对 API 路线）

- **无 API 参数可传**：一切约束必须写进正文（比例不对靠"竖屏 9:16 构图"式描述 + 平台选择器双保险 `[待验证]`）；
- **多次重试成本高**：优先用已验证写法（机位化站位、逐字对白语法）；诊断返修时一次只改一个变量；
- **素材序号**：即梦界面的参考图顺序即正文 `@图片N` 的 N——挂载顺序错 = 绑定错，任务清单里每镜的参考图顺序列即挂载顺序。

## 与本流水线的接口

- 生成记录（generation-log）的"参数"栏在即梦路线下记录：界面档位选择 + 版本号（便于平台升级后对账失效）；
- 验收（acceptance）中标注 `[待验证]` 的核对项（如对白逐字率）首集全查，稳定后抽查。
