# Seedance 2.0 方言（视频提示词）

> 知识来源：drama-skills 实证方言文档（小样本实测 + 火山引擎官方 API 文档）与 seedance-2.0 仓库方法论。每条规则标注证据强度：`[官方]`（API 文档）/`[实测]`（小样本 n≥3）/`[待验证]`。素材硬限制与 2.5 档位于 2026-11-07 按火山引擎官方文档复核。
> 适用：目标模型为 Seedance 2.0（API / 火山引擎 / BytePlus 等端点）。即梦的底层模型即 Seedance——提示词语法与本文一致，平台操作差异见 [jimeng.md](jimeng.md)。目标模型为 Seedance 2.5 时，在本文基础上叠加文末「Seedance 2.5 档位差异」。

## 推荐项目档案

```json
{
  "target_video_model": "seedance-2.0",
  "native_duration_seconds": {"min": 4, "max": 15},
  "supported_generation_modes": ["text", "first_frame", "first_last_frame", "reference", "extend"],
  "audio_generation": "same_pass"
}
```

`[官方]` 时长 4-15 秒（手动指定为整数）；`duration: -1` 由模型自适应选择 `[官方]`。

## 正文组织

- 顺序：**主体 + 动作细节 + 场景 + 光色 + 运镜 + 视觉形态 + 约束**。具体可见事实优先，质量词只留必要项。
- 单镜按动作先后写。一次生成含多个镜头时才用 `镜头1：``镜头2：`，每个内部镜头写清"谁、在哪、做什么、镜头怎么动"。
- **镜头序号有效，时间戳无效** `[官方]`：2.0 响应镜头顺序，不响应逐秒时间码；时长用动作顺序与相对停顿表达，秒数只作内部预算。实测小样本的切点不按两镜均分 `[实测]`——需要精确切点时评估独立生成再剪。
- 每个可辨对白事件写 `{角色＋语气＋道/说："逐字台词"}` `[实测]`，如 `{陈建国怒斥道："…"}`；**台词已是中文，只写语气（道/说/问/道等说话动词＋语气状语），不写"用中文说"、不加外语暖场**。对白全文只用一种口语语言。
- 音效写 `<声音>`，配乐写 `（音乐）` `[实测]`。
- 默认禁字幕：正文明写"全程保持无字幕，不生成对白文字叠加"且不出现任何字幕指令 `[实测]`；创作者明确开启才用字幕语法。获准的画内文字逐字写明承载面与位置。

## 站位与视线（本方言最易错的工艺）`[实测]`

- 人物前后关系**按机位写**：写"机位在桌前，她走进前景、背对镜头停在桌子这一侧，桌子在她和他之间"。**只写关系不写机位（"隔着桌子与他面对面"）在小样本九次中九次被放成同侧**；机位化改写后三次全对。
- 画面左右（"男人在画面左侧""她从右侧门口进来"）小样本中被遵循，可以写 `[实测]`。
- 视线写看着谁；对方在画外时明写"在画外、不入画"，避免模型把人补进画面 `[实测]`。

## 参考绑定与三种起点互斥 `[官方]`

- 首帧（1 图开场）、首尾帧（2 图）、全模态参考（图 0-9 张 + 视频最多 3 段 + 音频最多 3 段；视频音频各 2-15 秒且合计 ≤15 秒；**音频不能单独输入，至少 1 图或 1 视频**）——**三种起点互斥，同一次生成不能混用**。
- **素材硬限制** `[官方]`（2026-11-07 复核 API 文档）：图片单张 <30MB、请求体 ≤64MB（大文件勿用 Base64）、宽高比 [0.4, 2.5]、边长 [300, 6000]px；参考视频单个 ≤200MB、帧率 [24, 60]、宽高比与像素同图片区间；参考音频单个 ≤15MB。阶段四出的锚点图与阶段五关键帧按此核对，超限先压缩再挂载。
- **写实人脸素材拦截** `[官方]`：2.0/2.5 均不支持直接上传含真人人脸的参考图/视频。本管线的 AI 生成锚点图天然规避；创作者若想用真人照片/实拍视频做参考会被系统拦截。官方三种替代：本账号近 30 天内由 Seedance 生成的人脸视频可作输入素材（续接场景适用，见下节）、预置虚拟人像（asset:// 素材 ID）、已授权真人素材。
- "起始帧 + 人物图 + 地点图"只能走全模态参考，正文写明"@图片1 作为首帧" `[官方]`；要求开场严格对上某图时用首帧模式，人物地点靠该图本身承载。
- **每次提及素材都重复绑定**：`人物 @图片1`、`参考 @视频1 的运镜`、`参考 @音频1 的音色` `[实测]`——不要只开头列清单。
- 参考图 9 张是**上限不是目标**：每张在本镜要有具体职责（起始帧/正在说话或动作的人物/必须认得的道具/地点）。实测中挂 7 张与 3 张画质无差，但**没挂图的道具在交接中变形**（文件夹变夹板，3 次中 2 次）`[实测]`——必须认得的道具要挂图，不能只靠文字。
- 超上限取舍顺序：起始帧 > 正在说话或做主要动作的人物 > 必须认得出的道具 > 地点 > 其余入画人物 > 定调图；放弃的写明，必要事实进正文。

## 续接（extend）`[官方][实测]`

- 接着上一段**实际结果**生成时：写"向后延长 @视频1"，并用 `@图片1` 指向该视频的**实际尾帧**（新段开场的可见状态）。
- **向前延长** `[官方]`：需要补前史（回溯开场）时写"向前延长 @视频1"，触发关键词为「向前/向后延长、延续、续写」；延长任务锁定输出宽高比与原视频一致（参数 ratio 取 adaptive），时长可自定义；官方建议输入/输出均用 mov 格式以获得最佳声画衔接。
- 续接含写实人脸的成片素材：本账号近 30 天内由 Seedance 生成的含人脸视频可作输入 `[官方]`——**续接任务宜在生成后 30 天内完成**，超期素材按"真人脸拦截"处理，改走尾帧图路线。
- 两样真实输入（实际视频 + 实际尾帧）缺一不宣称连续生成；不拿计划尾帧或文字描述冒充。
- 素材序号来自当次任务的真实绑定，不沿用文档 REF ID 猜序号 `[实测]`。

## 正文长度 `[官方建议 + 实测]`

- 官方建议中文 ≤500 字（过长可能只抓重点）。实测约 800 字不丢后段细节，但**随手写的环境铺陈会进画面**（猫、出租车被画出来，甚至硬切到正文描写的公交站）`[实测]`。
- 控制方法：**只写这一镜需要被看见的东西**，不靠删字凑数。超长先删不进画面的环境铺陈；**连续性锁面与逐字对白不删**。文生无图承载外观，锚点与锁面写在正文里是必要代价。

## 边界纪律

- 镜头时长进入本阶段前已落在 4-15 秒（分镜责任）；短于 4 秒的叙事动作并入 ≥4 秒镜头且终点为可见 hold，长于 15 秒回阶段五拆镜 `[官方]`。
- 同轨音画不代表语速必然容得下原文——对白仍按发声窗口复核（字数 ÷ 4.5 字/秒）。
- 画音同次生成（same_pass）：声音写法直接影响成片声音 `[官方]`。

## 未知能力处理

本方言文件未覆盖的参数/写法（分辨率档位、帧率、seed、首帧强度等）：**不在提示词里编造**，按"未验证"处理——正文只用本文已验证语法；平台参数由创作者在生成端核对后回填 generation-log 的"参数"栏 `[待验证]`。

## Seedance 2.5 档位差异（2026-11-07 官方文档复核，全部 `[官方]`，未实测）

目标模型声明为 seedance-2.5 时在本文基础上下列覆盖生效；未声明的项仍按 2.0 执行：

- **素材上限扩大**：全模态参考图 1-30 张（4K 内）、参考视频最多 10 段（合计 ≤30s）、参考音频最多 10 段（合计 ≤30s），合计 ≤50 素材；**音频可单独输入**（无需搭配图/视频）。
- **单段 30 秒直出**：时长区间上限从 15s 提至 30s——分镜镜长 >15s 时优先评估 2.5 直出而非拆镜，但长段稳定性下降，仍以分镜闭合点拆镜为默认。
- **锁定/无锁定任务分类**（2.0 无此区分）：编辑、首尾帧、延长为**锁定任务**——输出宽高比甚至时长被输入素材锁死（编辑任务 duration 必须为 -1；受输入帧处理影响输出时长与输入可能有 ≤0.3s 差异）；参考类任务无锁定，宽高/时长可自定义。编 MOTION 时按任务类型预判哪些参数不可指定。
- **时间戳立场与 2.0 不同**：2.5 官方指南**推荐**用时间戳理清剧情（以 1 秒为单位、区间连续不跳段如「0-3 秒…3-7 秒…7-15 秒」、单点事件如「第 2 秒…」）；但**不建议**用时间戳控制频率频次（"一秒摇头 3 次"），区间内容过多会导致过度剪切。2.0 的"镜头序号有效、时间戳无效"结论不变；2.5 正文可按上述官方约束使用时间区间，精确切点仍不可当作执行保证。
- **样片模式（draft）**：API 两步走——先出 Draft 样片确认，再基于样片任务 ID 出正式视频（样片 ID 有效期 7 天）。适合批次内高不确定镜先试样，省钱验证写法；即梦平台端是否有对应入口 `[待验证]`。
- 提示词语言扩展至 10 余种（中文建议仍 ≤500 字不变）。

## 通用降级路径（无方言文件的其他模型）

目标模型无方言文件时：MOTION 状态链按自然语言直写（主体/动作/场景/光色/运镜/约束），对白用引号逐字，参考图用途在正文文字声明；标"未验证方言，生成前核对目标模型文档"。**不得套用 Seedance 的时长、参考上限、符号语法。**
