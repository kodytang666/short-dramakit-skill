# 失败诊断与返修

> 症状 → 可能原因 → 首修动作。返修纪律：**一次只改一个变量**；先改正文写法，后动参考图，最后才加负面排除。同一镜两次返修仍失败 → 上报回上游（分镜/资产/关键帧）。返修意见遵循**批评三轴**：指得出具体位置（GEN/秒段/画面处）、发现一处先扫同批次同类镜、每条修改必须具体可执行（给不出→标"待排查"，不占返修轮次）。

| 症状 | 可能原因 | 首修动作 | 上游升级信号 |
|---|---|---|---|
| 人物脸/身份漂移 | 参考图职责不清或未挂锚点图 | 该人物锚点图入槽 + 正文重复绑定"人物 @图片N" | 锚点图本身多人/低质 → 阶段四重出 |
| 动作没做完/被压缩 | 一镜动作量超载 | 删并次要动作，只留状态链必需动作 | 仍装不下 → 回阶段五拆镜 |
| 台词缺失/改词/口型乱 | 对白未用方言逐字语法；发声窗口不足 | 按 `{角色＋语气＋道/说："逐字"}` 重写（带语气，不写"用中文说"）；字数÷4.5 复核窗口 | 台词过长 → 回阶段五调镜长 |
| 镜头开头跳切/与上一镜不接 | 该续接的段走了独立生成；或尾帧未用实际帧 | 改"向后延长 @视频1"+ 实际尾帧 @图片1 | 平台无续接入口 → 独立生成+尾帧作首帧 |
| 人物位置与站位块不符 | 站位只写关系未写机位 | 机位化改写（"机位在__，__在前景背对镜头，__之间隔着__"） | 轴线根本冲突 → 回阶段五站位块 |
| 画面出现正文没写的东西（多余人物/物体/场景跳转） | 正文环境铺陈过多 | 删不进画面的环境描述（实测：随手写的猫/出租车会进画面） | — |
| 字幕/对白文字叠加出现 | 未明写禁字幕 | 正文加"全程保持无字幕，不生成对白文字叠加" | — |
| 画内文字乱码 | 模型生成可读文字能力弱 `[待验证]` | 文字改为后期叠加（回阶段七计划），关键帧画面留白承载位 | — |
| 运镜没执行/多余运镜 | 运镜描述太弱或与动作争抢注意力 | 运镜写行为+终点（"缓慢推近至__，停在__"）；无理由运镜删掉 | — |
| 多人同框交互崩坏（融合/穿模/排队挨打） | 多主体交互超出生成能力 `[待验证]` | 拆回合（一主体一动作）；同框减到 ≤3 人 | 回阶段五按回合制重新切镜 |
| 整体泛化/像模板/廉价感 | 正文全是质量词空话 | 换成具体可见事实（主体/动作/光色/构图）；删"电影感/高清/杰作"类词 | — |
| 画质模糊/闪烁/抖动 | 平台档位或分辨率问题 `[待验证]` | 核对平台分辨率档位；正文降低运动复杂度 | — |
| 生成被拒/内容拦截 | 内容触发平台审核 | 按"保留戏剧、移除提示词"改写（武器→后果，镜头外处理）；被拒内容与创作者确认尺度边界 | 尺度约束不清 → 回阶段一简报边界 |

## 返修记录格式

```
## 返修 R-EP001-SC001-SHOT05-v2
- 症状：
- 定位（GEN/秒段/画面具体位置）：
- 诊断（对照上表）：
- 修改（一次一变量）：
- 同类扫描（同批次同写法其余镜已查/有相同问题列入）：
- 结果：通过 / 再返修（→ 下一变量）/ 升级上游 / 待排查（给不出修法，不占轮次）
```
