## 提交前预检（状态改"就绪"前逐行核对，不过不提交）

1. 参考图文件**实际在手**（"已确认"≠文件已下载到本地；缺文件按阻塞处理）；
2. 方言正文无占位符、无流程语言（复制即用）；
3. 时长落在模型原生区间；
4. 平台/凭证可用（本 Skill 不持凭证——由创作者确认 API key 或平台登录态）；
5. 目标行属于本批配置快照覆盖的范围（跨快照的任务移入新批）；
6. 复用候选列已核对（旧产物与新版 MOTION 状态链一致）；
7. 本批预算已确认（见上节，未确认整批不提交）。

预检不过的行保持"阻塞"并写明原因，不进入本批提交。

## 使用说明（给创作者的操作单）

1. 按行在生成端执行：挂参考图（顺序与本表一致）→ 粘贴方言正文 → 设时长 → 生成；
2. 每次生成后回填 [generation-log.md](generation-log.md)；
3. 结果文件命名：`{任务ID}-v{n}.mp4`；
4. 续接任务必须等上一段实际视频产出后再提交。
