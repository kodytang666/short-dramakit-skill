# 短剧剧本创作

把单集六字段（进入状态/钩子/追求/转折兑现/出去压力/交接事实）写成**可表演、可拍摄、每场有用**的剧本。剧本是台词与动作的唯一权威来源：下游字幕逐字取自这里、TTS 原句取自这里、剪辑的叙事核对依据这里。

## 核心立场

1. **剧本管戏，分镜管拍**：剧本只写人物做什么说什么，不写镜头、机位、提示词。
2. **每场有用，每句可演**：场次要改变信息/权力/关系/情绪/物理状态/风险（否则删或并）；台词要能转成演员的一个动作或表情（转不成的删或改成动作）。
3. **动作是 AI 要生成的画面**：动作行只写"常见动作"（走路、拿起、坐下、递出——模型见过千万次的）；"睫毛颤了一下""手指微不可察地收紧"这类精巧微动作在生成端必崩，改写成可见的大动作或删掉。剧本阶段就为阶段六把关。
4. **时长是预算不是估算**：写之前知道这集有多少秒，写完折算，超了砍动作节拍先于砍台词，欠了加冲突不加寒暄。
5. **上游权威**：分集大纲的六字段与故事圣经的人物（目标/筹码/底线/语言指纹）是硬输入；发现结构问题记 DEC 回阶段二，不在剧本里悄悄改故事。

## 剧本格式（唯一标准，下游机械依赖）

```markdown
# EP001 集名

## EP001-SC001 内 · 苏家宴会厅 · 夜 · 宴会

[场景描述一行：可见的空间状态与光线，不含镜头语言]

林凡站在长桌末端，手里捏着一份离婚协议。
（动作行：主语 + 常见动作 + 对象/方向。一行一拍，2.5 秒/拍。）

岳母（把酒杯重重放下）：好，你今天签了，就再也不是苏家的人！
（台词行：角色（表演提示）：台词。单句一口气 ≤35 字。）

林凡：妈，我签。
（无提示时可省略括号。）

[VO] 林凡（内心）：三年了，账该清了。
（[VO] 画外音、[OS] 画外声源、[SFX] 音效、[画面文字] 画内可读文字、[转场] 转场方式、[连续性] 易丢失状态交接。）

> [连续性] 上集：林凡左手缠着纱布（EP002 需继承）。
```

规则：
- 场次标题 `## EPxxx-SCxxx 内/外 · 地点 · 时间 · 天气/光态`——SC 编号全局稳定，删场不补位、留痕。
- 动作行与台词行**严格分离**：动作行出现引号对白即违规（对白必须在台词行）。
- 每场至少一行**场景描述** + 至少一个**动作节拍**（纯对白的场是广播剧，AI 生成没有画面可写）。
- `[画面文字]` 单独成行写明"载体 + 文字内容"（手机屏幕/横幅/账本），这是阶段七后期叠加的依据。
- `[连续性]` 只交接"由前文动作建立、又容易在下游丢失"的状态（伤势/持物/湿污/知识状态），不复述正文已清楚的事。

## 工作流

1. **接收上游**：读本集六字段 + 相关人物档案（目标/筹码/底线/语言指纹）+ 上一集的出去状态与交接事实。上游缺失时：有故事大纲无分集 → 先要求补分集（阶段二职责）；只有梗概 → 建最小单集契约（六字段各一句话）再写，标注"轻量上游"。
2. **预算时长**：单集秒数 = 目标时长 × 60。预算 = 台词字数 ÷ 4.5（字/秒）+ 动作拍数 × 2.5（秒/拍）+ 停顿余量（基准：每个场景 3 秒过场 + 台词间停顿按句数 × 0.5 秒；写完按此折算并在自检记录里给出数字）。参数可按项目调整并记录在剧本头部 `params` 注释。倒推本集节拍配额（如 120 秒 ≈ 台词 270 字 + 动作 20 拍的可调配比）。**单场时长上限**：任何一场不超过单集预算的 60%——超了先拆场（拆场不需要回上游，属剧本层职责）。
3. **排节拍**：在上下文里排"因为—行动—结果—下一股压力"的节拍链，不落盘节拍表；每场明确唯一功能与场尾状态，并先定文风温度档（1–5，见"文风温度"节）。
4. **钩子前置**：本集钩子必须在**前 3 拍内**以可见场面兑现（第一场就是钩子的具象，不是铺垫）；结尾一拍是悬念或出去压力的落纸。
5. **逐场写**：按格式写正文；对白在争取/回避/试探/逼迫/重新定义关系，不解释已演清的机制；"谁的话像谁"——按圣经的语言指纹写（句形/口头禅/禁词/发火方式）。
6. **静默反查**：写完整集只读剧本自查——观众能否接收到本集承诺？人物行动有因果吗？题材语气一致吗？自检若增添了输入没有要求的机关（新人物/新规则/新道具），撤去。
7. **量化自检**（下方 11 项）→ 修订。
8. **同步产出**：场次表、台词本、时长预算更新；剧本改动后三件同步重生成。
9. **停靠**：每批（≤3 集）成稿后交创作者确认（"一次跑完"可豁免，标注之）。

## 量化自检（11 项，成稿必查）

| # | 门 | 标准 |
|---|---|---|
| Q1 | 时长预算 | 折算时长在目标 ±15% 内；参数记录 |
| Q2 | 单句长度 | 台词单句 ≤35 字（一口气能说完） |
| Q3 | 说话人合法 | 台词行说话人 ∈ 本场出场人物或标 [VO]/[OS]，名字与圣经一致 |
| Q4 | 钩子位置 | 钩子在前 3 拍内以可见场面兑现 |
| Q5 | 结尾悬念 | 最后一场落纸"出去压力/悬念"，不写"本集完" |
| Q6 | 每场有画面 | 每场 ≥1 场景描述行 + ≥1 动作节拍 |
| Q7 | 动作行纯度 | 动作行不混引号对白；无精巧微动作（常见动作原则） |
| Q8 | 爽点认领 | 大纲标注的本集爽点有对应场次认领（对照节奏表） |
| Q9 | 角色对账 | 出场人物都在圣经有档案；新增人物必须先回阶段二补 CHAR。**豁免**：无台词的功能性群演（"宾客们""警员"等群体背景）不入圣经，但须在剧本中用称呼标签写明，不得给群演个体加名字 |
| Q10 | 场景对账 | 出现场景都在圣经有 LOC 且用途集号覆盖本集；LOC 登记不含本集时补记用途（本阶段可改用途字段，不新增 LOC）；新场景先回阶段二 |
| Q11 | 台词尺度 | 台词不含直白脏话（"你他妈""妈的""操""TMD""你娘的""X你妈"等会被平台打回或需消音的词），一律用委婉表达（"你特喵的""我去""靠""淦"等）或改写为动作/语气（拍桌、瞪眼、青筋、长叹）代替爆粗；人物再愤怒也不允许"出口成脏"直给 |
| + | 去AI味 | 删解释性对白（"你是说……"复述）、删总结陈词、删同义反复；留下的每句都有人在做事 |

## 文风温度（场景情绪档）

每场先定一个**温度档**再动笔，五档决定台词节奏与动作密度；先定档后写，避免全集一个劲。

| 档 | 用途 | 台词节奏 | 动作密度 |
|---|---|---|---|
| 1 平静日常 | 铺垫/日常/静默 | 句长偏长、平顺 | 低 |
| 2 轻推进 | 常规对白/情节推进 | 中长为主偶夹短句 | 中 |
| 3 紧张对峙 | 关键对白/逼迫/试探 | 短中交替（8–20 字） | 中高 |
| 4 冲突爆发 | 打脸/反转/情绪破裂 | 短句为主（5–15 字） | 高 |
| 5 全剧顶点 | 终极对峙/大爆点 | 极短 + 气口断裂（≤10 字） | 极高 |

- **升级不可跳档**：1↔2↔3 自然，3→4 需冲突爆发，4→5 需极端情境；禁止 1 直跳 4/5。
- **单句 ≤35 字仍是硬关口**（TTS 气口），高温档靠"句长错落 + 停顿"拉紧，不靠写长句。
- 一场一个主档；结尾钩子常比场头高一档，留下升温感。

## 对白手艺与动作节拍

- **动作节拍当说话标签**：连续 4 句纯对白、中间无动作行/表演提示，是"对话墙"——在两句对白间插一句可见动作行（放下杯子/把合同拍在桌上），既标出谁在说、又给阶段六画面。
- **表演提示用可见动作或表情，不用副词**：`（提高声音）`✓ `（把酒杯重重放下）`✓；`（坚定地）（愤怒地）（意味深长地）`✗——改成动作行或删。
- **遮名辨人**：通读台词遮掉说话人名，若分不出是谁在说，回阶段二补语言指纹（句形/口头禅/禁词/发火方式）。
- **情绪不直呼**：不写"她很难过"，写她做了什么（捏紧手腕/把脸别过去）。
- **动作可生成硬约束优先**：动作行只写阶段六见过的常见大动作；感官比喻（"喉咙像卡了湿棉花球"）是小说语言，剧本不承载，删或改成大动作。

## 去 AI 味专项（写完通读一遍，逐条扫）

1. 删复述性接话（"你的意思是说""原来如此，所以……"）——观众已听到，不必重播。
2. 删对白报时/报天气/自我介绍（"现在是凌晨三点，我是市局法医苏眉"）——能演的不说。
3. 删同义反复——两句意思重复的台词留一句。
4. 删解释性对白复述已演清的机制（"他这是要下毒"——用动作演，不用嘴说）。
5. 情绪不直呼（"我很愤怒"→ 写他做了什么：拍桌/摔杯/青筋/长叹）。
6. 删空泛加强词与套话（"非常/极其/深深地/缓缓地""展现出/彰显出/无与伦比"）。
7. 拆"观点—解释—总结"三段式对白——散开、跳接，别像作文。
8. 破"完美信息传递"——台词要有半句、吞字、岔开，别把话说透。
9. 换同一情绪模板重复（一章三次"心一紧"）——换身体反应，别反复用一个词。
10. 台词带身份口癖——按圣经"语言指纹"字段校对（遮名可辨）。
11. 人人一个说话模子也是 AI 味——不同角色句长/口癖/发火方式要有区分。
12. 总结陈词、拔高升华（"这就是……的意义啊"）一律删。
13. 台词过审（平台红线）：不写直白脏话（"你他妈/操/TMD/你娘的"等），改委婉（"你特喵的/我去/靠/玩呢"）或落到动作；宁可删脏字不能爆粗。

## 修订规则

- 局部修订保留无关段落与 SC 编号；删场留痕（`<!-- SC003 已删：并入 SC002 -->`）。
- 改台词同步台词本；改场同步场次表；改时长同步预算。
- 上游矛盾（发现大纲冲突/人物行为越线）：小冲突在剧本内消化并记 DEC 备注；结构性冲突（改集数结构/改引擎级设定/单场超集预算 60% 无法拆场）停笔报创作者，回阶段二或阶段一。
- 用户提出的**镜头调度类要求**（"一镜到底""手持跟拍"等）：剧本不承载，记 DEC 移交阶段五；剧本只保证场面可被这样拍。
- 豁免停靠标注位置：剧本 frontmatter 加 `stops: waived` 行（全局统一，无第三态）。
- 人物"语言指纹"依据：优先圣经的"语言指纹"字段；该字段缺失时从小传与一句话定位推断语感，并在自检 Q3 行注明"语言指纹由小传推断"（同时建议上游补字段——此为阶段二圣经模板的已知扩展点）。

## 边界

- 不写镜头/景别/运镜/提示词（阶段五六）；
- 不改分集结构、不加人物、不加场景（上游职责，需求走 DEC）；
- 不做视觉设定与资产（阶段四）。
