# 短剧故事开发与小说改编

把一个立项（或一个点子/一部小说）变成**能持续制造选择、代价与状态变化**的故事系统，并落成下游（剧本创作）可以直接使用的六份文档。

## 核心立场

1. **故事是状态机，不是事件堆**：每集必须完成"可验证进入状态 → 压力 → 选择与反制 → 部分回报 → 新压力 → 可验证出去状态"的循环；分集边界对应必要的状态变化。
2. **砍在前，写在后**：改编先砍线、合人、收场景、排爽点，骨架拍板后才写分集——快版错了只损失一轮骨架，分集写完才发现方向错，全废。
3. **上游权威**：阶段一制作简报的"已定事实"不得推翻；冲突时记 DEC 决策回阶段一重审，不在本阶段悄悄改。
4. **归并是候选不是资产**：原著人物归并只是故事候选；真正的视觉资产（形象/参考图）在阶段四从已确认剧本建立。
5. **量化门 + 因果判断双轨**：可数的用数量门卡（角色数/场景数/爽点间隔），不可数的（升级是否真实）用因果链自检；数字配方永远不能替代因果判断。

## 入口分流

| 入口 | 判断 | 动作 |
|---|---|---|
| A-简报开发 | 有阶段一制作简报 | 读简报；已定事实为硬约束；直接进入骨架 |
| A2-裸点子 | 无简报、无原著，只有点子 | 一次问全必要参数（题材定位/规模/平台倾向/尺度边界）；问过仍沉默或不给就按建议值标注后继续 |
| B-小说改编 | 有小说（原文/简介+梗概） | 按 [references/adaptation.md](references/adaptation.md) 走五步改编法 |
| C-续跑 | 已有本阶段产物 | 读已有文档，从断点继续；已拍板的骨架不重推 |

**体量双向规则**：素材撑不起目标集数时（故事单元自然支撑集数 < 目标 70%），先做缺口测算并停靠给方案（降集数 / 借壳+结构化扩容：记忆恢复引擎、反派梯队、副线增密、前史分层——扩容内容全部标 `add` 并注明扩容来源）。**add 集数占比超过 40% 时必须告警**：此时已接近原创，建议改改编档位为借壳或直接回阶段一重新立项。素材超体量时按砍线处理（见 adaptation.md）。

## B 入口：五步改编法

按 [references/adaptation.md](references/adaptation.md) 执行，顺序即方法：

1. **原文登记与覆盖率声明**：读多少、依据什么材料，报告首行声明（"读了 N 章中的 M 章 x%，基于原文/梗概"）；未读内容不引用、不脑补（简介+梗概降级档：判定全部标 `[推断]`，建议阶段二末提供原文复核）。
2. **功能提取**：逐章/逐单元提取戏剧功能（该段改变了谁的选择、信息、权力或关系）与载体（可见行动/对白 vs 心理叙述）；四类判定（`screen_ready`/`needs_carrier`/`prose_only`/`ai_hard`，继承阶段一）。
3. **聚合**：故事单元（有始有终，记录进入状态/冲突/代价/出去状态）+ 爽点表（按观众收益排名，标注埋设与兑现位置）+ 桥段统计（同一桥段出现次数——是卖点还是拖沓要能数出来）。

## 快版骨架 → ⛔ 停靠 1：骨架拍板

**B 入口**按五步法的砍线/合人/收场景/排爽点产出快版骨架；**A 入口**直接产出：主线一句话、对抗机制、大爆点位置、主角组构成。

**必须停靠**，把三件事摆给创作者拍板：**砍了哪条线、合了哪些人、大爆点落在第几集**（A 入口为：主线方向、主角组、大爆点位）。不点头不写分集。创作者声明"一次跑完"、或已问过一次后沉默/明确要求继续时豁免停靠，但骨架仍须成文，拍板结果标"未停靠自动确认"；豁免停靠的项目出现体量缺口告警或 add>40% 时，停靠 2 必须执行（不可豁免）。

拍板通过的骨架落进故事大纲；未通过的调整进骨架重跑。所有取舍记 DEC。

## 故事引擎

写故事大纲前先过**引擎六问**（详见 [references/story-engine.md](references/story-engine.md)）：

1. 压力如何出现，主角通常如何应对？
2. 对手或系统如何反制，主角为何不能轻易退出？
3. 每轮冲突改变什么（而不是怎样重复得更响）？
4. 人物各自的目标、筹码、底线和关系压力？
5. 哪种人物转变或事实揭开会终结这个引擎（长线终止条件）？
6. 视觉、声音、场景规模与内容边界是什么？

引擎六问的答案写进故事大纲的"故事引擎"章；第 4 问的答案展开成故事圣经的人物档案。

## 故事圣经

按 [templates/story-bible.md](templates/story-bible.md) 写：

- **人物档案**（`CHAR-` ID）：分档（lead 主角组 / support 重要配角 / functional 功能角色）、一句话定位、小传（≤200 字）、**灵魂字段**（3–5 条不可破行为铁则——"在 X 下必 Y／任何情况不 Z"；一旦写入全剧任何情节不可破，剧情要破就改剧情或重写铁则）、**语言指纹**（句形／口头禅／禁词／发火方式，遮名可辨，供阶段三写台词校对；lead/support 必填、functional 免）、目标/筹码/底线、**弧光节点**（起点信念 → 至少 2 次压力测试 → 转变触发 → 终点状态；functional 角色不写弧光）、关系（与谁、何种压力）。
- 分档上限走量化门（lead ≤5、support ≤10、functional ≤10）。**分档由骨架拍板决定，后续阶段不推翻**；真需要改，回本阶段重拍板。
- **叙事道具**（`PROP-` ID）：判据是"它坏了、丢了、被换掉，剧情会不会塌"；每件写功能与托起的爽点/集号；上限 8 件。
- **主场景**（`LOC-` ID）：上限随集数动态（4+⌈集数/10⌉，夹 5-15）；一次性场景要么砍掉、要么写复用方案。
- **世界观规则**（超出现实的硬设定，每条可验证）。
- **时间线**（故事内时间，跨集连续性用）。
- **伏笔-兑现登记簿**（`FORE-` ID）：埋设集、兑现集、内容；未兑现伏笔是审查项。

## 分集大纲

按 [templates/episode-map.md](templates/episode-map.md)，每集六字段 + 三栏：

| 字段 | 说明 |
|---|---|
| 进入状态 | 上集留下的位置/持物/伤势/知情/欠情/未决动作——足以让本集第一场不凭空出现 |
| 当集钩子 | 观众能立即理解的未稳定局面（七形态见 story-engine.md）；连接本集目标，无因果的只是装饰 |
| 当集追求 | 人物想让谁/什么在本集结束前发生怎样的变化；反对力量有自己的目标与筹码 |
| 转折与兑现 | 方向性转折（原计划失效）+ 本集兑现的承诺（不能一条都不兑现，只留钩子的集观众第三集就停） |
| 出去压力 | 具体的新决定、危险或问题 |
| 交接事实 | 下一集必须继承的事实清单 |

- 第 1 集必须完成**收益入口 vs 冷开**决策（后文更强的高光可提前；决策记 DEC）。
- 集数多时分批写（每批 ≤10 集），批间不停靠（除非发现骨架问题）。
- 改编项目：分集从故事单元切，不按章号或字数平均切；章与集不是 1:1。

## 情节节奏表

按 [templates/rhythm-table.md](templates/rhythm-table.md)：每集一行（集号/钩子类型/主要爽点/情绪值 1-5/大爆点标记/卡点建议）。写完与分集大纲逐行对账；分批书写时，节奏表对已写集逐行对账，未写集标"规划值"并在该批次完成时补齐对账。情绪值基准：1=平缓铺垫，3=常规冲突，5=峰值爆点（相对档，全集标定时保持同一把尺）。

## 连续性设定文档

按 [templates/continuity.md](templates/continuity.md)：世界观硬规则、时间线、地理关系、伏笔簿（与圣经同步）、跨集不变的设定（阶段四的连续性锁从这里生长）。

## ⛔ 停靠 2：成稿确认

全部文档完成 → 运行 [references/quality-gates.md](references/quality-gates.md) 的 9 项量化门 → 向创作者汇报：集数规模、主角组/配角量、爽点分布、大爆点位置、量化门结果、最大的连续性风险。等待确认后标记 `status: approved`。

## 编号与版本

`CHAR-` `PROP-` `LOC-` `EP-` `FORE-` `DEC-`；文档 frontmatter：`project_id / doc_type / version / date / status`。上游修改（简报已定事实变更）→ 相关文档 version+1 并在变更记录注明；分集改动必须同步节奏表与伏笔簿。

## 自检清单（成稿前逐条核对）

1. 引擎六问完整且第 3 问（每轮改变什么）不是重复描述；
2. 9 项量化门全部通过（见 quality-gates.md，阈值可参数化但必须有值）；
3. 每集六字段完整、进出状态可交接（上集出去=下集进入）、每集至少兑现一项承诺；
4. 首集有钩子 + 收益入口/冷开决策已记录；
5. 伏笔簿内每个 FORE 有埋设与兑现集（或标注"系列性伏笔，预计第 X 集兑现"）；
6. 人物弧光有起止与至少 2 次压力测试节点；分档不超上限；lead/support 灵魂字段 3–5 条与语言指纹齐（functional 免）；
7. B 入口：四类判定比例与分母、覆盖率声明、关键取舍附原文最短引文；
8. 与阶段一简报无冲突（有冲突的已走 DEC 回溯）；
9. 改编新增内容均标注 `add`（原著没有的登记为新增）。

## 常见错误与纠正

| 错误 | 纠正 |
|---|---|
| 未拍板就写全部分集 | 停靠 1 不可跳（除"一次跑完"豁免） |
| 分集按章号/字数平均切 | 按故事单元与爽点分布切 |
| 每集只留钩子不兑现 | 每集必须兑现部分承诺 |
| 引擎答成"冲突越来越激烈" | 第 3 问要的是状态改变，不是响度 |
| 人物小传抄原著外貌描写 | 小传写目标/筹码/底线/弧光；外貌归阶段四 |
| 伏笔埋了不登记 | FORE 簿是硬产出；不登记的伏笔视为没埋 |
| 用数字配方解释剧情质量 | 数字门卡下限，质量靠因果链 |

## 边界

- 不写带台词的完整剧本（阶段三）；分集大纲的"钩子"栏允许一句台词意向但不写对白。
- 不建视觉资产、不写参考图（阶段四）；圣经只留"画面代称"占位。
- 不做分镜与镜头语言（阶段五）。
- 原著分析不复制原文段落，引用限最短必要片段。
