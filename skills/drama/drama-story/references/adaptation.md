# 五步改编法（小说 → 短剧故事系统）

## 顺序就是方法

**砍线 → 合人 → 收场景 → 排爽点 → 收道具**。顺序不是随意的：道具排在爽点之后，因为"叙事道具"的判据是它托起哪个爽点；场景收在合人之后，因为砍掉的人物带走他们的场景。

### 1. 砍线

短剧只装得下**一条主线 + 至多一条副线**。原著的其他线砍掉，每条写砍因（`adaptation.cut`）。忠实档改编一条不砍会被体量门拦住——40 集装不下 150 章的支线，这是物理事实。

砍完补一句结论：砍线后全剧终点是什么（"这意味着：全剧终点是 XX 而不是 YY"）。

### 2. 合人

功能重复的角色合成一张脸（两个报信的→一个；两个反派打手→一个），合并记录 `from`（由原著谁+谁合并）。然后**分档**：

| 档 | 上限 | 判据 |
|---|---|---|
| lead（主角组） | ≤5 | 有完整转变弧、贯穿全剧 |
| support（重要配角） | ≤10 | 有名字、有独立目标或反制力 |
| functional（功能角色） | ≤10 | 占脸不占名（"急诊医生"式称呼），不写弧光 |

无名背景人不进表。合人后联动检查：分集不能引用被合并删除的原著人物名。

### 3. 收场景

主场景上限随集数动态：`4 + ⌈集数/10⌉`，夹在 5-15（60 集→10 个）。AI 短剧的场景是生成的没有搭景钱，可以比实拍宽松——多开几个景换观赏性划算，但每个景都要在阶段四生成参考图，上限存在的意义是控制资产总量。

原著一次性场景：要么砍（戏移到现有场景），要么写复用方案（换时段/天气/陈设改出来）。

### 4. 排爽点

先定 **major（大爆点）** 落在哪几集，再用 **minor** 填缝。硬规则：

- 相邻 major 间隔 ≤ 3 集（悬疑单元剧可放宽到 4-5，作为参数记录）；
- 开头结尾无真空（第 1 集有钩子、最后一集是终局兑现不是新爆点）；
- 最早的 major 不在最后一集；
- 爽点类型跟着题材走（女频打脸与男频战神不是一种爽）——对照阶段一题材卡的爽点字段。

### 5. 收道具

叙事道具上限 8 件，与主角数量一个量级。**判据一句话：它坏了、丢了、被换掉，剧情会不会塌。** 会塌是叙事道具（皮箱、那封信）；不会塌是场景陈设（挂灯、茶碗），归阶段四场景资产管。

每件写 `function`（承载什么戏）与托起的爽点/集号。填不出 function 的一律不收——填不出的不是道具，是背景。

## 覆盖率纪律（继承并强化阶段一规则）

1. 报告/大纲首行声明材料基础：`> 本改编基于：原文全文 / 抽样 N 章中的 M 章（x%）/ 简介与 K 章梗概 / 仅梗概约 N 字（无原文）。未读内容未参与判断。`
2. 关键取舍（砍线、合人、改动）附**原文最短引文**作证据（`evidence` 字段）——大纲要能指回原文，不是凭印象改编。**add（新增）内容的证据是扩容来源说明**（记忆恢复引擎/反派梯队/副线/前史等结构化来源 + DEC 决策），不是原文引文。
3. 简介与梗概降级档：全部判定标 `[推断]`，成稿前建议创作者提供原文复核关键章节；禁止用对同题材小说的记忆补细节。
4. 原文修改后：声明失效，受影响部分重做；不比对字节，靠改文者声明。

## 体量双向规则

- **砍向（素材超体量）**：按上文五步砍线收场景，砍线记录写明"砍掉的是哪类体量"。
- **扩向（素材撑不起目标集数）**：先测缺口——把功能提取得到的故事单元按"能自然支撑的集数"加总，低于目标集数 70% 时停靠给方案：降集数，或借壳档 + 结构化扩容（记忆恢复引擎、反派梯队、副线增密、前史分层）。扩容内容全部标 `add`；**add 集数占比 >40% 时告警**（接近原创，建议改档位或回阶段一重新立项），告警项目停靠 2 不可豁免。

## 四类判定的改编处置

| 判定 | 处置 |
|---|---|
| screen_ready | 直接进入故事单元 |
| needs_carrier | 每个写明：原载体/新载体（可见行动/物证/空间关系/对白策略/第三方反应）/保住什么/失去什么——写不出新载体的降级 |
| prose_only | 明确放弃并写进砍线记录（放弃的是什么快感） |
| ai_hard | 保留的折算制作规模（分批/替代调度），放弃的记 DEC |

**不要把 prose_only 悄悄改成 needs_carrier**——假装能拍的代价在分镜/生成阶段暴露，那时整条链都建在它上面。

## 改编幅度三档（继承阶段一）

忠实 / 抽核 / 借壳。骨架拍板时明确档位；档位决定砍线的激进度。新增内容（原著没有的）一律标注 `add` 并在故事大纲中列明。
