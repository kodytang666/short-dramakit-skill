# 故事引擎、钩子与单集契约

## 引擎六问（故事大纲的发动机）

写任何分集之前回答，答案写进故事大纲"故事引擎"章：

1. **压力如何出现，主角通常如何应对？**——压力的常态形态（每集开机的默认冲突）。
2. **对手或系统如何反制，主角为何不能轻易退出？**——没有"不能退出"，故事随时可以大结局。
3. **每轮冲突改变什么？**——权力/信息/关系/暴露/资源/时间/代价的状态改变；答成"冲突更激烈了"是错的，那是响度不是改变。
4. **人物各自的目标、筹码、底线和关系压力？**——主要人物每人一行，写进圣经人物档案。
5. **哪种人物转变或事实揭开会终结这个引擎？**——长线终止条件 = 全剧终局的来源。
6. **视觉、声音、场景规模与内容边界？**——引擎能兑现的画面量级要匹配阶段一的可行性评估。

## 钩子七形态（"钩子"是未稳定局面，不是神秘台词）

| 形态 | 例 |
|---|---|
| 高代价行动正在执行 | 当众签字的瞬间 |
| 正常事实与可见证据矛盾 | 账本数字对不上 |
| 有时限的目标开始 | 倒计时生效 |
| 前因后果现在抵达 | 上集选择的本集报应 |
| 必须公开作决定 | 被逼当场表态 |
| 权力关系突变 | 一直忍让的人翻脸 |
| 信息差倒置 | 观众知道、人物不知道的事即将撞上 |

钩子必须**因果连接**本集目标——开场刺激与后续无因果的只是装饰。

**信息差三态（钩子的认知骨架）**：每条钩子都建立一种认知势能，落到三种之一——
- 观众知道、人物不知道 → **悬念**（看着人物走向陷阱）；
- 人物知道、观众不知道 → **迷题**（人物领先一步，牵着观众猜）；
- 双方都蒙在鼓里 → **探索**（一起揭开）。

每集至少交付一个**信息增量**：新信息 / 新问题 / 旧信息回响（旧设定被新情境唤醒）。钩子既不建立信息差、又不交付信息增量，多半是"神秘台词"式装饰，删或改。

## 首集入口决策：收益入口 vs 冷开

| 方案 | 做法 | 适用 |
|---|---|---|
| 收益入口 | 从第一个强收益点（打脸/反转/奇观）直接开始，身份信息后补 | 大多数题材的默认；观众 30 秒内要拿到回报。**注意**：把镜头直接切进高压场面（不做铺垫）不改变时序的，属于收益入口的"高压起手"变体，不是冷开 |
| 冷开 | 把**后文**更强的高光提前到第 1 集，再回到时序起点补铺垫 | 原著/故事前几段平、高光在后的改编项目 |

决策写 DEC。无论哪种：第 1 集必须有钩子（量化门）、观众必须后补的信息要尽量少（后补信息清单 ≤3 条）。上游文档（如阶段一简报）用词与本定义冲突时，以本定义为准并在 DEC 中记录归并逻辑。

## 单集契约（分集大纲每集六字段的操作定义）

```
可验证的进入状态
→ 当集压力迫使人物追求目标（钩子连接目标）
→ 选择遭遇反制并产生后果（因果升级链）
→ 观众获得当集承诺的部分回报（兑现）
→ 一个具体的新决定/危险/问题形成下一步压力（出去压力）
→ 可验证的出去状态
```

### 进入状态只写会影响本集行动的事实

人物位置/持物/伤势；谁知道什么、误信什么、有什么证据；谁占主动、谁欠谁；上集留下的未决动作；必须接住的视觉/声音/时间事实。**不要把整本设定复制进每集**。

### 因果升级链（反"预填冲突次数"）

```text
因为进入状态中的事实 A，人物采取行动 B；
B 触发反制 C；
C 让状态 D 改变，迫使人物放弃旧策略或付出更大代价；
新选择 E 产生本集的方向性转折。
```

写分集时用这条链自检：删掉"发生三次冲突"这类数字，每个冲突都要能指出它改变了什么状态。

### 兑现规则

- 每集至少兑现一项当集承诺（可以小额）——只留钩子不兑现，观众第三集就停；
- 兑现可以是旁观者形态（群体改口、对手当众吃瘪——收益落在观众身上）；
- 终局集兑现的是全剧长线承诺，不是新爆点。

### 出去压力与交接事实

出去压力要**具体**（一个决定、一个危险、一个问题），不写"留下悬念"；交接事实是下一集进入状态的原料——逐集首尾相接，上一集的出去状态必须能原样填进下一集的进入状态。
