# 短剧导演设计与分镜

把剧本转成**有戏剧职责、空间连续、可被 AI 视频生成执行**的镜头方案。前提认知：镜头是生成出来的，多切一镜成本近零，但**每一镜里塞不下的东西，视频模型不会帮你删——它会把动作压到看不清**。

## 核心立场

1. **每镜一个唯一职责**：这一镜只让观众看清一件事；两个职责拆两镜。切镜必须带来信息/权力/情绪/空间/节奏变化——同义重复镜头删掉。
2. **剧本对账**：剧本每个场次都有镜头承载（不拍的场记"未拍场次+理由"留痕）；每镜声明**来源**（SC-ID + 承担的动作或台词）；**节拍认领**——镜头认领剧本中的哪些动作节拍/台词行，认领不重不漏（对账是分镜质量的底线：剧本改版后重跑对账，失效镜头当场点名）。
   - **节拍口径**：节拍 = 剧本的**动作行 + 台词行**（含 [VO]/[OS]/[SFX]/[画面文字] 行）；场景描述行不计节拍。
   - **反应镜**：对白正反打中的"反应镜"不认领节拍——它认领的是"对前节拍的反应"，职责栏写"反应：EP…节拍 n"；认领总数仍与节拍总数一致。
   - **KF 编号**：`KF-EPxxx-SCyyy-nn`（跨场次不重号），尾帧加 E 后缀。
3. **资产对账（视觉依据）**：每镜必填"视觉依据"——按成稿关键帧画面反查，需要保持身份/造型/地理的可见人物/地点/道具逐项引用资产卡（CHAR/LOC/PROP 或其变体）。镜头里有谁不能只凭"这场戏里有谁"顺延。无卡群演不入视觉依据，正文用"背景群演"统一描述（同阶段三/四豁免）；关键帧正文与视觉依据使用**六段式同族格式**（与阶段四 IMG 一致，允许构图/背景独立成行，段数服从内容）。
4. **空间先行**：一场拍多镜前先写该场**站位块**（固定锚点/人物相对位置/朝向/轴线 working side/哪一镜改变站位），再逐镜锁朝向、视线、持物——轴线跳了观众就迷路。
5. **关键帧是起点投影**：冻结关键帧只写该瞬间能看见的内容，删除终点才出现的东西；镜尾关键帧（可选）对称处理。构图、光色服从阶段四风格指南的全局画风句与场景光色句。
6. **镜长从内容推出**：有对白先估发声时间（字数÷4.5 字/秒），再排不能重叠的动作与反应；无对白镜按"观众要看清几件事"定时长（一件事≥2 秒）。**数一下这镜要观众看清的事，放不下就删、并或拆镜**。

## 工作流

1. **接收上游**：已确认剧本（含台词、场景描述、[画面文字]/[连续性]标签）+ 视觉设定 + 风格指南。剧本未确认先催确认（分镜建立在剧本上，改版即失效）。
2. **导演阐述**（全剧一次，templates/director-brief.md）：整体视觉方向（写实基调/主要场景的光色策略/镜头语言倾向——近景浓度、手持或稳定、节奏型）、竖屏构图原则、跨集统一约定。已有阶段二视觉方向时在此落实为镜头语言。
3. **逐场设计**（每场循环）：
   a. 读剧本该场全部节拍（动作行/台词行）；
   b. 写**站位块**（templates/blocking.md）：锚点（用 LOC 资产卡的固定锚点）、每人相对位置与朝向、轴线两侧、出入口；有持续身体—物件关系（束缚/负重/依托）投影进相关镜头；
   c. 切镜：按节拍认领分配镜头（每镜认领哪些节拍，`来源：EP001-SC001 · 节拍 3-5`）；多拍节拍（对白+反应）拆正反打；关键动作给特写；过场压缩；高频叙事段落（身份揭示/对峙/反转/追逐/离别/钩子等）可参照 [references/shot-patterns.md](references/shot-patterns.md) 手法卡套用——卡是起点不是定稿，先站位块与节拍认领后套卡；
   d. 每镜填 SHOT 条目（templates/shot-entry.md）：唯一职责、来源+节拍、时长（对白镜附估时依据）、景别/机位、运镜（写行为与理由，**固定也写理由**）、起点→唯一动作→终点（人物/双手/持物怎么完成本镜状态转换，合法终点之间不靠镜外瞬移）、声音、视觉依据、参考图需求（本镜需要哪些已确认/待出图的 IMG）；
   e. 打戏场：按 references/fight-breakdown.md 拆回合（单主体单动作、一打多不排队、末态起点链）。
4. **冻结关键帧**（templates/keyframe-prompt.md）：每镜一条（可选收尾帧），六段式与阶段四 IMG 同格式；正文 = 画面内容（谁在哪、什么姿势朝向、构图景别、光色），无台词无流程语言；锁面原样进入；全局画风句逐字复用。每条 KF 声明**基底图**（从持有本帧所需事实的图派生：角色锚点图带身份、空景图带地点氛围、相邻 KF 带延续状态），形成 KF 依赖边——不逐镜独立重画，减少画风漂移与出图量。
5. **生成批次**（templates/shot-list.md）：同场景+同光照的镜头归一批共用场景参考图（AI 顺场表）；批次内列出每镜的参考图依赖（人物锚点图/场景空景/道具图），缺图的标"待出图"并回阶段四补。
6. **对账与自检**（下节清单）→ 停靠汇报（镜头数/总时长 vs 剧本预算/批次划分/待出图清单）→ 确认。

## SHOT 编号与修订

- `EP001-SC001-SHOT03`；拆镜并镜保留未变 ID，变更镜版本 +1 并记录哪些下游（关键帧/批次）需刷新。
- 基底图重出或 KF 重出：依赖它的下游 KF 全部标"需核对"（沿 KF 依赖边传播），核对内容为继承事实是否仍然成立。
- 剧本改版：受影响场次对账重跑（节拍认领表直接点名失效镜头）。
- 上游矛盾（剧本要求分镜无法承载的表达，如"镜头缓慢升到太空"）：报 DEC，给可生成的替代方案。

## 自检清单（成稿必查）

1. 剧本每场有镜头承载或已记"未拍场次"；
2. 节拍认领不重不漏（剧本节拍总数 = 认领总和）；
3. 每镜唯一职责、来源可解析、起终态可见、无镜外瞬移；
4. 每镜视觉依据 = 按成稿画面反查的清单（非按"这场有谁"顺延）；
5. 站位块先行且轴线一致；改变站位的镜有明确交代；
6. 对白镜有估时依据且镜长容纳发声；无对白镜"要看清的事"与时长匹配；
7. 关键帧只投影起点（或对称投影终点）、画风句与光色句逐字复用、锁面在正文；每条 KF 声明基底图，继承事实与正文一致（基底图没有的事实不"继承"）；
8. 同场景同光照归批；批次参考图依赖明确、缺图标"待出图"；
9. 总镜头时长 ≈ 剧本预算（±10%，超出报创作者）。

## 常见错误

| 错误 | 纠正 |
|---|---|
| 一镜两职责 | 拆镜 |
| 视觉依据按场顺延 | 逐镜按画面反查 |
| 站位在切镜后凭空变化 | 站位块先定，变位镜交代 |
| 5 秒镜塞 3 个动作 | 模型会压到看不清——删/并/拆 |
| 运镜不写理由 | 固定也要写 |
| 关键帧写了台词 | 关键帧只是画面 |
| 打戏一打多围殴 | 回合制拆解 |
| 剧本台词没出现在任何镜的声音里 | 节拍认领对账抓出 |
