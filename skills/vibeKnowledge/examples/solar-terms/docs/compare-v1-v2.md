# 同一选题 · Skill 更新前后对比

> 选题不变（二十四节气如何计算），只换方法论。因此两版差异来自 **skill 更新本身**，而非换题。
> 更新前 = 旧 `script.ts` + 旧五场景；更新后 = 新 `script-v2.ts` + 新五场景（`MainV2`）。

## 0. 一句话结论

V2 的变化**不在画面更花，而在叙事**：钩子换成"你"的处境、悬念提前并在中段解掉、反转显式叠三层、全片常驻读数、无字幕呼吸口从 **8.5% 提到 27.9%**，并接入程序合成 BGM。画面主形象仍是同一个轨道盘（这是对的——一个世界用到底）。

## 3. 画面具体改了什么

- **钩子**：纸质日历页 → 手机日历 App（状态栏 / 刘海 / 事件条），让观众"看到自己的手机"。
- **机制段**：新增三层反转卡片；新增右上"年度进度盘"；14 天 / 16 天改为左右对撞（主角出现时轨道盘自动压暗）；平气 / 定气用双刻度叠影。
- **纵深段**：新增"冬至点沿黄道漂移"镜；落点改成"手机 + 轨道盘"同框，把 400 年前的算法接到观众手机上。
- **结尾**：回场由"日历 + 轨道盘"改为"手机 + 轨道盘"，并给片名回声。
- **转场**：纵深→结尾两场构图相同，交叉淡化会叠影，改为过一次极短黑场。

## 5. 诚实说明

- 画面仍是几何 / 线稿 / 示意风格，不是实拍或 3D 质感；两版共用同一套配色与轨道盘组件。
- BGM 是纯程序合成的极简织体（pad + 钢琴柱式 + 轻打击），胜在版权干净、可精确卡点，不是真实配器。
- V2 无字幕占比的提升，部分来自"拍间留空 + 片名卡 + 引用卡"，并非新增了大量纯动画长镜头。
- 事实表沿用 V1（同题），V2 未新增事实；所有年份 / 数字 / 文献与 V1 一致。
- V1 的 `out/final.mp4` 原样保留，V2 为独立合成 `MainV2`，两者互不覆盖。

## 6. 复现

```bash
# 预览两个合成（Main = 旧，MainV2 = 新）
npx remotion studio src/Root.tsx

# 重渲 V2
npx remotion render src/Root.tsx MainV2 out/final-v2.mp4

# 重生成 V2 配乐
python3 ../../scripts/synth_bgm.py out/bgm-v2.wav --duration 135 --bpm 77 --key Am \
  --sections "0,10,pad;10,40,piano;40,95,full;95,116.5,arp;116.5,127,piano;127,135,outro" \
  --beats out/bgm-v2.beats.json
```
