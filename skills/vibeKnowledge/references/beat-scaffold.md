# 逐拍骨架：把 130 秒拆成一个个"位置"

> 一个 130 秒的标准片约 40–46 拍，每拍 2.5–4 秒。拍数可 ±4，但每个**功能位置**必须有人接。新手按表填，熟手当检查表用。
> ★ = 全片强调位（金句或关键数字，合计 6–8 处，时长自动加长，配停顿）。
>
> **节奏硬线**：每 8 秒至少一个可见事件（物变/数字/景别/硬切），130 秒 ≥16 个；每 20–25 秒一次景别变化；全片 ≥3 次硬切。事件不够，先删解释句，再补总览/特写；不要靠缓推和颗粒位移凑"在动"。

## 一、钩子与片名（0–14 秒，约 4 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b01 | 处境 | 观众亲身经历过的一个具体时刻，前半句切入，不解释 |
| b02 | 处境转折 | 同一件事的反面结果，或"然后发生了什么" |
| b03 | 疑问 | "是 A（常识答案），还是 B（真相方向）？" |
| b04 ★ | 片名卡 | 标题问句；卡上写两字片名 + 英文术语 + 一句副题 |

**开场可选模式——作画过程开场**：b01 不从成品画面起，让主形象"自己画出来/长出来"——曲线按笔顺生长、结构逐块点亮、粒子按格聚成主体，字幕压在过程上。好处：第 0 帧就是动的（无静止封面帧），且"它被画出来"本身就是"这个东西由什么构成"的第一次讲解。适用：主形象有明确构成结构的概念；不适用：处境代入型钩子（那要的是生活实感，不是工程感）。

## 二、真实故事：埋悬念（14–40 秒，约 9 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b05 | 时间地点 | "年代，地点。"——顶部年代戳同步出现 |
| b06 | 抛出现象 | 一句话把问题讲清 |
| b07 | 具体情境 | 当场演示一遍，让观众代入 |
| b08 | 关键提问 | 把观众心里的问题问出口 |
| b09 | 反直觉答案 | 当事人/专家给出意外答案（必须查证过） |
| b10 | 人物揭晓 | 名字 + 一个让他像活人的细节 |
| b11 | 引出波澜 | "很快……"——有人反对，或现象被意外证实 |
| b12 ★ | 悬念金句 | 一句话推翻，**不解释**（解释留给演示段） |
| b13 | 过渡 | "谁对？让数字说话。"——收束故事，进模拟 |

## 三、机制演示：多层反转（40–95 秒，约 15 拍）

全片最长的段落，模拟在跑，反转叠在结果上：

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b14 | 设定 | 模型规模与前提（数字来自事实表，不现场编） |
| b15–16 | 规则 | 两条：一条公式式规则 + 一条"哪个变、哪个不变" |
| b17 | 第一组结果 | 挑出一组（强调色高亮） |
| b18 | 关键数字 | 只说数字（先写占位符，算出后回填） |
| b19 | 排除外因 | 强调"什么都没做、纯靠规则" |
| b20 | 悬停 | 破折号收尾，留半秒悬念 |
| b21 ★ | 对照数字 | 另一组的数字，只说结果 |
| b22 | 直观化 | 把对比换算成更好懂的（"几乎正好是三分之一"） |
| b23–24 | 机制解释 | 反方向也指一下 + 大白话讲清为什么 |
| b25 ★ | 第一层金句 | 对仗短句，点破第一层 |
| b26 | 第二层反转引子 | 固定句式："更反直觉的是：……" |
| b27 | 反转证据 | 换个条件，数字反转 |
| b28 ★ | 第二层金句 | "关键不是 X，是 Y" |

## 四、历史纵深：第三层反转（95–110 秒，约 5 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b29 | 时间跳跃 | 年代戳切换，"其实，这个问题比想象的老" |
| b30 | 更早的答案 | 前人怎么解决/回答同一个问题 |
| b31 | 现代对照 | 今天的算法/制度/工具如何继承它 |
| b32 ★ | 第三层金句 | 升华但不说教 |
| b33 | 现实落点 | "你的手机里 / 你的日历上，也有一个" |

## 五、收尾（110–130 秒，约 6 拍）

| 拍 | 功能 | 写法要点 |
|---|---|---|
| b34 | 回问 | 回到开头的钩子画面，观众现在能自己回答了 |
| b35 ★ | 末句 = 片名回声 | 写片名时就把末句一起想好（《运气的形状》→"运气，从此有了形状"） |
| b36 | 声明 | "本片为科普示意，非学术表述" |
| b37–40 | 引用卡 | 学术引用（作者、文献、年份）逐条滚动；免责声明；无水印不加署名 |

## 适配说明

- 更短的片子（90 秒）：二段砍到 6 拍、三段砍到 10 拍，四段可并入三段结尾
- 更长的片子（165 秒）：三段加 6 拍（多一组对照）、四段加 2 拍
- 每拍写进分镜表时必须填：字幕（中/英）、屏上主体、本拍动作（六种呈现动作之一）、强调位与否
