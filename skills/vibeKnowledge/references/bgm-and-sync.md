# BGM 合成与卡点：让声音跟着讲解走

> 无旁白片没有"人声"撑节奏，画面之外全靠 BGM 与事件音。BGM 不只是垫底——它的节拍网格是卡点的时间轴，段落起伏要对齐分镜章节。

## 1. 规格（先定，再合成）

| 维度 | 规范 | 依据 |
|---|---|---|
| 速度 | 76–78 BPM 小调 | 参考片实测 [官方] |
| 时长 | 覆盖全片 + 结尾淡出（约 2–4 秒） | [官方] |
| 响度 | 峰值 -1dB；最终混音压到 -14 LUFS 左右 | [官方] |
| 织体 | 段落起伏对齐分镜：pad < piano < full < arp < outro | [官方] |
| 格式 | 44.1kHz 16bit 立体声 WAV | [官方] |

## 2. 合成（scripts/synth_bgm.py）

零采样、零虚拟乐器，纯 numpy 算出：低音 pad 长音 + 钢琴柱式和弦 + 轻打击，五级织体对应五段情绪。

```bash
python3 scripts/synth_bgm.py out/bgm.wav \
  --duration 135 --bpm 77 --key Am \
  --sections "0,8,pad;8,40,piano;40,95,full;95,110,arp;110,125,piano;125,135,outro" \
  --beats out/bgm.beats.json
```

- `--sections` 的分段起止秒**直接抄分镜表的段界**（钩子 / 故事 / 机制 / 纵深 / 收尾），让音乐高潮落在机制演示段。
- `--beats out/bgm.beats.json` 输出节拍网格（每拍、每小节时间点），下一节卡点用它。
- 合成器是纯函数：同一参数两次运行结果一致（固定随机种子）。

## 3. Remotion 对接

BGM 作为一层 `<Audio>` 放进合成，不放进任何场景组件：

```tsx
<Sequence from={0} durationInFrames={totalFrames}>
  <Audio src={staticFile("bgm.wav")} volume={(f) => envelope(f)} />
</Sequence>
```

- `volume` 用帧号做包络：开头淡入、标题卡后回落、结尾淡出。
- 事件音（关键揭晓那一下）单独一层，放最上；提问镜不出声。
- 若走无声版（本 Skill 允许），跳过本文件，但成片节奏会明显更依赖画面微动画补密度。

## 4. 卡点纪律

1. **卡点对齐强重音，卡点 ≠ 逐拍切。** 只把"揭晓 / 金句落定 / 读数到位"这几下对到强拍（小节第一拍），其余镜头过渡不硬卡。
2. **切点误差 ≤ 3 帧**（30fps 下 ≈ 0.1 秒）。需要卡点的地方，用 `beats.json` 里的小节时间算 `from` 帧号，别用秒数四舍五入。
3. **每下变化配一次轻响。** 主体出现、读数滚动、推拉，各配一次；金句前一拍静一点，落定时低音一下。
4. **不要听不见还硬做。** 合成完把波形画成图检查（爆音 / 长静音段），听不见的地方不要假装有卡点。
5. **拍点那一帧必须有整屏可见的变化。** 卡点作用于新旧两层：揭晓层（新主体/新数字）在拍点帧出现，持续动画层（母题循环/高亮）也在拍点帧完成一次可见跳变——两层同时到点，误差各 ≤3 帧。只冲新层的后果是揭晓"拖拍"：画面变化落在拍点后 0.1–0.17 秒，观众读成慢半拍。

## 5. 声音质检

- 波形图：有没有爆顶（峰值超 -1dB）、有没有意外长静音。
- 响度：最终混音压到 -14 LUFS 左右。本片无旁白，所以不查"BGM 是否盖过人声"，只查 BGM 自身是否干净。
- 与分镜表对齐：`--sections` 的段界是否与 `storyboard.md` 的段界一致；高潮（full / arp）是否落在机制演示段。
