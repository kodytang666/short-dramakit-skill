# 叙事场景型

> 证据档案：`参考分析/vibe-古代知识/`（《晚一步，就是一整夜》唐代长安宵禁，2:46）。写片前先读本题模板 + structure-bible 十一条定律。

## 何时用

题材有**真实的时间、地点和因果链**——历史事件、制度由来、一场事故、一个发现的过程。能讲成"那天晚上发生了什么"的，都是这一型。判据：能用一句话说出"谁在某时某地被某事卡住了"。

## 结构骨架

钩子问句（观众可代入的处境）→ 计数装置登场（时间开始流动）→ 制度/机制展开（卷轴/地图/剖面）→ 落到个体 + 危机命名（大字卡）→ **黑屏问句卡反转**（≤2 次）→ 规矩细节与例外 → 代价阶梯（大字卡连打）→ 等待段（情绪蓄水）→ **计数装置反向回环** → 悬念兑现 → 一点透视 + 金字金句收束。

## 视觉系统

- **色温即叙事时钟**：分幕色板跟着故事时间走（暮红→米黄→夜蓝→黎明金），幕内一套不换，幕间渐变，禁全屏跳变。题材没有时间弧时，退回深蓝黑 DNA。
- **同一场景多光照复用**：主场景先想好能出现在几幕，画一版结构换 N 版光照，空间连续性免费。
- **三级注解分工**：红底小标签管识别（坊名/店名/地点）、双语字幕管叙述、白线注解图管数字关系。互不抢。
- 计数器：大数字 + 单位 + 动作主体 + 一句 caption。

## 招牌手法

1. **计数回环**：同一装置首尾各用一次，装相反情绪（暮鼓 0→600 焦虑 / 晨鼓 0→3000 希望，0:04 与 2:00）。
2. **黑屏问句卡当转折拍点**（0:56"那被关在城外的人呢？"）。
3. **大字卡阶梯连打情绪重段**（0:46"犯夜"、1:24"徒二年半→减一等"）。

## 质量阈值（红灯）

- 色温弧与故事时间不一致，或一幕内换了色板
- 计数装置只出现一次（没有回环，收束就泄气）
- 每幕没有"主动作 + 2–4 个母题循环"
- 出现抽象概括句——本型的命是具体名词（朱雀大街、热汤一张榻、四更一点）
