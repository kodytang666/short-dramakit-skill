# 机制演绎型

> 证据档案：`参考分析/vibe-数学与逻辑/`（《运气的形状》概率论五百年，2:09）。写片前先读本题模板 + structure-bible 十一条定律。

## 何时用

题材有一条**推导链或发展史**——定理从哪来、机制怎么被一步步想明白、技术如何演进。判据：能把内容排成"第 N 年，有人做了一件事，答案变成了什么"。多概念、多章，是四型中结构最重的一型。

## 结构骨架

问句钩子（"运气，能被计算吗？"0:04）→（可选）前史小节 → **编年章**：每章 = 年份标签推进 + 一个新具象载体 + 一个机制演示 → 改判拍（旧答案被划掉）→ 幽灵合影闪回（全片道具同框淡出）→ 收拢成公理/一句常识 → **装置回到观众**（"今年·你"）→ 金句 + 文献线索收束。

## 视觉系统

- **年份标签就是叙事钟**：左上"年份+城市+人名"金字标签按章滚动，全片时间推进全靠它，不用旁白说"接下来"。结尾标签必须滚到"今年·你"。
- **每章一个具象载体，章间接力**：骰子展开图→金币赌注→概率树→死亡公报→坛子→硬币直方图→钉板→公式。**无符号先行**：每章先物后式。
- **计数器演收敛**：进度条 + 对数收敛图贴真实值虚线 + 实验台账三行，三套装置做同一件事——"多次重复逼近稳定"被眼睛看见。
- 配色纪律：单一主强调色（金）+ 红只给三种用途（输面/文献签/事件戳）。

## 招牌手法

1. **标签钟滚到"今年·你"**——历史片结尾把骰子交到观众手上（1:59–2:00）。
2. **历史改判可视化**：金币"5:2"被红笔划掉改注"15:1"（1:06），纠错变成一个动作。
3. **原文引言卡压节拍**：原文+译文同屏，分别压在"通信开始/全书总结/情绪顶点"三个节拍（0:56、1:37、1:51）。

## 质量阈值（红灯）

- 任何一章符号/公式先行，没有具象载体
- 年份标签断档（观众丢了时间感，本型就散架）
- 计数器数字不绑真实比例或虚线参照——纯跳动是装饰不是讲解
- 收束不回到观众（缺"今年·你"，编年就没有出口）
