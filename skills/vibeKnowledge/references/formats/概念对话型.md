# 概念对话型

> 证据档案：`参考分析/vibe-哲学与思想/`（《七宗罪 · 为什么傲慢排第一》，1:58）。写片前先读本题模板 + structure-bible 十一条定律。

## 何时用

题材是一个**有争议或反直觉的观念**——要推翻观众的默认排序/默认信念，且这个观念在历史上有多个版本或多位回答者。判据：能写成"你以为 X 是答案，其实排第一的是 Y"。最容易滑向文字主导的一型，纪律最严。

## 结构骨架

直觉设问（把观众的真实想法亮出来）→ 名词群登场（七画像/概念墙）→ **历代答案接力**：每位思想家给一个新视觉结构，同一份名单被重排 N 次 → 关键区分拍 → **现代数据"照镜子"**（唯一现代场景，放结尾前）→ 论点句专属版式 → 逐个熄灭/排除收束。

## 视觉系统

- **亮度分配就是论点**：全片暗场为底，亮给谁、谁熄灭，就是论证本身。本型色温弧可以与叙事相反（越走越暗），前提是"暗"服务于论点。
- **排序用"位置"不用跳动计数器**：徽章行 → 台阶层号 → 天平倾角，重量与海拔承担排序。排位题材把计数器换成位置装置。
- **论点句专属版式**：衬线大字 + 上下金色细线框 + 关键词金色高亮（1:49"而是**最看不见**的那个。"）。全片 ≤2 句。
- 具身托底：每个抽象论断配一个身体动作（被拖走 vs 自己转身、背巨石弯腰、根须长出来）。

## 招牌手法

1. **一份名单 N 次重排**：观念升级 = 视觉结构升级（徽章行→塔与根须→天平→炼狱山，0:18–1:12），不靠两人对辩。
2. **照镜子华夫图**：93% 方块图（1:28）把古典概念翻译成"优于平均效应"，观众从看历史变成被看。
3. **逐个熄灭收束**：七画像按序熄灭只剩答案独亮（1:44–1:48），近黑暗廊 + 尘埃光束 + 小金字回声。

## 质量阈值（红灯）

- 任何一句论断没有画面动作（本型文字主导风险最高，逐句过）
- 结构升级不可感知——观众看不出"换了一代人/换了一种想法"
- 现代数据场景出现在中段（镜子必须照在结尾前，照早了论证还没立起来）
- 数据来源机构没给全名（参考片 93% 调查机构缺失 = 反例，见 citation-policy）
