# 质量门：机器扫硬伤 → 小图看清晰 → 三问看讲解

> 三步各管一件事，不重复：第 1 步机器拦硬伤，第 2 步人看"看不看得清"，第 3 步人看"讲没讲明白"。毛病的改法统一查 [visualization.md](visualization.md) 第十节。

## 1. 量化门禁（渲完先跑）

```bash
bash <skill>/scripts/motion_gate.sh 成片.mp4
```

| 判据 | 线 | 级别 |
|---|---|---|
| 静止帧占比（5fps 采样帧差） | > 25% | 黄灯 |
| 单次静止段 | ≥ 3 秒 | 红灯 |
| 中段黑场/空画面（片头尾 2s 豁免） | ≥ 1.2 秒 | 红灯 |
| 暗帧占比（YAVG<45） | > 50% | 黄灯 |
| 镜头级变化（>90s 的片子） | < 3 次 | 黄灯 |

- 红灯修完重渲再跑；黄灯修掉或写明理由（如夜景本来就暗、长镜头是有意的）。
- 无字幕段与金句停顿是设计意图，不按"静止"修；停留拍靠微动画把帧差抬起来。
- **门禁只拦硬伤，拦不住难看**——绿灯后照常做下面两步。

## 2. 小图网格（看得清吗）

每 10–15 秒抽一帧，共 8–12 帧，缩到 480px 宽排成网格；先看网格，再回看全尺寸关键帧。

| 查 | 线 |
|---|---|
| 主体 | 每格一眼说得出主体；面积 ≥1/4，关键镜头 ≥1/3 |
| 亮度 | 近黑像素（Y<16）≤45%；中间调（Y 40–180）≥20%；每帧一个暖色/高光锚点 |
| 焦点 | 眯眼看，最先吸引你的就是这句字幕的主语 |
| 构图 | 没有连续三格构图一样、主体一样大 |
| 事件 | 每 8 秒至少一次可见变化（物变/数字/景别/硬切），≥1.2 次/10s |
| 版面 | 常驻大版面（刻度/多行页眉/边框）≤30% 时长、同屏 ≤2 个；字幕区 y>82% 干净 |
| 结尾 | 最后一镜是主形象的状态反转，不是字卡或引用墙 |

## 3. 三问（讲明白了吗）

每做完一段就截图，遮住字幕和小字，逐镜问：

1. 屏上这是什么？（一个日常的词）
2. 它在干什么？（一个动词，就是字幕里那个）
3. 观众明白了什么？（一句话，和上一镜不同）

再对着 visualization.md 第十节的毛病表过一遍。

**至少改两轮再给用户看。** 每轮：列毛病 → 改 → 重截同样的时刻 → 确认改掉了、没改坏别的。不带着自己都看得出的毛病交片。

## 4. 终检（交片前）

整片渲出来后看三遍：**静音遮字幕看一遍**（每段在讲什么看得出吗）→ **只读字幕一遍**（通顺吗？哪句里的名词屏上找不到？）→ 对照下表。

| | 门槛 |
|---|---|
| 讲解 | 成片和分镜表对得上；抽五镜过三问；没有换给别的文案也成立的画面；尺子和道具回过场 |
| 画与不画 | 提问、命名、结论没硬配图；约 1/5 句子不配新画面；没有连着几句画面不变 |
| 文案 | 密度 ≥2.6 字/秒；每句含一个新信息；无字幕时间 25–40%；末句是片名回声 |
| 事实 | 屏上每个数字/年份/人名在事实表有出处；示意处标"示意"；分歧两说并列；引用卡完整 |
| 技术 | 1920×1080 / 30fps；同一帧渲两次结果一致；无水印署名 |

交片时说实话：不满意的地方、没做的东西、没完整看过的部分，直接列出来。宁可少，不要糊——时间只够把三个概念做好，就只做三个。
