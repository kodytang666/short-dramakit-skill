# 质量门：量化门禁、三问、六查、两轮

## 0. 量化门禁（渲完先跑，机器扫硬伤）

```bash
bash <skill>/scripts/motion_gate.sh 成片.mp4
```

| 判据 | 线 | 级别 |
|---|---|---|
| 静止帧占比（5fps 采样帧差） | > 25% | 黄灯（风格 DNA：静止秒 < 25%） |
| 单次静止段 | ≥ 3 秒 | 红灯（常见错误：静止超 3 秒） |
| 中段黑场/空画面（片头尾 2s 豁免） | ≥ 1.2 秒 | 红灯（主角或主物必须在画里） |
| 暗帧占比（0.2fps，YAVG<45） | > 50% | 黄灯（反"黑屏图表"：补中间调/暖锚点） |
| 镜头级变化（scene>0.3，>90s 的片子） | < 3 次 | 黄灯（全片只有淡化和缓推，像 PPT） |

- 红灯修完重渲再跑；黄灯修掉或写明理由再交片。
- **暗帧黄灯先看 480px 小图**：如果主体、中间调、暖锚都达标，只是夜景整体暗，可写明理由保留；不要为了指标把夜景提成灰片。
- **镜头级变化黄灯**：连续长镜头是风格选择时可以保留，但必须有物变/景别变化补事件；否则观众仍会觉得停。
- **门禁只拦硬伤，拦不住难看**——绿灯后照常过下面的三问与六查；运镜顺不顺、画面美不美，机器看不出来。
- 无字幕占比 25–40% 与金句停顿属于设计意图，不按"静止"修；字幕停留拍要靠微动画把帧差抬起来。

## 0b. 清晰度与观看性门禁（渲后抽帧，人工过）

> `motion_gate` 只证明"帧差不是零"，不证明"画面看得清、看得下去"。再跑这一组：

**做法**：每 10–15 秒抽一帧，共 8–12 帧；缩到 480px 宽排成 3×3 或 5×5 网格；先看网格，再回看全分辨率关键帧。

| # | 查 | 线 | 不过的样子 |
|---|---|---|---|
| 1 | 480px 小图主体 | 每格一眼说得出主体 | 只剩金线/标签；眯眼看不出画的是什么 |
| 2 | 主体占比 | ≥1/4；关键镜头 ≥1/3 | 主体缩在角落，靠字幕解释 |
| 3 | 近黑像素（Y<16） | ≤45% | 整帧黑成一片，细节全没 |
| 4 | 中间调（Y 40–180） | ≥20% | 只有黑底 + 金线，没有体积/材质 |
| 5 | 主体/底色对比 | ≥3:1 | 主体和背景糊在一起 |
| 6 | 暖色/高光锚点 | 每帧 ≥2% 面积 | 冷底冷画，没有"火"的落点 |
| 7 | 视觉事件 | ≥1.2 次/10s；最长空档 ≤8s | 长时间只有缓漂；观众觉得"停了" |
| 8 | 镜头级变化 | ≥6 次/130s；硬切 ≥3 | 全片只有淡化和缓推 |
| 9 | 常驻 HUD | ≤30% 时长；同屏 ≤2 个 | 左侧刻度/页眉把画面框成 PPT |
| 10 | 连续同构图 | ≤2 拍 | 连续三拍都是"左图右字" |
| 11 | 最后一镜 | 主形象状态反转 | 落在金句卡/引用墙 |

**判断法**：
- 把网格图拿远一米看：哪一格最先吸引你？它是不是这一句字幕的主体？不是就调。
- 遮住字幕看每一格：能不能说出"这是什么/它在干什么/我明白了什么"？三问有一个含糊，这一格不过。
- 网格里出现连续三格"构图一样、亮度一样、主体一样大"，直接重做这三拍，不要靠加特效救。

## 1. 三问（每镜截图后，遮住字幕过）

1. 这是什么？
2. 它在干什么？
3. 我明白了什么？

答得含糊就是没做好——不进下一步。

## 2. 六查（每轮看图时逐条对）

| # | 查 | 不过的样子 |
|---|---|---|
| 1 | 主体大小 | 主体 < 画面 1/3；或被文字压住 |
| 2 | 主体可辨 | 认不出是什么东西（只是抽象几何+标签） |
| 3 | 每句一改 | 一拍里同时变了两样以上东西；或屏上根本没变 |
| 4 | 字幕带干净 | y>82% 区域有动效杂物；小字压在主体上 |
| 5 | 转场清楚 | 段落切换后不知道自己还在哪个画面体系里 |
| 6 | 密度 | 静止超 3 秒；金句前没有停顿；数字没有滚到位 |

## 2b. 易懂与质感三查（新增，配合 visualization.md §7 与 visual-style.md §7）

| # | 查 | 不过的样子 |
|---|---|---|
| 7 | 焦点唯一 | 一帧里两个以上主体同等亮 / 同等动；眯眼看不出该看谁 |
| 8 | 数字有锚 | 关键数字孤零零，没有生活换算、并排对比或可数实物 |
| 9 | 因果可见 | 遮住字幕，看不出 A→B→C 的关系；三格互不相干 |

质感不越界（附带）：grain/bloom 不压字幕、不糊主体；强调手法（光扫/冲击帧/遮罩）全片不超上限（见 visual-style.md §7.4）。

## 3. 两轮纪律

第一次渲出来的画面几乎都有毛病。这种片子是**看着图改出来的**：

1. **至少改两轮再给用户看。** 每轮：把看到的毛病列出来 → 改 → 重截同样的时刻 → 确认改掉了、没改坏别的
2. 看的时候当自己是第一次看的观众，不是检查自己代码的开发者
3. 抽帧用 `--frames=0,30,90`，对应片头/中段/结尾；改哪段抽哪段
4. 还有毛病就接着改，不要带着自己都看得出的毛病交片

## 4. 文案终检

- 总字数 ÷ 总秒数 ≥ 2.6（密度红线）
- 每句四者有其一：新事实/数字/转折/动作
- 无字幕时间占比 25–40%
- ★ 强调位 6–8 处，每处前有停顿
- 末句是片名回声；引用卡完整；声明在场

## 5. 事实终检

- 屏上每个年份/人名/数字都在事实表里有出处行
- 示意处标了"示意"
- 分歧说法两说并列（若适用）

## 6. 交片时说实话

不满意的地方、没做的东西、没完整看过的部分，直接列出来。宁可少，不要糊——时间只够把三个概念做好，就只做三个；每一镜都认得出，比多讲两个概念重要。
