# 选题种子库：方向、四关检验与自建题库

> 选题公式：**一个硬核概念 × 一个"你"的处境**，标题必须是在问观众。
> 本文档给方向与检验标准；具体事实动笔前逐条查证、进事实表（配合 `structure-bible.md` §1 四项打分与铁律③"没出处不上屏"）。

## 一、五个最易出好题的方向

1. **被推翻或修正的经典结论**——反转现成：流传的是误传版本，真实结论更微妙。做之前核实"修正版"本身可靠。
2. **"你每天都在经历，却不知道它有名有姓"的现象**——回归均值、幸存者偏差、基础比率谬误、友谊悖论。钩子一句对号入座就成立。
3. **一场真实的历史比赛 / 实验 / 事件，能代码重跑**——"能模拟"最难满足，但满足的题最省心：模型贯穿全片、数字全真算。
4. **大奖背后的小故事**——诺奖级结论 + 一个日常应用。权威解决可信度，日常解决钩子。
5. **你自己评论区的问题**——每期发布后观众反复问的"那为什么……"，就是下一期。

## 二、种子题示例（动笔前逐条核实事实）

> 表内数字是常见文献引用值，**制作前必须查证原始出处**；标 ⚠️ 的题存在常见误传，最好把误传本身讲清楚（这往往是最强反转）。

| 题目方向 | 核心概念 | 画面构想 | 核实要点 |
|---|---|---|---|
| 每天进步 1%，一年后变成多少？ | 指数 / 复利 | 两条曲线 1.01ⁿ 与 0.99ⁿ 从同点岔开 | 1.01³⁶⁵≈37.8、0.99³⁶⁵≈0.026；别引申成鸡汤式的"努力"计算 |
| 体检查出阳性，真得病了吗？ | 贝叶斯 / 基础比率 | 1000 个小人方阵逐步筛出真假阳性 | 自设参数并在画面标"示意参数" |
| 23 人的教室，为何几乎必有人同天生日？ | 生日悖论 | 365 格扔球，概率曲线在 23 处过半 | 23 人 ≈50.7%，当场真算 |
| 为什么你排的队总最慢？ | 概率与选择 | 三条队同时前进 | 三队时"别的队更快"概率 2/3；措辞分清"这一队"与"平均" |
| 为什么你觉得朋友总比你受欢迎？ | 友谊悖论 | 网络图高亮"朋友的平均朋友数" | Feld 1991；结果是统计性的，非人人如此 |
| 纸对折 42 次能摸到月亮吗？ | 指数增长 | 对数刻度一路越过珠峰 / 卫星 / 月球 | 2⁴²×0.1mm ≈ 44 万公里 > 地月约 38.4 万公里；标"理想化假设" |
| AI 真懂你在说什么吗？ | 中文房间 | 房间里照手册查表回复 | Searle 1980；标"思想实验"，两方立场都给 |
| 换光所有零件，还是原来那条船吗？ | 忒修斯之船 | 木板逐块替换 | ⚠️ 别引"人体细胞 7 年全换"（谣言，多数神经元终生不换） |
| 越得不到越想要？ | 间歇强化 | 固定 vs 随机奖励两组曲线 | 行为主义经典结论；落点克制，不给心理建议 |
| 一段体验，你只记得结尾 | 峰终定律 | 体验曲线与记忆曲线并排 | 经典实验；落点在"设计结尾"，不说教 |

## 三、候选题四关检验

| 关 | 不过的信号 |
|---|---|
| 钩子 | 标题改不成"为什么你……""你……吗？" |
| 故事线 | 找不到具体年份 / 人物 / 论文，只能讲道理 |
| 能模拟 | 画面只能放图与字，没有会动会变的模型 |
| 反转 | 观众听完只会"哦"，不会"啊？" |

四关全过才进制作；任何一项弱，宁可换题。

## 四、避开

- 平台已被做烂的题材（搜索确认；同一概念 30 天内有高赞片就换角度或换题）。
- 只讲知识、与观众处境无关的题。
- 事实有争议、又无法在片里讲清争议的题（除非"争议本身"就是反转点，且双方案例都可靠）。

## 五、维护自己的题库

在上面建一张表（建议 `topics.md`，不进仓库）：列 = 标题方向 / 四项打分 / 模拟方案 / 反转层级 / 事实把握。每期做完回填实际完播率，五期后按数据定方向。
