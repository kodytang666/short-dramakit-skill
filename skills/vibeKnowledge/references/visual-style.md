# 视觉规范：皮相统一

> 一条片一套色、字、画法。每种颜色全片一个意思，用色即用典。

## 1. 配色（默认 · 深空蓝黑）

| 令牌 | 值 | 用途（全片唯一） |
|---|---|---|
| `bg` | `#050510`–`#101028` 线性渐变 | 背景 |
| `ink` | `#F5F2E9`（暖白） | 字幕主句、主体线稿 |
| `ink-dim` | `#9A97A8` | 英文对照、注释小字 |
| `accent` | `#D9B36C`（金） | 强调位、片名、染色词、刻度 |
| `alert` | `#E85D4A`（朱红） | 反转/警示/故障态（全片 ≤ 3 处） |
| `glow` | 主体色 15–25% 透明度辉光 | 主体发光、微动画呼吸 |

深色底上的文字禁止纯白 `#FFFFFF`（刺眼），禁止饱和蓝紫当正文色。用户点名其他风格家族（古风/纸本/像素等）时整套换，不许混搭。

## 2. 字体

- 中文：衬线体（Noto Serif SC / 思源宋体）——知识片的"文献感"
- 英文对照：衬线斜体（如 Playfair Display Italic）
- 数字/代码：等宽（JetBrains Mono）
- 字号阶梯（1080p）：字幕主句 44–52px、英文 24–28px、片名 96–120px、注释 28–32px——**全片只用这一档阶梯**，用 `@remotion/google-fonts` 加载，阻塞到就绪

## 3. 构图

- 主体占中央 1/3 以上；重心稳定（模拟动画时允许偏移制造张力，落回中心）
- 顶部标签带（y≈6%）：场景/年代戳，等宽小字，切换段落时淡入
- 画面注释（y≈70%）：对主体的即时说明，一拍一换
- 字幕区（y≈85–91%）：下方留黑边缓冲，任何动效元素不许侵入 y>82% 区域
- 三层构图：背景微动（星尘/网格/辉光呼吸）→ 主体动画 → 文字层——**背景永远最暗、最慢**

## 4. 转场

- 相邻拍之间：同场景内**只改一处**，不转场（一个世界用到底）
- 段落之间：fade（0.4–0.6 秒）或滑动模糊；转场时长计入总时长（TransitionSeries 会缩短编排，预算时补足）
- 片名卡：全片唯一一次"重"转场——黑场 0.3 秒 + 金字落定 + 辉光扩散

## 5. 微动画（密度红线：静止秒 < 25%）

文字停留时也要动——三选一，幅度要小：

- 辉光呼吸（opacity 0.85↔1.0，周期 2–3 秒）
- 缓移（1 分钟 ≤ 10px，几乎不可察觉）
- 粒子/星尘背景常驻慢速漂移

## 6. 数字上屏样式

- 关键数字用 `accent` 金色 + 等宽字体，出现时**从 0 计数滚到位**（数出来的呈现动作）
- 示意数据必须标"示意"二字；精确数据可上屏但出处进结尾引用卡

## 7. 动效语言与质感（一套，不混搭）

> "酷"来自**统一**，不来自**数量**。全片只用一套缓动、一套材质、一套强调手法；特效必须服务于"看懂"，否则删。

### 7.1 缓动（全片一套）

- 入场统一 `Easing.out(Easing.cubic)`；强调落定可叠加 `spring({damping: 12–18, mass: 0.8})` 做轻微 overshoot
- 缩放动画必加 `output: "perceptual-scale"`
- **禁线性**、禁 CSS `transition`/`animation`——所有动效由帧号驱动（见 remotion-contract.md）

### 7.2 辉光 / 描边 / 拖尾

| 手法 | 参数 | 用在哪 |
|---|---|---|
| 辉光 bloom | `feGaussianBlur stdDeviation 4–12`，叠主体色 15–25% | 太阳、片名、金句 |
| 描边生长 | `stroke-dashoffset` 随帧从满到 0 | 轨道线、曲线、时间轴 |
| 运动拖尾 | 画最近 6–10 个位置的残影，透明度线性递减到 0 | 地球沿轨道跑、计数器流动 |

### 7.3 材质（全片常驻，克制）

- **grain 细颗粒**：强度 3–6%，固定种子、逐帧微位移；用 data-URI SVG 噪声当背景图（解码一次，别每帧重算）
- **vignette 暗角**：径向渐变，四角压到 70–80%
- **色差**：≤1.5px，只给主体边缘，别糊字
- 材质层压在画面之上、字幕之下；**grain 不许降低字幕对比度**

### 7.4 强调手法（全片上限）

| 手法 | 参数 | 限制 |
|---|---|---|
| 光扫 | 斜向高光条随帧扫过，`mixBlendMode: screen`，opacity ≤0.3 | 只给片名/金句，全片 ≤2 次 |
| 遮罩转场 | 圆形/线性 SVG mask 擦除，0.4–0.6s | 段间用，段内不用 |
| 冲击帧 | shake 振幅 ≤6px、指数衰减 0.15–0.25s + 一次闪白 ≤1 帧 | **全片只用一次**，给最大揭晓 |
| odometer 数字 | 按位滚动，每位 spring 落定 | 只给一个核心数字 |

### 7.5 纪律

- 一套缓动、一套材质、强调色不超过 4 个令牌（bg/ink/accent/alert）
- 同一帧**只允许一个视觉高点**（最亮/最大/在动），其余压到 20–30%
- 任何特效加上去，先过 quality-gate 三问：遮住字幕还认得出"这是什么/在干什么/我明白了什么"吗？答不出就撤掉

## 8. 亮度与层次：反"黑屏图表"

> 深空蓝黑是 DNA，不是"全片压黑"的许可证。暗色片最常见的毛病不是配色，而是**画面大面积近黑、主体只剩一条金线**；480px 小图仍要能一眼读出主体。

### 8.1 三值法（每帧都要有）

| 层 | 亮度（0–255） | 占画面 | 作用 |
|---|---|---:|---|
| 暗底 | 0–16 | ≤45% | 夜空/墙阴/背景 |
| 中调 | 40–180 | **≥20%** | 主体体积、材质、砖缝、衣褶 |
| 高光 | 190–255 | 2–8% | 主体受光边、火芯、数字、金句 |

- **主体与紧邻底色对比 ≥3:1**；主体边缘不能只靠 1px 金线。
- **每帧至少一个暖色/高光锚点**，面积 ≥2%：火、灯、金护甲、炭火、纸被受光边。冷底没有暖锚，观众会觉得"黑得没东西看"。
- 近黑像素（Y<16）超过 45% 就是"黑屏图表"；先补中调（砖、木、布、墙），再谈氛围。

### 8.2 材质（每个主角物至少两层）

- 平涂 + 一道暗面 + 一道受光边 = 最低限度的"立体"；只有轮廓 + 填充，会像图标。
- 全片锁定**一个光源方向**（例：左上 45°）；所有物的高光/阴影同向，观众才相信它们在同一个空间。
- 颗粒、纸纹、布纹、砖缝是"精致感"的来源，但**不许压字幕**；纹理对比度控制在主体对比度的 1/5 以下。
- 辉光只给强调位，不用来"救"低对比；主体本身要能在关掉辉光后仍认得出。

### 8.3 480px 小图测试

把任意一帧缩到 480px 宽：
- 还能说出主体是什么吗？
- 关键数字还读得清吗？
- 画面里有没有一块"什么都没有"的近黑区域超过一半？
- 主体是不是只有一条线/一个标签？

过不了，先放大主体 1.3–1.5 倍、把配角压到 20–30%、补中间调；不要靠加字解释。

## 9. 镜头语言：不要全片只有缓漂

### 9.1 两种运动，分开记账

| 类型 | 例子 | 作用 |
|---|---|---|
| **物自己的动作** | 火苗跳、热烟走、雪落、炭筐变矮、纸被掀开、红纱被风吹起 | 讲解；观众看见"它在变" |
| **镜头运动** | 缓推、横移、拉远、硬切、景别跳 | 引导视线；制造节奏 |

**"静止秒 <25%" 只是地板，不是目标。** 全片缓漂 + 颗粒位移可以让帧差不为零，但观众仍然觉得"没变化"。真正的事件是"物变了/景别变了/信息揭晓了"。

### 9.2 节奏线（130 秒）

- **每 8 秒至少一次可见变化**（物变、数字跳、景别换、硬切）；最长无事件 ≤8 秒，超过 12 秒就是"前紧后松"。
- **每 20–25 秒至少一次景别变化**；全片 ≥3 次硬切，≥6 次镜头级变化。
- 镜头动作要交替：停 → 缓推 → 横移 → 拉远 → 硬切；**不要每镜同向缓推**，那是"放 PPT"。
- 快推/砸入只给重音（揭晓、反转、关键数字），全片数得过来；用多了会"急、不顺"。

### 9.3 事件密度自检

把分镜表按秒排开，标出每一次"物变/数字跳/景别换/硬切"。数一数：
- 全片事件数 ÷ 130 秒 × 10 ≥ **1.2 次/10 秒**
- 最长空档 ≤ **8 秒**
- 连续三拍同一构图 = 红灯

## 10. 版面纪律：别让 HUD 变成页框

- 常驻**大版面**元素（左侧等级刻度、多行标题栏、页码、logo 框、大面积边框）合计 ≤ **30% 时长**，同屏 ≤ **2 个**。
- 顶部**单行**年代签（≤3% 画面高度）是导航，不算页框；不要把它扩成多行标题带。
- 优先**画进物里**：等级刻在木牌上、数字刻在炭筐上、年代写在门匾上；悬浮 UI 只留一个最小标签。
- 如果刻度/阶梯是主母题，它可以常驻，但必须**随段落变状态**（当前层亮起、其余压暗），不能是一张静止的框。
- 字幕区 y>82% 永远干净；任何 HUD 不许压字幕、不许压主体。

## 11. 收尾：最后一镜是"物变了"，不是字卡

- 最后一镜回到开场的主形象，给一个**状态反转**：同一片雪落在同一只手上，这次化了；同一堆炭，这次空了；同一道墙，这次塌了。
- 金句/片名回声压在状态反转上，不要先出金句卡再出引用卡。
- 引用卡放在最后一镜之后，或缩到角落；**不要用一张字墙结束全片**。
- 结尾 2 秒内不要再引入新信息；让观众看完那个"物变了"的瞬间。
