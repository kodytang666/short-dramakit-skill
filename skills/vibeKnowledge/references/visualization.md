# 讲解设计：一句字幕出来时，屏上拿什么让观众懂

> 决定片子好坏的是这一篇。色、字、辉光、片名卡都是皮；片子好看，是因为字幕说到的每一样东西，屏上都认得出、看得见它在变。
> 方法借鉴 vibe-knowledge-film（MIT），按本 Skill 的 Remotion 工程改写。

## 〇、配图和讲解的区别

一条讲蛋白质折叠的片子，第一版的主体是一串星点连成的折线。字幕说"它要折成一个形状才能干活"，折线卷成一团；字幕说"只换掉第 6 个，形状就变了，这就是镰刀型贫血"，那一团换个卷法、变成玫红色。每一句都"有画面"，颜色节奏都像参考片——可观众从头到尾没见过蛋白质是什么、错一个字母到底坏在哪。

**检验法：把这个画面换给另一段文案，还成立吗？** 成立，它就是配图。

重做以后：镜头从血管里的红细胞钻进去，找到一串珠子；第 6 颗变了色；拉出来，细胞弯成了镰刀；再钻进去，珠串卷成一团抓住氧分子；变色的那颗在表面成了黏点；一团粘一团连成长杆，从里面把细胞顶弯。每样东西叫得出名字、长得像它本身，每句的动词屏上都发生了，看完的人讲得出"因为……所以……"。

## 一、怎么给一个概念找形象

对概念清单里每一个概念，**按顺序问，前面有答案就不往后问**：

| # | 问 | 有答案就这么画 |
|---|---|---|
| 1 | 它本身是个东西吗？ | 画它本身：骰子、红细胞、烽火台、手机日历。一眼认得出 |
| 2 | 它是一个过程或方法吗？ | 找一个小到每一步都画得出来的题目，当场走一遍：1 到 1024 猜数、12 个程序、一颗珠子的突变 |
| 3 | 它是一个量、一种程度吗？ | 给它一把尺子，**用同一把尺子量三样东西** |
| 4 | 它是观众脑子里的事吗？ | 设计一个五秒的小测试，让它在观众身上当场发生（填空、乱序、猜一个数） |
| 5 | 它是一条规律吗？ | 先各演两三个例子，再把例子摆到一张图上 |
| 6 | 都不是（判断、态度、总结） | 不画，上字 |

找到以后再加三问，把形象做强：

- **生活里哪儿见过它？** 找那个锚。至少一半概念要有锚；找不到锚的概念观众记不住。
- **换一个尺度看是什么样？** 拉近或拉远一级，原因和结果常常就连上了（一颗珠子 → 一团分子 → 一根长杆 → 一个细胞）。
- **它坏了会怎样？** 让它错一次。东西正常时看不出它在干活，坏了才看得出。

最后定全片的**一个**形象、**一把**尺子，以及哪些东西会回场。

### 画得像它本身

- **有体积，有材质。** 红细胞有厚度、中间凹、边上一道高光；珠子有光泽、一颗挨一颗穿在线上。一个圆圈加标签"红细胞"不算画了红细胞。
- **从认得的地方进场。** 先给人人见过的画面，再推进去找要讲的东西。直接把一串珠子摆在黑底上，观众不知道它在哪、多大、跟自己有什么关系。
- **记号只当小字用。** 箭头、虚线框、小圆点、柱子可以贴在东西旁边做说明，不能自己当主体——除非它是一件带刻度、叫得出名字的仪器（数轴、表盘、温度计）。
- **题材决定画风，不是规矩决定。** 讲数学和文字的片子，主体可以就是字、数轴、表格；讲身体、历史、动物的，要画实物。

## 二、六种画法

一句字幕出来，屏上能做的只有这六种。分镜表每一行选一种。

1. **亲自试。** 屏上摆出一个东西让观众自己起反应，字幕晚半拍出来，说的是观众脑子里刚发生的事。填空的古诗、乱序的句子、被盖掉一半的广播。用在开头和一切"你以为……"的地方。
2. **照着句子画。** 句子里说到什么屏上就是什么，句子里的动词屏上真的做。"砍掉一半"就盖住一半，"粘住"就真的卡上去。讲故事、举例子、摆事实都用它。人只画背影、剪影、一只手。
3. **当场做一遍。** 拿一个最小的具体题目，把方法一步步走完，屏上看得见状态和计数。字幕用人话说完规则就闭嘴，让过程自己跑。数是真算的。讲方法、机制、"为什么一定是这样"都用它。
4. **并排比。** 两样东西放进同一个版式，只留一处不同；或者前后两种状态叠在一起。凡是"A 比 B"都用它。
5. **摆到一张图上。** 把前面已出场的东西摆进一张坐标图，轴用人话写，重点是图上的一块区域或一条线。一条片两三次，只用来回答"为什么"，而且一定排在例子后面。
6. **只上字。** 规则卡、引文卡、命名的大字、公式加一句人话、末句；或者什么都不加，把上一幕停住。

另有两个贯穿全片的动作：**回场**（前面的道具、尺子、开场画面再出现）和**合体**（把全片的形象和观众生活里的东西放进同一个画面——轨道盘和手机日历同框）。

## 三、什么时候画，什么时候不画

能画的尽量画；但参考片里约每五句有一句不配新画面——那些停顿是观众把刚看到的东西想明白的时间。按这句话在做什么来定：

| 这句话在做什么 | 怎么处理 |
|---|---|
| 讲一件事、举一个例子 | 照着句子画 |
| 讲方法、机制、"因为……所以……" | 找最小的题目，当场做一遍 |
| 说观众自己的直觉 | 亲自试 |
| 比较两样东西 | 并排比 |
| 说一个数量 | 让它数得出来（一格一格、一颗一颗），或用全片那把尺子量；不是给数字配一根柱子 |
| 总结"为什么会这样" | 摆到一张图上，用前面出现过的东西摆 |
| 把道理落到"你"身上 | 合体 |
| 提问 | 不加新画面：停住上一幕，或只留一个问号 |
| 起名字、下定义；规则、结论、金句 | 只上字，或把上一幕停住 |
| 引一句原话 | 引文卡：原文 + 译文 + 出处 |
| 某年、某人、某篇论文 | 一行小字贴在已有画面上，不为它换场，不画脸 |
| 过渡句 | 不画，让下一幕进场 |

容易犯的几条：

- **刚演过的事，结论句不要再画一遍。** 再配一张图表，等于不相信刚才那一幕。
- **没有东西可指的句子不要硬配图。** 硬配出来的就是光点、连线和抽象图形。
- **公式不单独解释。** 贴在刚演过的例子上，每个符号都对得上屏上某样东西。
- **一个场景撑 2–5 句字幕，每句只改一处。**

## 四、为什么看得懂，为什么让人"哦——"

看得懂靠：

1. **不用翻译。** 屏上的东西就是句子里说的东西；数字、符号是贴在旁边的小字。
2. **先例子，后道理。** 名字、公式、结论排在观众看过例子之后。
3. **借观众已有的经验。** 每个难概念拴在一件人人经历过的事上。
4. **量看得见。** 多少是数得出的东西，大小是长度和高度，比较在同一个画面里。
5. **一把尺子用到底。** 观众学会读一次，后面都在自己比。
6. **字幕说人话，屏上给证据。** 字幕谁都听得懂；年份、人名、p 值是屏上的小字。

让人"哦——"靠：

- **变脸**：同一样东西原来是另一样东西。
- **尺度跳变**：从一颗珠子到一个细胞，从一个人到一座城。
- **真算出来的结果**：计数在跳、曲线贴过去，观众感觉得到不是摆拍。
- **回到开头**：第一秒的画面在最后回来，只改了一处。

## 五、文案和画面一起写

画不出来，多半是文案的问题：句子里没有东西。所以不是先写完文案再配画面，而是先给概念找到形象，再把形象里的东西和动作写进句子。

| 画不出来的句子 | 找到形象以后改成 |
|---|---|
| 只换掉第 6 个，形状就变了。 | 只换错第 6 颗——圆圆的红细胞，就弯成了镰刀。 |
| 等级制度让冬天变得不同。 | 皇太后一天一百二十斤炭，皇孙十斤。 |
| 节气其实是按太阳算的。 | 太阳每在黄道上走满 15 度，日历就翻一个节气。 |

把道理弄懂是找形象的前提——"形状就变了"这种含糊话，正是没弄懂时写出来的（换掉那颗以后折法几乎没变，变的是表面多了一个黏点）。

## 六、三条理解加速器

**一镜一焦点。** 同一时刻只有一个视觉高点（最亮/最大/在动），就是这句字幕的主语；其余压到 20–30% 亮度。眯眼看截图，最先看到的不是主语就调。

**数字可感化。** 关键数字配一个体感锚点：生活换算、并排对比、或可数的实物。"36.8%" → 100 个小人里亮起 37 个；"14 天 / 16 天" → 同样 15° 的两段不等长的弧。遮住数字问观众"它大概多大/差多少"，答不出就是锚没给够。

**因果链连演。** 一句"因为……所以……"拆成 A → B → C 三格，用同一套图形语言在 1–2 秒里连着演（太阳走到 270° → 刻度落定 → 日历跳到 22 号）。演不出三格，说明还没想清，回去改文案。

## 七、一个世界、一把尺子、镜头有来有回

- **一个主形象贯穿全片**，结尾回到开头的画面，只改一处（状态反转）。
- **一把尺子**：全片同一比例系统（同一个轨道半径、同一条时间轴）。
- **景别要变**：全景交代在哪，中景看它做什么，近景看关键那一下；同一固定画面不撑过三四句。推近以后要拉出或切走。
- **场景之间长出来或推拉过去**：钻进去、拉出来、卷起来、倒放回去——转场本身是一个说得出名字的动作。
- **分章时每章第一句带空间连接词**（更高/更低/往里/再往下一层/同一/另一/更早/今天），章交界让同一个物再出现一次，章末给 1.5–2 秒无新字幕的总览。

## 八、每一镜过三问

遮住字幕和小字：

1. **屏上这是什么？** 用一个日常的词回答。答案是"一些点""几条线""一个圈""几根柱子"的不合格。
2. **它在干什么？** 用一个动词，就是字幕里那个动词或它的直接后果。
3. **观众因此明白了什么？** 一句话，和上一镜明白的不一样。

三问答不出，不进下一步：改画面，或回第一节换形象。

## 九、走一遍：同一段内容的两版分镜

**第一版**（主体是星点折线）

| 字幕 | 屏上 | 三问卡在哪 |
|---|---|---|
| 蛋白质，是一串字母。 | 一串星点从左长到右 | 是什么："一串点" |
| 可它要折成一个形状，才能干活。 | 星点卷成一团 | "干活"屏上没有 |
| 只换掉第 6 个，形状就变了。这就是镰刀型贫血。 | 那一团换卷法、变玫红 | 明白了"它变红了"；贫血在哪？ |

**重做**（论点：一串珠子怎么折决定它是什么，所以错一颗能改掉一个细胞的形状。形象：一串珠子和它折成的那团。镜头只推近拉远，不换场）

| # | 字幕 | 画法 | 屏上是什么，在干什么 | 小字 |
|---|---|---|---|---|
| 1 | 你的血里，有一串 146 颗的珠子。 | 照着画 | 血管里漂着红细胞；镜头钻进一个，停在一串珠子上，亮光顺珠串跑过，角上数到 146 | 血红蛋白的一条链 |
| 2 | 只换错第 6 颗—— | 照着画 | 推到开头十二颗；第 6 颗从冰蓝翻成玫红 | 谷氨酸 → 缬氨酸 |
| 3 | 圆圆的红细胞，就弯成了镰刀。 | 照着画 | 拉出细胞；它弯成镰刀，旁边的还是圆的 | — |
| 4 | 一颗珠子，凭什么？ | 提问：不画 | 镰刀停着慢漂 | — |
| 5 | 这串珠子，会自己折成一团，去抓氧气。 | 照着画 | 推回去（细胞倒放回圆）；珠串卷成球，一个氧分子落进中间的窝 | O₂ |
| 6 | 错的那颗，正好落在表面，成了一个黏点。 | 照着画 | 氧飞走；玫红珠子在球面鼓出来、一下下亮 | 黏点 |
| 7 | 一个粘一个，连成了长杆。 | 当场做一遍 | 拉远一级：第二个球卡上来，第三个、第四个……接成长杆 | — |
| 8 | 长杆从里面，把细胞顶成了镰刀。 | 回场 | 再拉远回到红细胞，杆越长越长，把它顶成第 3 镜那把镰刀 | 一个红细胞约 2.7 亿个血红蛋白 |
| 9 | 一颗珠子，改掉了一个细胞的形状。 | 只上字 | 镰刀停住 | Pauling 1949 · Ingram 1957 |

九镜两镜不画；第 3 镜和第 8 镜是同一个画面，第一次是结果，第二次是原因。这张表动手前还改过一次：最初第 1 镜是"珠子在黑底上一颗颗穿出来"，可字幕第一句是"你的血里"，屏上却没有血——**句子里的名词屏上找不到，是最容易漏的错**。

## 十、看图改图

第一次渲出来几乎都有毛病，这种片子是看着图改出来的。用 `npx remotion still` 抽同一组时刻，改完重抽同一组对比。

| 看图时发现 | 多半是因为 | 改法 |
|---|---|---|
| 主体小小缩在中间，像一条虚线、一撮点 | 尺寸按"画得下"定的 | 先定屏上大小：主体约占画面宽度六成、面积 ≥1/4（关键镜头 ≥1/3），最小单元（一颗珠子、一个字）不小于 20px；再反推缩放 |
| 遮住字幕，看不出这是什么 | 画成了记号 | 加体积材质（暗面 + 受光边 + 高光）；或从认得的画面推进去；还不行回第一节换形象 |
| 字幕里说到的东西，屏上没有 | 分镜漏了这个名词 | 画出来，或改句子。开场尤其容易漏 |
| 大片发白、发糊 | 实心大色块加了辉光 | 辉光（blur filter）只给线、珠子、字；实心的大块不加 |
| 画面又暗又空，只剩一条金线 | 主体只有线没有面 | 补中间调和体积；背景可以暗，主体不能暗 |
| 东西是平的，像贴纸 | 没有明暗 | 靠边暗一点，左上一点高光，背后垫一层很淡的底；全片一个光源方向 |
| 小字压在主体上 | 标注直接放旁边 | 拉到主体外，用细线连过去；一镜最多一条 |
| 有东西伸进字幕区 | 推近后别的部分被带进来 | 纵向 82% 以下清空；退到暗处的东西连线一起暗下去 |
| 一句字幕里画面变了三四处 | 贪多 | 拆成两句，或删掉次要的 |
| 连着几句画面没变 | 没给每句找到"那一处变化" | 回分镜表，每句写清改哪一处 |
| 转场中间几帧说不清在干什么 | 两个状态直接插值 | 换成一个说得出名字的动作（钻进去、卷起来、倒放回去），或压到半秒内 |
| 推拉先慢后猛冲 | 缩放在线性空间插值 | 在对数空间插值：`Math.exp(interpolate(f, [a, b], [Math.log(s0), Math.log(s1)]))`；焦点按 `1/缩放` 走 |

改的时候守三条：

- **看图，不看代码。** "代码应该没问题"不算数，改完重截同样的时刻。
- **动的地方看动的。** 静帧好看不等于转场说得清：在每个转场前后连抽十来帧看。
- **拿参考片当尺子。** 把自己的帧和参考片的帧并排：主体有那么大吗？认得出吗？那么干净吗？
