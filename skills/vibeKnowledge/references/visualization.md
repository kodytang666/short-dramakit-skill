# 讲解设计：配图不是讲解

> 决定片子好坏的是这一篇。风格是皮，讲解是骨。

## 1. 一个失败案例（为什么有这篇）

一条讲蛋白质折叠的片子，全片主体是一串星点连成的折线。字幕说"只换掉第 6 个，形状就变了"，折线换了个卷法、变了个颜色。颜色、字体、节奏都对——可观众从头到尾没见过蛋白质是个什么东西、错一个字母到底坏在哪。那串星点**换给任何一段文案都成立**——它是配图，不是讲解。

重做：镜头从血管里的红细胞钻进去，找到一串珠子；第 6 颗变了色；拉出来，细胞弯成了镰刀；珠串卷成一团抓住氧分子；一团粘一团连成长杆，从里面把细胞顶弯。

差别不在画技，在于观众**看见它在变**。

## 2. 五问找形象（每个概念必过）

按顺序问，问到哪里停就用哪一层的答案：

| 问 | 层 | 例子（以"复利"为例） |
|---|---|---|
| 它本身是个东西吗？ | 实物 | 银行账户里的余额数字 |
| 它是个过程吗？ | 过程 | 雪球滚下山坡，越滚越大的轨迹 |
| 它是个量吗？ | 量 | 带刻度的数轴上跳动的点 |
| 它是观众脑子里的事吗？ | 心智 | "原来如此"的顿悟瞬间（用比喻演） |
| 它是条规律吗？ | 规律 | 一堵墙：每推一次，下一次更容易推 |
| 都不是 | 上字 | 直接排版，不硬配图 |

找到雏形后再追问四个：

1. 观众在**生活里哪儿见过它**？（锚点——至少一半概念要有）
2. **换个尺度**看是什么样？（细胞→珠串；星系→陀螺）
3. 它**坏了**会怎样？（演故障比演原理更有戏）
4. 从哪个**认得的画面**进场？（先给观众熟悉的，再给陌生的）

## 3. 六种呈现动作（每拍的画面动词）

| 动作 | 什么时候用 |
|---|---|
| **演出来** | 句子里有具体动词——"砍掉一半"就真的盖住一半 |
| **数出来** | 计数器逐个跳、珠子逐颗点亮——数字是节奏锚点 |
| **量出来** | 尺子/数轴/刻度盘上的读数移动到目标位置 |
| **画出来** | 曲线按 t 生长出来（不是突然出现整条） |
| **拆出来** | 分层展开、剖面、爆炸图——复杂的东西拆给人看 |
| **换出来** | 前后两态切换对比（"不是 A，是 B"的视觉版） |

## 4. 该画的画，该停的停

参考片里**约每五句有一句不配新画面**：

- 提问句（问完的下一句画面才去回答）
- 命名句（"这就是——复利"，屏上留白让金句落地）
- 结论句、出处句
- 语气过渡句

停顿是金句的聚光灯。句句配图 = 没有重点。

## 5. 一个世界、一把尺子、几样道具用到底

- **一个主形象贯穿全片**：讲节气就从头到尾是地球绕太阳的轨道盘，不要中途换成日历动画
- **一把尺子**：全片用同一比例系统（同一个轨道半径、同一个时间轴），观众建立空间记忆后新信息才接得住
- **回场**：结尾回到开头的画面——观众看见"同一个东西，现在我看懂它了"
- 一个场景撑两句以上；每句只改**一处**

## 6. 上屏检查（每镜截图后过）

1. 主体够不够大？（占画面 1/3 以上）
2. 主体认不认得出？（遮住字幕三问：这是什么/它在干什么/我明白了什么）
3. 有没有发白、糊成一团？
4. 小字压没压在主体上？
5. 字幕区干不干净（y≈85% 以下无杂物）？
6. 转场后观众知不知道自己在哪？
7. 缩到 480px 宽，主体还认得出吗？（见 quality-gate.md §0b）
8. 近黑像素 ≤45%、中间调 ≥20% 吗？每帧有暖色/高光锚点吗？
9. 这一拍和上一拍比，观众能不能指出"哪里变了"？（每 8 秒至少一个事件）

## 7. 三条理解加速器（写完分镜逐条过）

### 7.1 一镜一焦点

同一时刻，画面只允许**一个视觉高点**——字幕这句说的那个名词，就是它。其余元素压到 20–30% 亮度：

- 说出"计数器"时，轨道盘压暗；说出"椭圆"时，数字让位
- 判断法：截一张图，眯眼看最亮/最大/在动的那个东西，是不是这句字幕的主语？不是就调
- 反例：轨道盘 + 计数器 + 右侧读数 + 分层卡同时满亮度 → 观众不知道看哪

### 7.2 数字可感化

关键数字不能孤立上屏，必须配一个**体感锚点**：生活换算、并排对比、或可数的实物。

| 数字 | 不要只写 | 补一个锚点 |
|---|---|---|
| 365.2422 天 | 一个数字滚完 | "每 4 年多出约 1 天——这就是闰年" |
| 14 天 / 16 天 | 两个数字并排 | 两段**不等长的弧**，标"同样 15°，一个 14 天一个 16 天" |
| 36.8% | 一个百分比 | 100 个小人里点亮 37 个 |

判断法：遮住数字，观众能不能说出"它大概有多大/多快/差多少"？说不出，锚点没给够。

### 7.3 因果链定格

一句结论必须能拆成 **A → B → C** 三格，并用 1–2 秒连演；演不出三格，说明还没想清，回去改脚本。

- 例（节气）：太阳走到 270°（A）→ 黄经刻度落定（B）→ 日历跳到 22 号（C）
- 三格用同一套图形语言，中间用箭头/位移连接，不要三张互不相干的图
- 这是全片"我明白了"最容易发生的地方，值得多花 1–2 秒，甚至牺牲一句字幕

判断法：把这一句的字幕遮住，只看画面，你能复述出"因为 A，所以 B，结果 C"吗？

## 8. 一镜一物一动作（从"图解"升级到"讲解"）

> 讲得清楚的关键不在画技，在**这一拍观众盯着哪个物、它在做什么**。一排标签 + 一堆数字是图解；一个物在变，才是讲解。

每拍写分镜时，强制填三格：

| 格 | 要求 | 反例 | 正例 |
|---|---|---|---|
| 物 | 一个叫得出日常名字的名词 | "等级制度" | 七筐炭 |
| 动作 | 一个屏上真的发生的动词 | "展示份例" | 炭筐按 120→10 一筐筐变矮 |
| 变化 | 这一拍结束后，它和上一拍差在哪 | "换了组数字" | 最高的筐比最低的高出 12 倍 |

三条硬规则：

1. **抽象名词必须找物理替身。** 等级→炭筐/屋顶/墙厚；差距→两堆炭的高低；制度→一杆秤、一张配给牌、一道门槛。找不到替身，说明这句话还没想清，改句子。
2. **标签不是动作。** 一排文字标签 + 一条箭头不算"演出来"；让物自己长、倒、烧、塌、被掀开、被称重。
3. **每拍只改一处。** 这一拍只让一个物的一个属性变（高度/颜色/位置/数量），观众才跟得上。

判断法：把这一拍截成静帧，问"如果我是第一次看，能不能指着画面说：这是____，它在____？"两个空都填不出，重做。

## 9. 四种景别，别用同一种构图讲全片

一支 130 秒的片子至少要有四种景别，且**不允许连续三拍同一种**：

| 景别 | 用途 | 例（本实验） |
|---|---|---|
| **建立全景** | 交代"这是哪儿/有几种人" | 一场雪落在五种屋顶上 |
| **剖面/拆解** | 讲"热怎么走/里面是什么" | 火墙夹层、火炕火道、椒房泥墙断面 |
| **物特写** | 讲"这个东西值多少钱/怎么用" | 手炉、汤婆子、纸被、红纱系上牛头 |
| **总览/阶梯** | 把四层人放进同一画面比较 | 120→10 的炭堆阶梯、四层屋顶剖面 |

节奏线：**每 20–25 秒至少一次景别变化**；全片至少 3 次硬切（不是淡化）。只有"左图右字 + 缓慢推拉"一种构图，观众会在第 30 秒失去空间感。

## 10. 章节桥：让四层人接得上

分段讲阶层/层级/流程时，观众最容易迷路。每章第一句必须带一个**空间连接词**，把上一章的位置接过来：

- 更高 / 更低 / 再往下一层
- 往里 / 往外 / 墙里 / 屋顶下
- 同一 / 另一 / 反过来
- 更早 / 后来 / 今天

例："更早的秦宫，墙是空心的" → "往北走，屋子中间是一铺炕" → "再往下一层，连炭都没有" → "真正稀缺的不是火，是留住热的那层"。四句把"墙上→地下→炕→没有"接成一条线。

再加两个动作：

- **母题回场**：每章交界处让同一个物再出现一次（一片雪/一块炭/一道墙线），观众知道"还在同一个世界"。
- **总览停顿**：每章结尾给 1.5–2 秒无新字幕的总览画面（阶梯/剖面/全景），让观众把这一层放回整体。不要用一句话硬转下一章。
