## 分镜自检（写完逐行过，不过不进工程实现）

- [ ] 每拍"屏上主体"都叫得出日常名字；无空镜/纯色/黑场行（片名卡与转场拍除外，且数量计入无字幕预算）
- [ ] 每拍"呈现动作"非空——该拍字幕里的动词屏上真的发生
- [ ] 相邻两拍构图不同（位置/大小/视角至少变一样）；连续放大不超过两拍，推近后要拉出或切走（镜头=标点，有来有回）
- [ ] 模拟段每幕写明：一个主动作 + 2–4 个取自主形象的母题循环（呼吸/摆动/流动），保证画面一直在动
- [ ] 文字主导的拍 ≤ 30%；1/5 左右的句子无新画面（留白拍在表里标"停"）
- [ ] 拍点镜（对齐 BGM 强拍的揭晓/金句/读数）已在 ★ 行标注"卡点"
- [ ] 每拍"主体占%" ≥25（★ ≥33）；主体缩在角落的拍先放大，不许靠字幕解释
- [ ] "本拍事件"列非空：每 8 秒至少一个物变/数字/景别/硬切；最长空档 ≤8 秒
- [ ] 四种景别至少用三种；连续三拍同一景别 = 红灯；全片 ≥3 次硬切
- [ ] 每章第一句有空间连接词；章末有 1.5–2 秒无新字幕的总览停顿
- [ ] 常驻 HUD（年代签/刻度/页眉/框）≤30% 时长，同屏 ≤2 个
- [ ] 最后一镜是主形象的状态反转，不是金句卡/引用墙
- [ ] 抽 8–12 帧缩到 480px 排网格：每格主体可辨、无连续三格同构图、无一片近黑
