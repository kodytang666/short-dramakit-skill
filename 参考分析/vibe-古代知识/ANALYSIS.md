## 一、这片子想达成什么

讲清唐代长安宵禁制度的**因果链**：暮鼓闭门 → 坊墙隔断 → 犯夜有罪 → 夜里有例外 → 天亮鼓响开城。观众带走的不是知识点清单，而是一个可复述的悬念答案——"天黑前没进城，会怎样？晚一鼓，多等一整夜。"

## 二、为什么成立（解读）

1. **全片是一个"夜晚"**。色温即叙事时钟：暮红（0:00）→ 卷轴米黄（0:26）→ 夜蓝（0:42）→ 黎明金（2:24）。观众不需要字幕就知道时间在走，画面本身在讲故事。
2. **计数器用了两次，首尾回环**。开场暮鼓 0→600 鼓（0:04–0:24，城将闭），高潮晨鼓 0→3000 鼓（2:00–2:18，城将开）。同一视觉装置装相反的情绪（焦虑→希望），这是全片最高级的结构手法。
3. **大字卡是节拍器**。黑屏问句卡（0:56"那被关在城外的人呢？"）承担反转；红金大字术语卡（0:46"犯夜"、1:24–1:28"徒二年半→减一等"）承担罪名与刑罚的份量感。大字卡出现处正是 BGM 强拍。
4. **注解层三级分工**：小标签（坊名/店名/地点，红底白字，随主体出现）管识别；底部双语字幕管叙述；白线注解图（1:30–1:34 城墙剖面）管数字关系。三层互不抢。
5. **收束用透视不用引用墙**。黎明朱雀大街一点透视 + 金字"晚一步，就是一整夜"+ 小副题"唐代长安 · 城门与夜禁"（2:24–2:44）。采样帧内未见独立学术引用卡——本片用"地点标签（右上，唐·长安·朱雀大街）"替代了出处展示。
6. **具体名词撑起实感**：朱雀大街、常乐坊、热汤一张榻、四更一点、杖七十。全部是"叫得出名字的物"，无一句抽象概括。

## 三、系统清单（事实）

- 画幅 960×530（平台压缩产物，原制应 1080p）；30fps；BGM 单声道铺底。
- 布局：中央动画 + 底部双语字幕（中上英下）+ 角落红底小标签 + 大字卡层。
- 转场：硬切为主；一次卷轴纸纹全屏转场（0:26）；黑屏卡承担段落切换。
- 计数器样式：大数字 + 单位"鼓/坊"，主体旁持续跳动，配caption一句。
- 场景：城门立面（暮/夜两版）、鼓楼、坊市红格地图、坊墙、夜街灯笼、城墙、大路、客店、黎明大道。同一城门立面复用于暮/夜/晨三种光。
