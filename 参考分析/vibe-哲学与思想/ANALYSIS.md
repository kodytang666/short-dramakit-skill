## 一、这片子想达成什么

推翻观众的直觉排序——"最坏的罪是最显眼的那 个（色欲）"，换成教父哲学的答案：**排第一的是最看不见的傲慢**。观众带走的不是七宗罪名词表，而是一句可复述的论点——"七宗罪排第一的，不是最显眼的那个，而是最看不见的那个"（1:40–1:48），外加一次被点名的刺痛——"93% 的人认为自己开车高于中位数"（1:28–1:32）。

## 二、为什么成立（解读）

1. **观念史被译成"结构升级史"**。同一个问题"傲慢凭什么第一"，四位思想家各给一个视觉结构：埃瓦格里乌斯的 8 枚恶念徽章行（0:18–0:24）→ 格里高利的名单与根须（0:28–0:32）→ 阿奎那的天平（0:42–0:52）→ 但丁的炼狱山（0:54–1:12）。每次换结构=观念升级一层，概念对话不靠两人对辩，靠"一份名单被四次重排"完成——概念对话型成立，且比辩论型更稳。
2. **亮度分配就是论点本身**。全片以暗场为底，唯一暖亮段是 1600 年前的沙漠太阳（0:12–0:26，源头最亮）；结尾反向走暗：七画像逐个熄灭、只剩傲慢独亮（1:44–1:48），收束停在近黑的七拱暗廊（1:50–1:58）。"看见/看不见"不是说出来的是演出来的——色温弧与古代知识片相反（那边越走越亮的黎明金，这边越走越暗）。
3. **排序用"位置"不用"跳动计数器"**。序号徽章（0:18）、炼狱山台阶层号 1–7（0:58–1:10，1 在底 7 在顶）、天平倾角（0:46–0:52）三级递进。数字从不计时，重量与海拔承担排序——这是"排位"题材对计数装置的替换方案。
4. **关键句有专属版式**。普通叙述为双层中文字幕（顶部小字承接上句、底部落当前句）；论点句升级为衬线大字 + 上下金色细线框 + 关键词金色高亮（1:49 "而是**最看不见**的那个。"，见 `结尾渐暗` 帧）。片名卡前置（0:10 玫瑰窗徽记 + 大金字"七宗罪"），结尾只给小号金字回声（1:52 起）——首尾版本式对称。
5. **现代数据是"照镜子"拍点**。93% 方块华夫图（1:28–1:32，1995 年调查"开车水平高于中位数"，来源机构未标注，待核）是全片唯一现代场景，把教父神学翻译成"优于平均效应"，观众从看历史变成被看——古典概念落到"你"身上，irony 完成最后一击。
6. **具身隐喻托底，杜绝文字主导**。每个抽象论断都配身体动作："被欲望拖走 vs 自己转身"（0:52 天平两盘）、傲慢层小人背巨石弯腰（1:00）、"先卸下傲慢才能继续向上"（1:10）、其余罪"从它身上长出来"的根须/辐射线（0:32、1:18）。铁律成立：每句字幕都有一个画面动作。

## 三、系统清单（事实）

- 画幅 960×720（4:3，平台压缩产物）；30fps；HEVC；单声道 AAC（BGM 铺底）。
- 布局：中央彩绘玻璃动画 + 双层中文字幕（顶部承上句 / 底部落当前句，采样帧内未见英文，单语，待核）+ 拱窗下深底金字名牌小标签（傲慢/嫉妒/愤怒/懒惰/贪婪/暴食）+ 红底分类标签（"五种·心罪""两种·身体"，0:36）。
- 字体：中文衬线（宋体类），关键词金色；论点句上下加金色细横线。
- 转场：硬切为主；0:26→0:28 暖→冷色温硬切是唯一大色温跳变；1:12→1:14 场景切换；1:40–1:52 渐暗收束；无全屏纹理转场（对比古代知识片的卷轴转场）。
- 计数器样式：无跳动计数器；用 8 枚恶念徽章行（0:18）、台阶层号 1–7（0:58 起）、100 格华夫图 + 大号金色"93%"（1:30）。
- 场景列表：七连拱人物墙（5 次复用：0:00 开场 / 0:34 分组货架 / 1:20 两像并置 / 1:34 定义对比 / 1:40 渐暗）、玫瑰窗片名卡（0:10）、沙漠洞穴太阳（0:12–0:26）、教宗高塔与根须（0:28–0:38）、单拱人物过渡（0:40）、金色天平（0:42–0:52）、炼狱山（0:54–1:12，全片最长单场约 18 秒、一次连续上行运镜）、傲慢辐射网（1:14–1:18）、93% 方块图（1:28–1:32）、暗廊收束（1:50–1:58）。
- 结尾样式：暗场七拱廊、傲慢独亮 + 尘埃粒子 + 斜入光束（1:50），底部小号金字"七宗罪 · 为什么傲慢排第一"两侧金细线（约 1:52 起，见收束卡帧）；**无副题行、无独立学术引用卡/来源行**，出处以字幕内嵌（"4 世纪""公元 590 年""13 世纪""1995 年，调查"）。
