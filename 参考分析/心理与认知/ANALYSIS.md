## 一、这片子想达成什么

推翻"学得久 = 学得会"的默认信念，把观众从"被动摄入"扭到"主动留存"：先连开三张病历（划重点反复读 / 临时抱佛脚 / 被动学习），再给三步药方（费曼讲出来 / 间隔重复 / 习惯化）。观众带走的是一句可复述的金句——"再好的方法，不坚持也是漏桶；每天一点点，胜过考前一夜拼命。"

## 二、为什么成立（解读）

1. **一个隐喻管全片，首尾回环且状态反转**。"知识=水，记忆=桶"在 0:14 登场（白柱灌水、蓝水、桶底红点漏水），消失整整两分钟后在 2:14 复现——同一个桶，水从漏光的蓝变成注满的金（2:17–2:21）。开场它证明"你会漏"，结尾它证明"你能存"：全片论点被一个道具的状态变化物化了。
2. **病→药结构，先扎足再给糖**。错误 01（0:24 划重点·反复读）、错误 02（0:40 临时抱佛脚）、错误 03（0:58 被动学习）三张章节卡全部落在前 1 分钟，每个错误都配一个"会出事"的具身场景（10% 回忆率、箱子倒进垃圾桶、火柴人溺水）；1:38 才开始开药方。诊断的密度远高于处方，焦虑先建立，解法才值钱。
3. **每个抽象概念都换算成一个会疼的身体动作**。这是本片最高级的机制：被动学习=读完游泳书跳进泳池"你会溺水的"（1:00–1:08，火柴人沉底冒泡）；硬记=熬到 03:00 拼命往箱子里塞、塞到关不上（0:42–0:48）；遗忘=桶底漏（0:14）；回忆=合上书写半页纸（1:50）。抽象的认知科学全程没有以术语面孔出现。
4. **所有数字挤在一条语义轴上**：80% 流失（0:04）、10% 回忆得起（0:30）、金字塔 10→90%（1:24–1:36）、忘掉一半（1:54）、第 1/3/7 天（2:00）。观众反复被同一根"留存率"轴敲打，不需要记术语也记住了方向——低的是灰，高的是金。
5. **学术诚实用两行小注脚完成，不设引用卡**。金字塔图底部"注：学习金字塔是流行的经验模型，百分比并非严格的实验数据，看趋势即可"（1:31）；遗忘曲线底部"艾宾浩斯（1885）用无意义音节做的经典实验 · 曲线为示意"（2:00）。作者+年份+方法+免责一句话打包，权威立住了，节奏没断。
6. **收束不换新概念，把"坚持"也装回漏桶里**。结尾三行字（2:17–2:21）"再好的方法，不坚持也是漏桶 / 每天一点点 / 胜过考前一夜拼命"——方法论升级成习惯学，但视觉母题没换，金水注满桶身即收。无片名卡、无副题卡、无引用墙。
