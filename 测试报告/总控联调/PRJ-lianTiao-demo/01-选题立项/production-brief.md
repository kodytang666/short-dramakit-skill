## 四、题材卡要点（GEN-01 悬疑日常）

- 压力来源：日常秩序中的不可解释之物
- 爽点与桥段：解谜推进 / 背脊发凉时刻 / 反转揭晓
- 追看引擎方向：调查升级 + 线索三段式揭晓 + 倒计时（订单到期）

## 五、受众与爽点要点

- 情绪需求：悬念紧抓 → 亲情反转的双段情绪（前惊后暖）
- 弃剧点与规避建议：悬念 2 集不推进即弃；规避=每集至少兑现一条信息增量；惊悚越过恐怖线即弃；规避=止步氛围（DEC-2）
- 开场钩子方向（含 IP 入口的开篇替换点结论）：冷开——监控回放直接开场，前 3 拍见机器人（非 IP 项目，无开篇替换点）

## 六、制作可行性预警（交阶段四/五/六/七提前规避）

- 无人机外观全流水线一致性：阶段四必须建 PROP-1 资产卡 + LOCK 连续性锁，全部无人机镜头共用同一参考图（RSK-3；DEC-7 修订，v1 为机器人）
- 监控时间戳 / 订单小票等画面文字：关键叙事文字，建议阶段七后期统一叠加，阶段五分镜时留出画面空间
- 无人机动作保持常见动作库（悬停、机械爪取杯、飞行、升空离开），不设计精巧微动作；**注意：无人机无法自行开门，取货入侵路径（排气窗/送餐口）需阶段二 v2 定稿后阶段四才能落资产**（DEC-7 新增预警）
- 声音设计注意：旋翼声将取代机械足声成为无人机登场的听觉签名（阶段七）
