## 一、人物档案

### CHAR-1 沈棠（lead）
- 一句话定位：用理性硬扛世界的奶茶店老板娘， 直到世界拿出她无法 rationalize 的东西。
- 小传（≤200 字）：32 岁，独自经营亡母留下的奶茶店。母亲病重半年，她因店里的流水没赶上最后一面，只来得及接手一个还飘着奶香的后厨。她把愧疚折算成每天开门、打烊、数杯子——数字不会骗人。直到监控里的机器人在 23:17 拿走三杯贴着母亲手写便签的奶茶，她第一次数不明白了。
- 说话方式（口癖/句长/语气特征，供阶段三写台词校对）：短句、冷幽默、爱用反问和数字说话（"一百零八，一杯不少"）；情绪波动时不喊叫，改低声重复关键词。
- 目标 / 筹码 / 底线：守住店并查明真相 / 监控录像与订单小票、周野的后台权限 / 不卖店、不放过任何一个关于母亲的线索。
- 弧光：起点信念（数字与秩序可控，愧疚用经营偿还）→ 压力测试 1（EP02，发现机器人只拿母亲配方便签那三杯——愧疚有了形状）→ 压力测试 2（EP08，发现订单是母亲下的——她以为没来得及的告别其实被母亲提前安排了）→ 转变触发（EP10，23:17=母亲去世时刻）→ 终点状态（EP12，接受告别可以迟到，订单到期日主动续上新的一杯）
- 关系：与 CHAR-2 周野（调查同盟，互为对方不敢碰的软肋的镜子）；与 CHAR-4 沈慧茹（亡母，未完成的告别）

### CHAR-2 周野（lead）
- 一句话定位：城市配送系统的守夜人，追查一台数据库里不存在的设备，也在追查自己没接住的一通咨询电话。
- 小传（≤200 字）：28 岁，城市智能配送运维员，值夜班，负责追踪全市配送设备的信号。他在后台发现一台无注册号的原型机连续多晚在同一路线活动，按规程应上报封存——但上报意味着这台"活着的遗物"会被拆解。他见过它的注册申请：发起人签名是沈慧茹。
- 说话方式：技术员式精确、句中带设备术语但会自我翻译成大白话；被戳中旧事时答非所问。
- 目标 / 筹码 / 底线：查清原型机为何仍在运行 / 系统后台权限、原型机档案 / 不违规外泄用户数据——直到沈棠出示小票（EP09 后底线松动，记 DEC 或剧本层备注）
- 弧光：起点信念（规程至上，拒绝即正确）→ 压力测试 1（EP05，为拖住上报时限向沈棠隐瞒自己见过注册档案）→ 压力测试 2（EP07，原型机来历揭晓，他认出发起人）→ 转变触发（EP09，坦白沈母曾来电咨询而他按规程拒绝）→ 终点状态（EP12，选择让原型机"退役"进店门口当摆设而非进报废流程）
- 关系：与 CHAR-1 沈棠（同盟→并肩）；与 CHAR-4 沈慧茹（曾拒绝对她的咨询请求，负罪）

### CHAR-3 老郑（support）
- 一句话定位：片区老民警，按常识办案，常识破不了案但能守住人。
- 小传（≤200 字）：55 岁，片区民警，看着沈慧茹的店开了二十年。沈棠来报案"机器人偷奶茶"，他婉拒立案但留了心，帮她调了周边的公共监控。
- 说话方式：家常、绕弯、爱拿吃的一边让一边谈正事。
- 目标 / 筹码 / 底线：片区平安 / 公共监控调阅权 / 不越权立案、不拿没有的事吓唬人。
- 弧光：不设（support 担纲功能：官方渠道的合理解释者与 EP11 的助攻）。
- 关系：与 CHAR-1 沈棠（看着她长大的长辈）；与 CHAR-4 沈慧茹（旧识，欠她一句"你女儿挺好的"）

### CHAR-4 沈慧茹（support，已故，不出场）
- 一句话定位：用最后一个订单安排告别的人。
- 小传（≤200 字）：沈棠母亲，生前是智能配送试点项目的测试用户协调员，退休前参与过原型机"小零"的日常测试。确诊后她下了最后一个订单：每天 23:17，三杯奶茶，备注分三条。她去世前一周完成下单，去世当天 23:17 停表。
- 说话方式（仅存在于备注文字/录像中）：温吞、爱用省略号、每句话都像顺便一提。
- 目标 / 筹码 / 底线：（生前）让女儿在没有自己的店里也能被奶茶香接住 / 原型机的测试权限与私交 / 不让女儿提前发现订单
- 弧光：不设（已故人物，功能为真相层；其"弧光"通过三段备注倒叙呈现）。
- 关系：与 CHAR-1 沈棠（母女）；与 CHAR-2 周野（咨询被拒的来电者）；与 PROP-1（测试员与原型机）

## 二、叙事道具

### PROP-1 外卖机器人（原型机"小零"）
- 功能：每晚 23:17 取走三杯奶茶的执行者；全剧悬念的核心载体与真相的物证。
- 托起：悬念爽点（EP01-03）/ 反转与泪点（EP07、EP08、EP12）
- 判据复述：它坏了、丢了、被换掉，剧情会塌——没有它，丢失事件不成立、订单无从执行、真相无实物可回溯。

### PROP-2 三杯奶茶（母亲手写配方便签）
- 功能：数量之谜的悬念扣 + 三段备注的物理载体，三段式揭晓结构。
- 托起：悬念（EP01）/ 情感反转（EP04、EP08、EP11）
- 判据复述：三杯与便签是"母亲在场"的唯一可见证据，抽掉则真相失去抓手。

### PROP-3 订单小票（编号模糊）
- 功能：连接异常与真相的钥匙，引出周野与后台数据。
- 托起：调查推进爽点（EP03、EP06）
- 判据复述：没有小票，沈棠无法证明"有订单"，周野入伙缺媒介。

## 四、世界观规则

1. 本市智能配送系统已商用的是"配送柜+骑手"，人形配送机器人仅停留在原型机测试阶段，从未公开上线（全剧"不该存在"的依据）。
2. 原型机无注册号则无信号回传，城市追踪系统对它不可见（"不可追踪"的依据）。
3. 订单一经锁定服务周期，执行不因账户状态（含用户身故）终止——订单系统的机械忠诚（真相的装置性依据）。

## 五、时间线

故事内时间跨度约三周（EP01 发现 → EP12 订单到期日）。锚点：每晚 23:17 为机器人取货时刻；母亲去世于故事开始前六个月；订单发起于去世前一周（EP03 揭晓）；23:17 = 母亲去世当天停表时刻（EP10 揭晓）。
