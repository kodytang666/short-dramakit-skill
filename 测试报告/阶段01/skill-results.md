## 测试 A：常规任务 ✅

执行 Agent 报告：可执行性高，流程闭环无阻断。产出三份文档（选题评估报告/项目立项书/制作简报），自检清单 8 项全过。

亮点证据（摘自 `test-A-常规/选题评估报告.md`）：
- 六维三行字段齐全，每维证据强度三选一标注（统计：实测 3 / 推断 11 / 待验证 4）；
- 受众画像卡四栏完整，弃剧点预测含"尸检画面引发生理不适或平台限流 [待验证]"这类 AI 制作特有洞察；
- 对标四步法正确执行（同/异/跟随 vs 差异策略），未编造对标数据；
- 五维评级给出"凶手蒙面/背影处理降负担"等具体可执行的缓解建议；
- 立项书 PRJ 编号、DEC 决策 4 条、审批区注明"未停靠自动立项"；简报 9 条已定事实均带出处。

## 测试 B：复杂 IP 任务 ✅（发现规则缺口后已修复）

产出三份文档：四类判定 80%/20%/0%/0%（分母 5 章梗概）、覆盖率声明 3.3%、结论"调整后立项"、风险 5 条、DEC×3。

执行 Agent 指出的核心缺口：Skill 原版对"简介+部分章节梗概（非原文全文）"输入无分支规则。**已修复**：ip-evaluation.md 新增"材料降级规则"三档表（全量/抽样/降级），明确降级档的判定分母、[推断] 标注义务与记忆补细节禁令；SKILL.md 信息采集新增"B 入口专用：能否提供原文全文"必问项。

## 测试 C1：一句话点子边界 ✅

处理路径：一次补充询问（平台/集数时长）→ 用户沉默 → 按建议值继续（付费卡点、70集×90秒，标 [待验证]）→ 完成六维评估 + 2 个机制不同候选 → 总评"调整后立项"，停在停靠点未写立项书。六问中 3 问因输入不足如实判"无法判定"，未编造。

发现：原版未明示"询问后沉默"的处理 → **已修复**（信息采集规则补"问过之后仍未提供时按建议值继续并声明"）；原版证据强度枚举无"信息不足"档 → **已修复**（停靠节新增"信息不足，无法判定"规则 + 超两维时建议补齐）。

## 测试 C2：只有书名 ✅（规则咬合验证通过）

处理：拒绝启动评估，索要简介或原文，零剧情脑补。

Agent 验证三处规则互相咬合：核心立场"不脑补"（SKILL.md 核心立场 3）、入口分流"只有书名、无简介无原文：不启动评估"、常见错误表首行。且证据纪律结构性封死绕行：凭记忆的内容无法标 [实测]/[推断]，四类判定分母必须是实际阅读章数——硬跑必然过不了自检。
