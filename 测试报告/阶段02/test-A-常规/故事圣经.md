## 一、人物档案

### CHAR-1 沈知微（lead）
- 一句话定位：被凶手选中的验尸人——唯一能把妹妹之死从"意外"里验出来的人。
- 小传（≤200 字）：十年前妹妹沈知夏"意外溺亡"，鉴定签字"意外"，她不服但无据；家里烧掉遗物、不许再提。她把余生抵押给这个疑点：读法医、进市局法医中心，把卷宗疑点抄进随身错题本。妹妹出事当晚的最后一个未接来电，是她十年的自我刑罚。她极度可靠、不允许情绪被看穿；在沈家，她是相亲宴上被公开议价的人。
- 目标 / 筹码 / 底线：把妹妹之死重新定性并钉死真凶／全省前三的病理鉴定能力+凶手指名带来的不可替代性／不伪造证据、不出卖职业身份——哪怕代价是失去翻案机会。
- 弧光：起点信念"只要我足够专业、足够有用，就没有人能再否定我"→ 压力测试 1（EP10，订婚宴：第一次当众拒绝被安排的人生）→ 压力测试 2（EP31，验尸资格被吊、被传唤：没有头衔时她还是不是她）→ 转变触发（EP34-35，纪风之问："你查真相是为了她，还是为了自己能被原谅？"）→ 终点状态（EP40，翻案完成；她第一次不为"被原谅"而活：合上错题本、封存发卡、接受阳光与"约饭"）。
- 关系：与姑妈沈桂芳（施压者→被她当众揭穿）；与母亲周慧兰（十年隔阂，实为被母亲沉默保护）；与顾野（被担保→并肩→被爱）；与纪风（职业搭档→凶手→"姐弟"式告别）；与妹妹（罪感与爱同一来源）。
- 画面代称（占位，阶段四用）：解剖灯下的白大褂背影。

### CHAR-2 顾野（lead）
- 一句话定位：把程序当信仰、又为她破了例的专案组组长。
- 小传（≤200 字）：新人时期在水库警戒线外给崩溃的沈知微递过一把伞，此后十年把"没帮她"记成私账。程序主义者，信卷宗不信直觉。师父曹建国当年压下水库案疑点，是他心里一根刺。他对沈知微的担保，一半为她，一半替十年前的自己还账。
- 目标 / 筹码 / 底线：办成经得起翻的铁案／专案组主导权+十年干净记录／不留任何越界记录——终局为破例全程布控留痕，把"例外"关回程序里。
- 弧光：起点信念"卷宗结了就是结，规矩保护所有人"→ 压力测试 1（EP06，自曝隐瞒力保沈知微：第一次把人排在程序前）→ 压力测试 2（EP16/EP22，师父之死+自己被停职：规矩被裴修当武器）→ 转变触发（EP16，忏悔录音：师父的罪在人不在规矩）→ 终点状态（EP37，用程序的方式打赢不规矩的人；EP39，逆光递伞收束）。
- 关系：与沈知微（担保人→并肩者）；与曹建国（师父之罪与愧疚）；与纪风（完美同僚→对手→收网对象）；与裴修（程序与权力的正面冲撞）。
- 画面代称（占位）：警戒线外递伞的逆光剪影。

### CHAR-3 纪风（lead）【内部文档：真实身份揭示于 EP34，对外材料须遮蔽本条真实身份段】
- 一句话定位：省厅借调的痕检顾问——坐在她对面的那个人，就是写谜的人。（真名程屿，沈知夏当年恋人，连环案凶手）
- 小传（≤200 字）：十年前他是知夏的大学同学。案发夜他在警戒线外跪了一整夜，随后被沈家与警方当作"闹事者"驱逐。他查了十年：定性人、场地人、鉴定人、执行人咬合成一条链。绝症确诊后，他决定用最后的生命把链子一节节敲碎——杀有罪者取证，在尸体上留下只有沈知微能读出的线索，逼唯一有资格翻案的人回到解剖台。明面他是完美顾问：细致、克制、可信，坐在她对面看她验他布置的谜。
- 目标 / 筹码 / 底线：死前把妹妹之死翻成"他杀"并钉死主谋／十年证据链+对每个死者的罪证+警方内部信息位／不伤沈知微、不把她的家人变成棋子（尽管姑妈收过钱）。
- 弧光：起点信念"我的命只值这一个用途"→ 压力测试 1（EP10，订婚宴看她反杀：第一次怀疑该不该把她拖进来）→ 压力测试 2（EP24-28，裴修盯上她：必须打乱完美计划保她）→ 转变触发（EP34，被她叫出真名：他准备的结局里没有"她还愿意听我说"）→ 终点状态（EP39，把审判还给法律、把自己还给知夏：以"最后的尸体"完成取证，死于她将亲手归档的报告里）。
- 关系：与沈知微（错位信任→摊牌→托付）；与沈知夏（全部动机与底线来源）；与裴修（猎人猎物互为）；与顾野（被识破前的完美同僚）。
- 身体特征锁（连续性）：左耳听力受损（侧右耳听话/戴单侧耳机，EP07 埋）；晚期病症（注射/药物痕迹，EP12 起以"凶手健康画像"形态浮现）。
- 画面代称（占位）：单侧耳机的侧影。

### CHAR-4 沈知夏（lead，殁——缺席主角）
- 一句话定位：死了十年的妹妹，仍在每一案里作证的人。
- 小传（≤200 字）：殁年 19，实习护士。善良到"多事"：救人不看场合、记录不看后果。十年前在半岛湾会所聚会目睹裴修酒驾顶包现场，随后"溺水意外"。她的善良在十年后成为破案钥匙——留给恋人的信、职业本能的记录习惯，让她死后仍在作证。
- 弧光（倒叙式，以证据人格推进）：起点"想成为救人的人"→（回忆节点 EP20：最后一封信；EP28：她死前的选择经母亲证词补全）→ 终点"十年后救了所有人"——她以证据人格存在于每一案，全剧对她的每一次发现都是一次"迟到十年的作证"。
- 关系：与沈知微（罪感的来源，也是她全部温柔的来源）；与纪风（互相守护，至死未寄出的信）；与母亲（倒扣的杯子）；与裴修（目击者与灭口者）。
- 画面代称（占位）：水面倒影与蓝琉璃发卡。

### CHAR-5 周慧兰（support）
- 一句话定位：用十年沉默给活着的女儿当围墙的母亲。
- 小传：十年前被威胁"再查，你剩下的女儿也会'意外'"，签字接受结案；用沉默给沈知微当围墙。家里永远倒扣着一只杯子。目标：保住活着的女儿；筹码：真相（她知道的事比所有人以为的多）；底线：女儿活着。
- 简弧光：沉默（EP08 失神警告"你妹妹会疼"）→ EP28 真相（保护性囚禁）→ EP40 当众说出真话、揭穿姑妈。
- 关系：与沈知微（隔阂与暗中护卫）；与沈桂芳（被裹挟的姐妹）；与"威胁者"（十年恐惧）。

### CHAR-6 沈桂芳（support）
- 一句话定位：逼婚主导者——也是当年把侄女之死折成钱的牵线人。
- 小传：沈家话事人，当年"跑前跑后办完后事"的功臣——实为赔偿牵线人，用分润换了新房。她真心认为"钱到位=体面"，把逼婚当慈善。目标：沈家的体面（=她的权力）；筹码：长辈话语权+当年"办事"的道德资本；底线：不能让人知道那笔钱。
- 简弧光：面子至上 → EP08 失言"赔偿签字" → EP30 资金流查实 → EP40 被母亲当众揭穿，家庭话语权崩塌。
- 关系：与沈知微（施压者/被打脸对象）；与"某人"（EP08 深夜报信，未露脸）；与周慧兰（共谋与互相拿捏）。
- 功能：家庭线打脸主要载体（EP08/EP10/EP30/EP40 四节点）。

### CHAR-7 裴修（support）
- 一句话定位：习惯"一切可买"的本地权贵——十年前灭口案的真正主谋。
- 小传：35 岁，裴氏集团继承人。十年前酒驾撞死环卫工，父亲安排顶包；目击的实习护士被"处理"成溺水意外。他杀人外包、从不脏手，直到凶手把他链条上的人一节节杀掉。目标：链条永埋；筹码：钱、权、与体制内的代理人；底线：自己不脏手——EP37 被逼破戒，破戒即落网。
- 简弧光：一切可买 → EP24 第一次遇到"买不动的人"（沈知微全身而退）→ EP30 嫁祸成功在望 → EP37 亲自下场灭口未遂，"可买的世界"被现行证据击穿。
- 关系：与沈知微（威胁与反威胁）；与凶手程屿（灭口者与猎物，互为）；与曹建国/姑妈（用后即弃的棋子）。

### CHAR-8 曹建国（support）
- 一句话定位：顾野的师父——当年压下疑点的人，也是疑点最后的活证人。
- 小传：58 岁，退休民警。当年受上级压力与自身怯懦压下"指甲缝皮肤组织"疑点，退休后癌症缠身。目标：死前卸下良心债；筹码：忏悔录音+旧样本下落；底线：不亲手递（愧对徒弟）。
- 节点：EP15-16 交出忏悔录音，当晚"病危"（裴修灭口，伪装医疗事故）。
- 关系：与顾野（师徒与愧疚）；与秦鸿儒（当年共谋签字链）。

### CHAR-9 许乐（support）
- 一句话定位：存疑十年的调查记者——舆论引擎。
- 小传：29 岁，当年报道过水库"意外"，十年存疑。流量动机与真相动机同向不同速：半盟友半对手。目标：挖出连环案与十年前案的关联；筹码：传播渠道+当年采访底档；底线：不编造。
- 节点：EP06 首发质疑（引爆"意外"进入公共视野）→ EP18/EP27 顶住收买 → EP37 同步引爆收官。
- 关系：与沈知微（互相借力）；与裴修（收买与反收买）。

### CHAR-10 小唐（support）
- 一句话定位：助理法医——解剖室的温度与递话人。
- 小传：27 岁，沈知微的助理。目标：成为像师父一样的法医；筹码：实验技术与忠诚；底线：不越权出报告。节点：EP12 起协助建立"凶手健康画像"。
- 关系：与沈知微（师徒式信任）；与专案组（技术接口人）。

### CHAR-11 沈甜甜（support）
- 一句话定位：姑妈的女儿——被安排人生的对照组。
- 小传：22 岁，"听话人生"的样本。目标：看清自己家；筹码：家内视角的情报；底线：不替母亲撒谎。节点：EP08 桌下握手 → EP14 递出"姑妈当年换房"情报 → EP40 宣布独立。
- 简弧光：顺从 → 站队 → 出走。
- 关系：与沈知微（暗中的同盟）；与沈桂芳（母女离心）。
