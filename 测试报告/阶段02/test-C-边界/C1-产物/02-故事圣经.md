## 一、人物档案

### CHAR-1 苏晚（lead）
- 一句话定位：把直播间当翻案法庭的三流女主播。
- 小传（≤200 字）：24 岁，全平台排名三百开外的小主播，靠直播替父亲还"死后"留下的债、撑起母亲的家。五年前父亲苏建国"车祸身亡"，公司倒闭、债主上门，她从准大学生变成家里唯一的收入来源。嘴硬心热，镜头感极佳，习惯用话术把事故圆成节目效果——直到一场连麦让她发现"死去的父亲"一直在榜单上看着她。
- 目标 / 筹码 / 底线：查明父亲失踪真相并公开团圆；筹码＝持续升温的直播间热度＋父亲只肯在直播间出现；底线＝不消费父亲的眼泪（拒绝把认亲做成剧本炒作）。
- 弧光：起点信念"直播只是还债工具"→ 压力测试 1（EP02，拒绝 MCN 把泪崩炒成剧本，代价 80 万违约金）→ 压力测试 2（EP05，父亲拒绝相认仍不放弃）→ 压力测试 3（EP40，父亲身份当众暴露危机中顶着封杀风险开直播）→ 转变触发（EP60，挡刀事件）→ 终点状态"直播间是守护父亲的阵地，敢用流量对轰资本与旧敌"。
- 关系：与 CHAR-2（父女，他躲她追）；与 CHAR-3（被其暗中相助，立场存疑到信任）；与 CHAR-4（被合同拿捏后决裂）；与 CHAR-8（闺蜜同盟）。

### CHAR-2 苏建国 / 榜一"老树"（lead）
- 一句话定位：在榜单上沉默守护女儿的"死人"。
- 小传（≤200 字）：55 岁，前"树深贸易"老板。五年前被深蓝集团设局背上天价债务、伪造车祸"死亡"，靠空壳公司通道转移最后一笔资产，从此隐姓埋名。他不能相认：认了，深蓝就知道账本还在，女儿会被卷入追索。于是他做了唯一被允许的事——注册小号"老树"，把打赏当成匿名汇款的延伸，在她每一场直播里守着。右耳后有旧疤，哼得出女儿幼年的摇篮曲。
- 目标 / 筹码 / 底线：暗中守护女儿＋攒够翻案证据；筹码＝藏起的账本（深蓝罪证）＋空壳资金线；底线＝绝不让女儿卷入深蓝的追索（宁可不认）。
- 弧光：起点信念"躲就是保护"→ 压力测试 1（EP01，连麦险些暴露，选择只留一句暗语）→ 压力测试 2（EP05，被女儿堵住仍说"就当爸死了"）→ 压力测试 3（EP40，暴露危机中差点弃账本跑路）→ 转变触发（EP60，女儿挡刀）→ 终点状态"站进直播间公开作证"。
- 关系：与 CHAR-1（躲与追）；与 CHAR-7（设局吞产的死仇）；与 CHAR-6（五年未见的妻子）。
- 画面代称：占位（形象归阶段四）。

### CHAR-3 陆则（lead）
- 一句话定位：拿着数据权限下场的平台运营总监。
- 小传（≤200 字）：31 岁，前财经记者，三年前因一篇被毙的深蓝集团报道离开新闻业，转行直播平台任运营总监，信条从"揭露"退成"守规则"。EP02 起注意到"老树"资金异常，职业敏感与旧怨同时被唤醒。他一度必须在平台利益与真相之间选边——而他的权限能查到的每一层，都把苏晚往父亲身边推一寸。
- 目标 / 筹码 / 底线：查清"老树"资金异常（职业动机），后期转为护苏晚翻案；筹码＝平台数据与风控档案权限；底线＝不做资本打手（旧PTSD：他当年就是被资本毙稿）。
- 弧光：起点信念"规则的旁观者"→ 压力测试 1（EP03，违规调档给她看空壳公司线索）→ 压力测试 2（EP40，上级施压封禁苏晚直播间，他抗令延迟执行）→ 转变触发（EP55，深蓝渗透平台高层）→ 终点状态"以内部证据链下场作证的人"。
- 关系：与 CHAR-1（相助与互疑→同盟）；与 CHAR-7（被毙稿旧怨）；与平台高层（权力压力）。
- 画面代称：占位（形象归阶段四）。

### CHAR-4 沈曼（support）
- 一句话定位：想把眼泪标价卖钱 MCN 女老板。
- 小传：38 岁，头部 MCN"星潮文化"创始人，信奉"一切情绪皆可变现"。EP01 后第一个闻到"父女认亲"流量腥味的人，先利诱（剧本化炒作）后威逼（80 万违约金诉讼、行业封杀），是苏晚在"地面世界"的主要压力源；后期被深蓝反向利用，成为其伸进直播行业的爪子。
- 目标 / 筹码 / 底线：签下苏晚做"认亲"人设、垄断该题材流量；筹码＝违约金合同＋行业封杀力；底线＝只玩民事纠纷，不沾刑事（这条底线最终让她倒戈成证人）。
- 弧光：不要求完整弧（support）；关键转折 EP50 深蓝越界后转向。
- 关系：与 CHAR-1（拿捏→决裂→被反用）；与 CHAR-7（利用与被利用）。

### CHAR-5 乔雅（support）
- 一句话定位：被代言合同拿捏的一姐。
- 小传：27 岁，平台一姐，苏晚当年的师姐。榜单是她的命，深蓝的代言是她的锁。前期用尽手段打压苏晚（买热搜、撕资源），后期发现深蓝用代言合同逼她做脏事（构陷苏晚直播间违规），天平倒转——她比谁都清楚被资本拿捏是什么滋味。
- 目标 / 筹码 / 底线：保住一姐位；筹码＝粉丝基本盘＋深蓝代言（双刃）；底线＝不肯亲手造谣构陷。
- 关系：与 CHAR-1（对手→盟友）；与 CHAR-7（被拿捏）。

### CHAR-6 苏母（support）
- 一句话定位：怕揭开伤疤的母亲。
- 小传：50 岁，五年来独自消化"丈夫死亡"的账单与羞辱，靠"他已经死了"这句话撑住。女儿每往真相走近一步，她就多崩溃一分——不是不想知道，是怕债主和真相一起回来。中盘得知丈夫活着时，第一反应是报警抓他（重婚/骗保质疑），后期成为父女和解的最后一关。
- 目标 / 筹码 / 底线：家恢复平静；筹码＝苏晚的软肋地位；底线＝不许女儿再冒险。

### CHAR-7 何深（support，幕后大反派）
- 一句话定位：吞掉"树深贸易"的深蓝集团老板。
- 小传：48 岁，深蓝集团创始人，五年前设局做假账吞掉合作伙伴苏建国的公司，逼其"死亡"。五年来靠"死人不会开口"高枕无忧，直到一个主播的连麦直播让"老树"的资金流水出现在风控屏幕上。他的手段层层升级：商业封杀→平台渗透→雇凶夺账本→狗急跳墙。
- 目标 / 筹码 / 底线：毁掉账本、让苏建国"死透"；筹码＝资本、律所、平台内线与打手；底线＝自己永远不出现在证据链上（这条线最终被陆则的内部证据链击穿）。
- 关系：与 CHAR-2（吞产灭口之仇）；与 CHAR-5（代言合同拿捏）；与 CHAR-4（互相利用）。

### CHAR-8 小艾（support）
- 一句话定位：助播闺蜜，直播间的大管家。
- 小传：23 岁，苏晚直播间唯一员工，管设备、场控、粉丝群。她的功能是"直播间内部视角"：弹幕风向、粉丝组织、平台规则的日常执行者；关键时刻用粉丝动员救场（EP40 封禁危机中组织粉丝转场）。
- 目标 / 筹码 / 底线：帮苏晚把直播做下去；底线＝闺蜜不能出事。

### CHAR-F1 风控主管 周正（functional）
- 占脸不占名（"风控主管"式称呼），平台资金风控线执行者，EP03 约谈、EP40 封禁令传递。不写弧光。

### CHAR-F2 收档人 老蔡（functional）

### CHAR-F3 黑粉头子"路灯下"（functional）
