## 基线对照结论（comparison 要点）

基线产出（1 万字）直觉良好（首集爆点、悬念三问、卡点意识），但结构性缺陷：

| 维度 | 基线 | drama-story |
|---|---|---|
| 追看引擎 | 无显式引擎定义（靠爆点直觉） | 引擎六问成文，第 3 问（每轮改变什么）强制状态化 |
| 单集契约 | 梗概级（"第 N 集发生什么"） | 六字段（进出状态/钩子/追求/转折兑现/出去压力/交接事实），EP(n) 出去 = EP(n+1) 进入 |
| 人物 | 小传+关系网（静态） | 目标/筹码/底线 + 弧光压力测试节点（动态，可校验） |
| 量化门 | 无 | 9 门（分档上限/场景动态上限/爽点间隔/伏笔完备） |
| 体量纪律 | 无缺口意识（素材薄直接膨胀） | 缺口测算 + add 告警线 40% |
| 伏笔 | "长线悬念"散述 | FORE 登记簿（埋设/兑现/状态） |
| ID 体系 | 无 | CHAR/PROP/LOC/EP/FORE/DEC 贯穿 |
| 上游接口 | 无（点子即全部） | 已定事实/可探索/约束三区接收 |

基线的优势：金句台词、题眼提炼等文学性内容——但这属于阶段三的润色职责。

## 跨阶段联调问题（记入总控阶段处理）

1. 简报引用 DEC 编号但未附全集（阶段一立项书有 DEC-2/3，简报只引了 1/4）——阶段二无法确认已用编号段；
2. 简报 status 交接时仍为 pending（应为 approved 才交接）；
3. 简报未说明人物命名权/城市规模的归属（可探索 or 已定）。

这三条归 drama-concept 的简报规范缺陷，列入阶段一观察项，总控联调时统一修复。
