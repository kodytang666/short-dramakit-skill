## 质量证据链

1. **可执行性**：8 个阶段全部由独立 Agent 按 Skill 实际执行真实任务验证（非自我评审）——产出物在 `测试报告/` 各 test 目录。
2. **对账能力**（最硬核证据）：阶段五节拍认领 44/44 精确对账；阶段七生成秒 vs 采用秒全镜对账；总控 DEC 编号 1-7 全程顺延无重号。
3. **越权拦截**：阶段三拒绝"8 分钟一镜到底"三项越权、阶段七拒绝"改字幕补画面"、阶段六识别"负面词陷阱"——各 Skill 的边界条款在实测中被正确引用。
4. **降级路径**：裸点子直通（阶段二 A2）、轻量评估（阶段一）、"一次跑完"豁免、材料降级档（B 入口）——四类降级均有明文且实测通过。
5. **修复响应**：43 项测试发现全部当日修复留档——缺陷发现→修复→版本迭代的闭环是质量的最强证明。
6. **诚实度**：所有无法验证的结论标 `[待验证]`（即梦 7 项、生成端行为多项、平台数据全类）；研究阶段不脑补书名、测试阶段不伪造生成结果。

## 与参考 Skill 的质量对比

| 对比项 | 最佳参考（drama-skills 群，88-93 分） | 本工具箱 |
|---|---|---|
| 阶段一能力 | 缺（生态空白） | 补全（94 分） |
| 中文即梦生态适配 | 多方言但英文中心 | Seedance/即梦方言 + 平台核对清单 |
| 依赖复杂度 | python/node 脚本链 + Dashboard + adapter | 零运行时依赖（纯指令集，ffmpeg 可选） |
| 独立安装 | 需 core 配合 | 每 Skill 自包含可用 |
| 量化门 | 部分脚本强制 | Agent 自检清单（去脚本化，代价：依赖 agent 自律执行） |

**已知风险**：量化门从"脚本强制"改为"agent 自检清单"是本工具箱最大取舍——换来零依赖与跨平台兼容，代价是门的执行依赖 Agent 遵循指令。缓解：门全部写成可数、可留痕的字段（gates 行/自检记录节），使用者可抽查。若未来需要强制，可按 shuohao 的 validate 脚本模式把清单脚本化（schemas 字段已为此预留）。
