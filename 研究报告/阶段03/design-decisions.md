## 舍弃清单

| # | 内容 | 理由 |
|---|---|---|
| 1 | script.json 机读载体 | 人读 Markdown + 行式纪律 + 台词表已覆盖 TTS/下游需求 |
| 2 | 估时 python 脚本 | 规则折算（4.5 字/秒、2.5 秒/拍）自检即可，参数可记录 |
| 3 | 渲染 HTML 报告体系 | 超出 Skill 本体职责 |
| 4 | 网文对白教程原文 | 无 LICENSE，只借鉴思想 |

## Skill 定义

- 名称：`drama-script`；输入 = 阶段二分集大纲 + 故事圣经（人物目标/筹码/底线/说话方式来源）；可选阶段四视觉设定（双向可并行）。
- 输出：`剧本-EPxxx.md`（每集）、`场次表.md`、`台词本.md`（按角色聚合）、`时长预算.md`。
- 停靠：每批成稿自检后交创作者确认（"一次跑完"可豁免）；上游矛盾记 DEC 回阶段二。
- 修改传播：剧本改动同步台词本与时长；SC-ID 稳定，删场留痕。
- 测试：A 常规（用阶段二测试 A 的 EP01 分集大纲写剧本）；C 边界（裸大纲直写 + 超长单场对白戏处理）；D 基线对照。
