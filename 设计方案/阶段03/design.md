# 阶段三设计方案：drama-script（剧本创作）

完整设计依据见 [研究报告/阶段03/design-decisions.md](../研究报告/阶段03/design-decisions.md) 与 [capability-matrix.md](../研究报告/阶段03/capability-matrix.md)。

## 核心设计决策摘要

- **载体**：人读 Markdown 剧本（short-drama-write 方言：SC-ID 场次标题、动作行/台词行分离、[VO][OS][SFX][画面文字][连续性][转场] 生产标签）+ 行式节拍纪律（novel-script 思想），不采用 JSON 载体。
- **质量双轨**：10 项量化自检（Q1 时长 ±15% / Q2 单句 ≤35 字 / Q3 说话人合法 / Q4 钩子前 3 拍 / Q5 结尾悬念落纸 / Q6 每场有画面 / Q7 动作行纯度 / Q8 爽点认领 / Q9-Q10 角色/场景对账）+ 语义自检（静默反查、可演性检验、去 AI 味专项）。
- **AI 生成前置**：动作只写常见动作（生成端"精巧动作必崩"经验 `[推断]`）、每场至少一个动作节拍（纯对白场=广播剧）。
- **接口**：输入=阶段二分集六字段+圣经人物档案；输出=剧本/场次表/台词本（TTS 接口）/时长预算；单场 ≤ 单集预算 60%。
- **舍弃**：script.json 机读载体、估时 python 脚本、渲染体系（理由见 design-decisions）。
- **测试方案与结果**：见 [测试报告/阶段03/test-report.md](../测试报告/阶段03/test-report.md)（93/100 通过）。
