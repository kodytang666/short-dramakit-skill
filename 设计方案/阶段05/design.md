# 阶段五设计方案：drama-storyboard（导演设计与分镜制作）

完整设计依据见 [研究报告/阶段05/research-report.md](../研究报告/阶段05/research-report.md)。

## 核心设计决策摘要

- **SHOT 条目**= 唯一职责 + 来源（SC + 节拍认领）+ 时长（对白镜附估时）+ 景别机位 + 运镜（固定也写理由）+ 起点→唯一动作→终点 + 声音 + 视觉依据 + 参考图需求。
- **节拍认领**（shuohao 思想）：镜头认领剧本节拍（动作行+台词行；场景描述行不计），不重不漏可对账——剧本改版的失效镜头当场点名；反应镜不认领（职责栏声明反应对象）。
- **空间先行**：站位块（锚点/位置朝向/轴线 working side/变位镜）先于切镜；打戏按 references/fight-breakdown.md 回合制拆解。
- **冻结关键帧**：起点投影（删除终点才出现的内容）；KF-EPxxx-SCyyy-nn 编号（尾帧 E）；六段式同族格式与阶段四 IMG 共画风句。
- **生成批次**：同场景同光照归批（AI 顺场表），缺图标"待出图"回阶段四。
- **测试方案与结果**：见 [测试报告/阶段05/test-report.md](../测试报告/阶段05/test-report.md)（95/100 通过；44/44 节拍对账）。
