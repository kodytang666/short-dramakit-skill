# 阶段七设计方案：drama-post-production（后期剪辑与成片交付）

完整设计依据见 [研究报告/阶段07/research-report.md](../研究报告/阶段07/research-report.md)。

## 核心设计决策摘要

- **可用带先行**：逐个素材看完整内容先标可用区间（起势静止/漂移/回弹是 AI 素材常态），再谈剪辑——事实先于决定。
- **决策表是权威**：CUT 条目（源=阶段六任务 ID / 生成秒 vs 采用秒双列 / 入出点自洽 / 取舍理由具体到画面变化 / hold 段默认裁除+特殊用途登记）；改表不改片。
- **台词逐字**：字幕与配音每一个字取自阶段三台词本（转写只定时间）；同场多句序以剧本行序为准。
- **缺口分流**：缺文件（回阶段六任务）与质量不可用（回返修）严格分开；缺关键职责镜阻塞交付。
- **工具中立**：决策表适配剪映/PR/任意软件；ffmpeg 直剪为可选增强路径（references/ffmpeg-guide.md）；质检可测项出数字、人判项交创作者。
- **测试方案与结果**：见 [测试报告/阶段07/test-report.md](../测试报告/阶段07/test-report.md)（96/100 通过）。
